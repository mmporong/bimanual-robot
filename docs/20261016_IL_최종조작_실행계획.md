# IL 최종 조작(병→컵 붓기) 실행 계획 — 한 번에 끝내는 루트

최초 작성 2026-10-16 · 조작(IL) 담당자 작성 · 성격: 실행 체크리스트(되돌아오지 않고 완주)

목표: **병을 집어 안에 든 내용물을 컵에 안정적으로 붓는** 조작을, 남은 기한(약 2주)
안에 앞 단계로 되돌아오지 않고 한 번에 완주한다. 배경·판단 근거는
[실제 붓기 전환 전략](20261016_IL_실제붓기_데이터수집_전환전략.md) 참고. 이 문서는
"무엇을 어떤 순서로, 무엇을 지키며 하는가"만 담는다.

## 0. 확정된 결정 (더 재론하지 않음)

| 항목 | 결정 | 이유(요약) |
|---|---|---|
| 매체 | **화분자갈(중간 크기 알갱이) + 받침 트레이** | 붓기 흐름 사실적·전기 위험 0·재사용. 수집은 직접 조종이라 안 튐, 평가 실패는 트레이로 회수 |
| jitter | **수집 ±3cm / 추론·평가 ±2cm** | 넓게 학습하고 안쪽에서 추론 → 가장자리 약점 회피(보간 원리) |
| 시연 방식 | **천천히·일정하게·매끄럽게** | 정책이 속도·부드러움을 그대로 흉내 |
| 붓기 | **한 번 매끈히 기울여 다 나올 때까지 유지 후 되돌림, 매번 같은 양** | 2번 기울임·짧은 붓기(흉내 붓기 잔재) 교정 |
| 시작 자세 | **매 에피소드 `goto_train_start`로 고정** | 눈대중 리셋 OOD가 떨림의 주범이었음 |
| 수위 감지·무게 대응(타 팀원) | **정책에 통합 안 함** | SmolVLA는 end-to-end. 그 작업은 성공 판정/별도 트랙으로만 병행 |

## 1. 준비

- [ ] 화분자갈 구매 — **너무 곱지 않은 중간 크기**(고우면 기구에 끼고 먼지남, 너무 크면 안 흐름)
- [ ] 받침 트레이(턱 있는 쟁반)를 컵·병 구역 아래에 배치 (평가 때 회수용)
- [ ] 병에 화분자갈를 **일정한 높이**로 채우는 기준량 정하기(매 에피소드 동일하게)
- [ ] 세션 시작 체크: 카메라 인덱스(1=오른손목/2=왼손목/3=top) · top `mirror:true` · top 라이브 여부(롤아웃과 같은 연속 읽기로)

## 2. 데이터 수집 (본 단계 — 여기만 잘하면 됨)

매 에피소드 절차:
1. 컵·병을 **중심 기준 ±3cm 범위에서 감대로 랜덤** 배치(둘 다 조금씩 다르게)
2. `python tools/rollout/goto_train_start.py`로 시작 자세 고정
3. 텔레옵으로 전체 과제 시연: 집기 → **한 번 매끈히 붓기(다 나올 때까지)** → 반환 → 적재
   - 천천히·일정 속도·매끄럽게, 매번 **같은 양** 붓기
4. 재생 검수 후 포함/제외 판정

- **목표 수량**: 30~40 에피소드(집기·운반은 이미 되므로 붓기 일관성 위주, 전보다 적어도 됨)
- **포함/제외 기준**(제외는 실패 레코드로 분리): 2번 기울임 · 중간 멈춤 · 엎지름 · 붓는 양이
  크게 다른 에피소드는 **제외**

## 3. 학습

- [ ] 기존 파이프라인으로 SmolVLA 재학습(원격 GPU), **eval_loss 최저 체크포인트** 채택
- [ ] held-out 일부를 평가용으로 분리(수집 때 미리 지정)

## 4. 추론·평가 (★ 반드시 화분자갈 넣은 상태로)

- **빈 병 추론은 "팔이 과격하지 않은가" 10초 안전 눈확인용으로만.** 무게가 학습과 달라
  유효한 평가가 아니다 — **안정성·성공 판단은 하지 말 것.**
- **진짜 평가·튜닝은 화분자갈 넣은 상태**(= 학습과 동일 조건), **±2cm 범위**에서.
- 운영: `goto_train_start`로 시작 고정 → 롤아웃(`max_relative_target=20`, sync). top 라이브 확인.
- 판정: **붓기 성공 = 컵에 들어간 양(저울 g 또는 눈금)**. CUP_PICK / POUR 분리 기록.
- 실패 시 그 조건 1회 더(한 번으로 단정 안 함).

## 5. 안정화·마무리

- [ ] 약한 구간만 타겟 추가 수집 + 재학습(필요 시)
- [ ] 운영 안정화는 이미 확보된 것 활용: `goto_train_start`(시작 자세), `max_relative_target=20`
      (급동작 차단), 카메라 freeze 검증, 카메라 타임아웃 패치
- [ ] **(최종) 물**: 화분자갈로 신뢰 확보 후, 시간 남으면 방수 보호 세팅(전장 커버·트레이·소량·
      커넥터 이격)으로 물 최종 데모/소량 파인튜닝

## 6. 이번에 "하지 않는" 것 (되돌아오지 않기 위해)

- 빈 병으로 안정성/성공 판단 금지(4절)
- jitter 가장자리(±3cm 극단)에서 추론 금지 — 추론은 ±2cm 안쪽만
- 수위 기반 가변 정지(X% 채우기) 통합 금지 — "정해진 양 붓기"로 고정(2주 범위 밖)
- 슬라임·물을 수집 매체로 쓰지 않음(화분자갈로 통일)
