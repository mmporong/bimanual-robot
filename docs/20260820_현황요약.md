# 현황 요약 (2026-08-20)

킥오프 다음 날 기준 스냅샷. 한 장으로 전체를 보기 위한 문서이며, 상세는 각 링크에 있다.

## 1. 프로젝트 정체성

**데스크톱 시료 취급 셀** — 실험실에서 사람이 하던 용기 취급을 양팔 로봇이 시연 학습으로 수행한다. 원본은 **ABB YuMi 기반 실험실 워크스테이션**. → [프로젝트 정의](20260820_프로젝트_정의.md)

**포트폴리오의 주어는 태스크가 아니라 파이프라인이다.** 수집·판정·학습·평가와 실패 진단·개선 루프가 산출물이고, 태스크는 그것의 검증 사례다. 태스크만 내세우면 "LeRobot 튜토리얼 따라한 것"으로 읽힌다.

## 2. 확정된 것

### 하드웨어

| 항목 | 값 |
|---|---|
| 구성 | **SO-101 리더 2 + 팔로워 2 (4대)** |
| 자유도 | 5축 + 그리퍼. `wrist_roll`은 **전회전 가능**(`full_turn_motor`) |
| 리치 | 약 **346mm**/팔 (상완 112.6 · 전완 134.9 · 손목→TCP 98.1mm) |
| 서보 | Feetech STS3215, 1:345. 표준 16.5 kg·cm / 프로 30 kg·cm — **어느 쪽인지 미확인** |
| 실효 페이로드 | 수백 g |
| 두 팔 간격 | 250~300mm 예상 — **실측 미확정** |

### 소프트웨어 (R1에서 확인)

- **양팔 동시 텔레옵은 LeRobot 공식 지원.** `bi_so_follower` · `bi_so_leader` · `BimanualMixin`
- **조작자 1명이 양손으로 리더암 2대**를 잡는 ALOHA 방식. 조작자 2명도 순차 녹화도 아니다
- **좌우 표현 규약은 `left_*` / `right_*` 접두어**로 이미 정해져 있다. 공용 카메라는 접두어 없음
- **HIL 개입 재학습(DAgger 계열)이 `bi_so_leader` 지원.** 정책 실패 시 리더암으로 교정해 재학습
- 데이터 포맷은 **LeRobot v3.0** 고정

### 수치 기준선

- **시연 50~60회/태스크** — Mobile ALOHA 50회로 80%, RoboTwin 공식 프로토콜 50개, ACT 60회로 80%. 세 출처 일치
- 평가는 **태스크당 100 에피소드** (RoboTwin 프로토콜)
- 수집 총량 200 에피소드 ≈ **5~8시간** (리셋·폐기 포함). 수집은 병목이 아니다

### 일정 제약

| 시점 | 의미 |
|---|---|
| **10/13** | **실기체 수집 마감.** M07보다 먼저 닫힌다 |
| 10/14 ~ 11/3 | M07 정규 15일 — 새 데이터 없이 분석·개선·발표 |
| **10/15** | 지원 슬레이트 스냅샷 → **이 프로젝트는 지원용이 아니라 면접용 자산** |

## 3. 미결정 — 엔드이펙터 구성

석션 도입 검토 결과 **구성에 따라 다른 프로젝트가 된다.** → [R9](../research/R9_엔드이펙터_구성_석션검토.md)

| 구성 | 태스크 | 양팔 근거 | 결정적 제약 |
|---|---|---|---|
| A. 그리퍼 2 | 용기 개폐 | 회전 반작용 토크 | **그리퍼 닫힘 15초** — 200 에피소드에 3.3시간 대기 |
| B. 석션 2 | 봉지 벌려 담기 | 양면 동시 견인 | 벌린 뒤 **투입할 팔이 없다** |
| **C. 석션 1 + 그리퍼 1** | 봉지 고정 + 물품 투입 | 유지와 조작의 역할 분리 | 진공 펌프·밸브 조달 필요 |

**권고는 절충안이다.** 구성 A로 먼저 파이프라인을 관통시키고(추가 하드웨어 없음), 석션을 병행 조달해 구성 C로 확장한다. 그러면 석션이 늦어져도 멈추지 않고, 성공하면 **"엔드이펙터 구성 비교"라는 축이 하나 더 생긴다.**

핵심 물리: **석션은 회전 토크를 전달하지 못한다.** 뚜껑을 돌릴 수 없다. 반대로 **얇은 비닐은 평행 그리퍼로 집기 어렵다.** 각 도구를 강점에만 쓰는 것이 구성 C의 논리다.

## 4. 측정 골격 (구성과 무관하게 유지)

이 넷이 "태스크 하나 학습시킨 것"과 프로젝트를 가른다. **축소할 때 마지막까지 지킨다.**

| 지표 | 역할 |
|---|---|
| **단팔 대조군** | 같은 파이프라인에서 한 팔만 사용 → 양팔 필수성을 주장이 아니라 실측으로 |
| **귀무 정책 대조** | 관측 무시하고 평균 궤적 재생 → 지표가 뭔가를 재고 있음을 증명 |
| **HIL 재학습 전후** | 개입 데이터 전/후 성공률 → 개선 폭이 곧 성과 수치 |
| **실패 유형 분류** | F1 파지 / **F2 고정 실패** / F3 미끄러짐 / F4 정렬 / F5 도달 → 진단 체계 |

축소 우선순위: 태스크 개수 → 난이도 수준 → 측정 항목.

## 7. 즉시 확인할 것 (우선순위)

| # | 항목 | 왜 급한가 |
|---|---|---|
| **1** | **서보가 표준킷(16.5 kg·cm)인지 프로킷(30)인지** | 고정 토크를 못 버티면 용기 개폐가 성립하지 않는다 |
| **2** | 두 팔 베이스 간격 실측 | 양팔 교집합 작업 영역이 여기서 결정된다 |
| 3 | 석션 그리퍼·진공 펌프 조달 가능 여부와 기간 | 구성 C 전환 시점을 결정 |
| 4 | USB 4포트 + 카메라 동시 운용 | 대역폭·전원. 카메라는 버스 분리 |
| 5 | 용기 후보 선정 | **손으로 돌려 필요 토크를 먼저 재고**, 그 안에 드는 것을 고른다 |
| 6 | M07 강의 트랙 ③(URDF·MoveIt2)과 팀 계획 충돌 | 강의는 URDF 제작을 포함하는데 팀은 배제하기로 했다 |

**순서를 지킬 것**: 용기를 먼저 정하고 로봇이 되기를 바라면 안 된다. 서보 스펙 → 필요 토크 실측 → 용기 선정.
