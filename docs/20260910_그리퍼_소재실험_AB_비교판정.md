# 그리퍼 STL(A/B) × 재질 5케이스 비교판정 — 잔(컵) 파지 기준

작성 2026-09-10. 처음 보는 사람도 A/B가 뭔지, 케이스 번호가 뭘 뜻하는지 바로 이해할 수
있도록 쓴다. 결론만 보려면 맨 아래 **[최종 결론]** 으로 건너뛰어도 된다.

## 0. 왜 이 문서가 필요한가

프로젝트 루트에 STL 파일 두 개가 있었다: `Ender_Follower_SO101.stl`, `SO101_soft_fin.stl`.
이 둘을 각각 **A**, **B**로 부르고, "잔(물컵)을 안정적으로 집는 그리퍼"라는 과제 기준으로
경질(딱딱한 PLA/PETG 계열) vs TPU(연질) 조합 5가지를 비교해 어느 쪽이 가장 이상적인지
판정한다.

> 참고: `docs/20260904_그리퍼_출력_인계.md`에는 이미 다른 그리퍼(ggao50
> SO101-Parallel-Gripper)를 채택한 기록이 있다. 이 문서는 그것과는 별개로 A/B라는
> 두 후보 설계를 놓고 진행한 재질 비교 실험이며, 기존 결정을 자동으로 대체하지 않는다.
> 두 트랙 중 무엇을 최종 채택할지는 팀 결정이 필요하다.

## 1. A와 B는 정확히 무엇인가

STL 파일을 직접 파싱해서 크기(bounding box)와 "붙어 있는 부품 덩어리 개수(연결요소)"를
측정했다. 이 둘의 정체가 서로 완전히 다르다는 게 이번 분석에서 가장 중요한 발견이다.

### A = `Ender_Follower_SO101.stl`

- 출처: [SO-ARM100 저장소](https://github.com/TheRobotStudio/SO-ARM100/blob/main/STL/SO101/Follower/Ender_Follower_SO101.stl)
- 실측: 216 × 215 × 87 mm, **서로 붙어있지 않은 부품이 12개** 들어있음
- **정체: 그리퍼 파일이 아니라 "Ender 시리즈 프린터 베드 크기에 맞춰 팔 전체 부품(베이스,
  상완, 전완, 손목, 모터 홀더 등)을 한 판에 몰아넣은 출력용 배치 파일"**이다.
- 같은 저장소의 `STL/SO101/Individual/` 폴더에 그리퍼 조각만 따로 있는
  `Moving_Jaw_SO101.stl`이 존재한다. A 안에는 이 그리퍼 조(jaw)가 12개 부품 중
  **일부로만** 섞여 들어있다.
- 즉 "A를 통째로 TPU로 출력"하면 베이스·팔뚝 같은 하중을 버텨야 하는 구조 부재까지
  전부 물러지므로, 로봇 팔로서 성립하지 않는다. 이 문서의 케이스 1~3은 **A 안에 있는
  그리퍼 조/트리거 서브파츠에 한정해서** 재질을 바꾸는 것으로 해석한다.

### B = `SO101_soft_fin.stl`

- 출처: [XLeRobot 저장소](https://github.com/Vector-Wangel/XLeRobot/tree/main/hardware)
- 실측: 67 × 119 × 65 mm, 부품 3개(핑거 52×49×65mm, 핑거/조 37×20×48mm,
  마운트 베이스 67×24×24mm)
- 저장소 README에 명시된 문구: **"Fin Ray(핀레이 효과) 소프트 핑거이며 TPU95A로
  출력해야 한다. 원래 SO101 핑거를 원하고 싶으면 원본 STL을 받아라."**
- **정체: 처음부터 "그리퍼 조 교체용 키트"로 설계된 소형 파일.** 핀레이 효과란
  물고기 지느러미에서 착안한 구조로, 내부에 비스듬한 리브(rib)를 넣어서 물체를 누르면
  그 리브가 휘면서 표면이 물체 곡면에 감기듯 적응하는 구조다. **이 구조는 리브가 실제로
  휘어야만 의미가 있으므로, 설계 자체가 TPU 같은 연질 재질을 전제로 한다.**

## 2. 5가지 케이스가 뜻하는 것

| 케이스 | 무엇을 뜻하는가 |
|---|---|
| **1** | A의 그리퍼 조를 **경질**(PLA/PETG)로 출력 — SO-101 기본 평행 조 그대로 |
| **2** | A의 그리퍼 조 **전체**를 TPU로 출력 — 피벗 구멍·링크 결합부까지 전부 물렁하게 |
| **3** | A의 그리퍼 조 중 **실제로 물체에 닿는 핑거 부분만 TPU**, 피벗·마운트·링크 결합부는 경질 유지 (이종재질 결합 또는 듀얼 익스트루전 필요) |
| **4** | B(핀레이 소프트 핑거)를 **경질**로 출력 — 설계 의도와 반대로 뽑는 경우 |
| **5** | B(핀레이 소프트 핑거)를 **TPU95A**로 출력 — 설계자가 의도한 원래 조합 |

## 3. 판정 기준: 잔(컵)을 잡을 때 뭐가 중요한가

잔은 ① 원통형 곡면 ② 표면이 매끈해 마찰계수가 낮음 ③ 내용물(물)이 있으면 흔들림·관성이
생김 ④ 벽이 얇아 한 점에 힘이 몰리면 깨지기 쉬움, 이라는 특성을 가진다. 따라서 좋은
그리퍼는 **접촉면적이 넓고(감싸는 형태), 마찰계수가 높고, 위치 오차에 관대(적응형)** 해야
한다.

## 4. 케이스별 분석

| 케이스 | 접촉 방식 | 잔 파지 적합성 | 기구적 정밀도/내구성 |
|---|---|---|---|
| 1. A 경질 | 평행 조가 원통면에 사실상 선접촉 2점 | 저마찰+저접촉면적 → 슬립 위험 큼 | 피벗·서보 결합 정확, 재현성 최고 |
| 2. A 전체 TPU | 조 형상 자체는 안 바뀌는데 재질만 물러짐 | 마찰은 조금 늘지만 "감싸는 그립"은 안 생김 | 피벗 구멍 마모·링크 백래시로 **1번보다 나쁠 수 있음** |
| 3. A 핑거만 TPU | 경질 바디 + 접촉면 연질 패드 (산업용 그리퍼의 흔한 방식) | 접촉 마찰·완충 개선, 다만 감싸는 형태는 아님 | 피벗·마운트 정밀도 유지 → A 계열 중 최선 |
| 4. B 경질 | 리브가 안 휘어 적응 효과 0, 얇은 리브라 오히려 잘 깨짐 | 설계 의도 정반대 → **최악** | 반복 파지 시 크랙 위험 |
| 5. B TPU95A | 리브가 잔 곡면에 감기며 접촉면적 극대화, TPU 자체 마찰계수도 높음 | 위치 오차에 관대, 얇은 유리잔에도 힘 분산 | 설계자가 검증한 정식 조합 |

**순위: 5 > 3 > 1 > 2 > 4**

## [최종 결론]

> ## 가장 이상적인 조합은 **케이스 5 — B파일(`SO101_soft_fin.stl`)을 TPU95A로 출력**이다.
>
> 이유는 한 문장으로: **잔은 곡면·저마찰·깨지기 쉬운 물체인데, B는 정확히 이런 물체를
> 감싸 쥐도록(핀레이 효과) 설계됐고 그 효과는 TPU로 뽑았을 때만 발현되기 때문**이다.
> 반대로 같은 B를 경질로 뽑는 케이스 4는 설계 의도를 정면으로 거스르는 최악의 조합이다.

### 실험 전 확인해야 할 것

- B의 마운트 베이스(67×24×24mm)가 실제 SO-101 손목 서보 나사 간격과 맞는지 —
  README상 드롭인 호환이라 되어 있지만, 이 저장소 규칙대로 **줄자·실물 대조**로 최종
  확정할 것 (프로브/문서만 믿지 않기).
- 컴플라이언트 핑거는 물체마다 닫히는 스트로크가 달라진다. 위치제어만으로 닫으면
  과소/과대 그립이 날 수 있으므로, STS3215 서보의 **전류(토크) 기반 그립 완료 판정**을
  쓰는지 현재 텔레옵/IL 파이프라인에서 확인 필요.
- 핀레이 리브는 얇아서 반복 파지에 따른 피로/파손 가능성이 있다. 장기 데이터 수집 시
  케이스 1(A 경질)을 안정성 대조군으로 병행 실험 권장.
- `docs/20260904_그리퍼_출력_인계.md`의 ggao50 결정과 이번 A/B 실험 중 무엇을 최종
  채택할지 팀 논의 필요 (본 문서는 그 결정을 대신하지 않음).
