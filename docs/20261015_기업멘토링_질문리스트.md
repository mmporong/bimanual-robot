작성 2026-10-14 · 대상: 위고로보틱스 / 솔트룩스 / 시티캣 (각 1시간, 총 3시간)

세 기업은 출정식에도 참여했고, 이후 매주 수요일(총 3회) 멘토링과 최종
발표에도 참여한다. 질문은 "우리 프로젝트의 실제 막힌 지점"과 "각 기업의
전문 분야"가 겹치는 지점만 골랐다 — 범용 질문은 넣지 않았다.

## 우리 프로젝트 한 줄 요약

HOLD THE FLOW: 웹 주문 → 이동 로봇이 주방까지 이동 → 양팔로 물 따르고 컵을
상판에 실어 테이블까지 운반 → 도크 복귀. 현재 시뮬 전체 미션 1회 통과,
SmolVLA 정책 실물 주방 조작 1회 완주, 실차 왕복 이동 기록까지 각각
확보했지만 **반복 평가·통합**이 남아 있다(README 참고).

## 위고로보틱스 — 로봇 플랫폼·VLA/모방학습·Sim-to-Real

Unitree·AgileX Robotics 한국 파트너사로, 로봇암(PiPER 등)·모바일로봇·휴머노이드를
공급하면서 VLA·모방학습·Sim-to-Real 적용까지 같이 다룬다. 우리의 양팔 조작
파트(SmolVLA, 실물 rollout)와 가장 직접 겹치는 기업이다.

1. **Sim-to-real 격차 우선순위**: 저희는 시뮬에서는 전체 미션이 통과했고
   실물에서는 SmolVLA로 주방 조작 1회를 완주했는데, 반복했을 때 성공률이
   떨어지는 게 당연히 예상됩니다. 실제 납품 현장에서 Sim-to-real 격차를 줄일 때
   가장 먼저 점검하시는 항목이 무엇인가요(데이터, 카메라/좌표 보정,
   하드웨어 반복성 중 어디부터 보시나요)?
2. **위치 일반화**: 물체(컵·물통) 위치가 조금씩
   달라지는 상황에 정책이 버티게 만들 때, "데모 데이터를 더 모으는 것"과
   "후처리 쪽 보완" 등의 방법 중 실무에서 어느 쪽을 먼저 접근하시나요?
3. **현장 반복 고장 유형**: 로봇암을 여러 산업 현장에 SI로 납품하면서
   가장 자주 반복되는 하드웨어 고장(캘리브레이션 드리프트, 케이블/커넥터
   문제 등)은 무엇이고, 이를 표준 점검 루틴으로 어떻게 관리하시나요?

## 솔트룩스 — LLM·지식그래프·AICC(AI 컨택센터)

자체 LLM '루시아'를 지식그래프 기반 사실 그라운딩으로 환각을 줄이는 게
강점이고, AICC처럼 "정해진 업무를 확실히 수행해야 하는" 서비스 경험이
많다. 우리 웹 주문 관제(정해진 테이블/옵션만 받는 폐쇄형 시스템)와
접점이 있다.

1. **좁은 도메인에 LLM 도입 실익**: 저희는 지금 버튼으로 테이블 등을
   선택하는 방식인데, 이걸 자연어 주문(예: "2번 테이블에 시원한 물 하나")
   으로 바꾼다면 지식그래프 기반 환각 억제 기술을 쓸 만큼 이득이 있을지,
   아니면 이 정도 규모·복잡도에서는 규칙 기반이 더 나은지 실무 기준으로
   어떻게 판단하시나요?
2. **오작동 명령의 최종 방어선**: AICC처럼 실수가 바로 비용으로 이어지는
   서비스에서, LLM이 잘못된 요청(명령)을 만들어낼 때 이를 실행 직전에
   걸러내는 안전장치는 어떤 구조로 설계하시나요?

## 시티캣 — Edge AI·영상처리·자율 로봇(ROBOAT)

Raspberry Pi급 엣지 보드에서 영상 인식을 돌리는 경험과, 군집 자율 로봇
운용 경험이 있다. 저희 지민석 파트(컵·물통·액면 인식, Raspberry Pi
온보드 처리)와 직접 겹친다.

1. **엣지에서 정확도 vs 지연시간 타협**: Raspberry Pi 같은 저성능 보드에서
   실시간 영상 인식(물체·액면 등)을 돌릴 때, 정확도와 지연시간을 동시에
   잡기 어려우면 실무에서 가장 먼저 포기하거나 타협하는 부분이 무엇인가요?
2. **조명 변화 대응 노하우**: ROBOAT처럼 야외·수면처럼 조명이 수시로
   바뀌는 환경에서 영상 인식을 운용하신 경험에 비추어보았을 때, 저희가 컵 속 액면을
   인식할 때 참고할 만한 운영 노하우가 있을까요?
3. **"에러 없이 조용히 틀린 값"을 내보내는 센서 감지**: 저희는 최근 카메라
   한 대가 멈췄는데 에러 하나 없이 똑같은 프레임을 계속 내보내서 데이터가
   조용히 망가진 적이 있습니다. 군집 로봇을 운용하시면서 센서가 이런 식으로
   "조용히" 고장 나는 걸 모니터링하는 방식이 있으신가요?
