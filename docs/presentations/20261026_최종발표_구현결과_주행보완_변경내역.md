## 1. 구현 결과 6장 (5~10번 슬라이드)
초안에는 제목 칩만 있었다. 6장 모두 같은 틀로 채웠다.
- **제목:** 결과 한 문장
- **진행 표시:** 11단계 중 이 장이 몇 단계인지(조작 단계는 주황)
- **영상 자리:** 왼쪽 점선 상자에 "▶ 이곳에 영상을 넣으시오", 들어갈 장면 설명, "16:9 · 이 점선 상자 크기에 맞춰 넣은 뒤 상자는 삭제" 안내
- **오른쪽:** "어떻게" 카드 3개, 수치 카드 2개
- **아래:** "핵심" 한 줄
- **발표자 노트:** 새로 썼다. 기존 노트는 6장 모두 개요 장의 노트가 복사되어 있었다.

## 3. 그 외 정리
- **쪽 번호:** 뒤섞여 있던 번호를 순서대로 다시 매겼다(02~24).
- **섹션 칩 번호:** 하드웨어 장 "06"은 "04"로, 뒤쪽 "6·7·8·9"는 "06·07·08·09"로 맞췄다.
- **4번 개요 장 노트:** "회색 두 단계" 설명이 실제 화면과 맞지 않아 고쳐 썼다.
- **자동 열기 실패:** 초안의 4~10번 장에는 슬라이드 전체를 확대하는 등장 애니메이션(`sldTgt` + `ppt_w/ppt_h`)이 있었다. 이것 때문에 PowerPoint가 파일을 자동으로 열지 못해 이 애니메이션만 지웠다. 모핑 전환은 유지했다.

## 4. 발표 전에 확인할 값
- "도킹 성공 2회"는 육안 확인이다. 소프트웨어의 자동 도킹 판정은 false로 기록돼 있다(노트에 구분해 적음).
- "20/20", "77 m"는 9월 2륜 차체 기록이다. 4륜으로 같은 시험을 반복한 기록은 없다.
- "14/14"는 배포 데모 웹의 클릭 시험 결과이고, 실차 주행과 웹 주문은 아직 연결되지 않았다(노트에 질문 대비용으로 적음).
- 기존 장의 [임의] 숫자(9/10, 93% 등)는 이번에 고치지 않았다.
