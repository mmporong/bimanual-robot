# Plan A 확정: HOLD THE FLOW

작성: 2026-08-28

상태: 메인 시나리오 확정, 실물 검증 전

## 결정

이동형 비정형 용기 붓기를 양팔 로봇 프로젝트의 Plan A이자 메인 시나리오로 확정한다. 봉지 열어 담기는 연구 기록과 후속 실험 후보로 남기지만, 현재 하드웨어 제작과 통합 일정에는 넣지 않는다.

프로젝트 이름은 `HOLD THE FLOW`, 팀·시스템 표기는 `HANDOVER`를 사용한다. `HOLD THE FLOW`는 물의 흐름과 작업 상태의 흐름을 함께 다룬다는 뜻이고, `HANDOVER`는 두 팔 사이의 역할 인계와 사람에서 로봇으로 넘어가는 작업 인계를 함께 가리킨다.

## 목표

로봇이 SLAM/Nav2로 작업대에 접근하고, 한 팔로 경량 병을 기울이는 동안 다른 팔로 받는 컵을 든다. 접촉 센서와 저울로 파지와 유입 결과를 판정하며, 실패가 기록되면 상태기계나 감독 에이전트가 검증된 복구 스킬을 고른다.

이 프로젝트는 이동, 로컬 정렬, 양팔 협응, 실물 판정, 실패 복구가 연결되는 과정과 각 단계의 실패 기록을 보여준다.

## 양팔이 필요한 이유

받는 컵을 작업대에 내려놓으면 붓기는 한 팔로도 끝난다. 이 프로젝트에서는 반대 팔이 컵을 들고 자세를 안정화한다. 한 팔은 병을 조작하고 다른 팔은 받는 용기를 유지하므로 역할이 겹치지 않는 비대칭 협응이 된다.

단팔 대조군은 같은 병을 테이블 위 컵에 붓는 조건으로 둔다. 양팔 조건은 공중에서 컵을 유지한 채 붓는 조건으로 둔다. 두 조건은 성공 여부뿐 아니라 컵 자세, 유입량, 흘림, 작업 시간으로 비교한다.

## 작업 시나리오

1. 모바일 베이스가 SLAM/Nav2로 작업대 인근 목표 자세까지 이동한다.
2. Depth 카메라나 표식으로 작업 셀의 마지막 위치를 보정한다.
3. 병 쪽 팔과 컵 쪽 팔이 각 물체를 파지한다.
4. 컵 쪽 팔이 자세를 유지하고, 병 쪽 팔이 내용물을 붓는다.
5. 접촉값과 저울값으로 파지 손실, 유입량, 넘침을 판정한다.
6. 실패 상태에 맞춰 재관측, 재파지, 추가 붓기, 중단 후 홈 복귀 가운데 허용된 행동을 실행한다.

## 시스템 경계

```text
SLAM / Nav2
  작업대 인근 접근
        ↓
Depth / 표식 정렬
  작업 셀 로컬 좌표 인계
        ↓
IK / ACT
  병·컵 파지와 붓기
        ↓
접촉 센서 / 저울 / RGB-D
  성공·실패 상태 생성
        ↓
FSM 기본 복구 → 로컬 LLM 감독 확장
  검증된 스킬만 선택
```

VLA는 현재 핵심 범위에서 제외한다. 로컬 LLM은 좌표, 토크, 모터 명령을 만들지 않는다. 정상 경로는 LLM 없이 상태기계로 먼저 통과시키고, LLM은 구조화된 실패 상태를 읽어 `REOBSERVE`, `REGRASP`, `POUR_MORE`, `ABORT_AND_HOME` 같은 허용된 스킬만 고르게 한다.

## 그리퍼와 센서

양쪽 팔에는 교체 가능한 평행 그리퍼를 사용한다.

| 위치 | 기본 구성 | 먼저 확인할 것 |
|---|---|---|
| 병 쪽 | V홈 TPU 패드, 접촉 센서 | 곡면 파지, 눌림, 미끄럼 |
| 컵 쪽 | 넓은 패드 또는 반원형 인서트 | 컵 자세 유지, 변형, 낙하 |
| 작업대 | 소형 저울 | 유입량과 흘림량 판정 |
| 공통 | 퀵스왑 손목 어댑터 | 질량, 개구폭, 손목 모멘트 |

진공 그리퍼는 Plan A의 선행 조건이 아니다. 봉지 실험을 다시 열 때 후속 엔드이펙터 후보로 검토한다.

## 하드웨어 전제

- 병과 내용물의 총중량은 200~300g으로 제한한다.
- 초기 내용물은 물 대신 비드나 쌀을 사용한다.
- 500ml 생수병은 현재 실험 대상에서 제외한다.
- 접촉 센서는 정밀 힘 제어보다 접촉 여부, 과도한 눌림, 좌우 불균형을 먼저 판정한다.
- 모바일 베이스는 조작 정밀도를 직접 만들지 않는다. 작업대를 카메라 시야와 팔 작업공간 안에 반복해서 넣고 로컬 정렬 단계로 넘긴다.

## 구현 게이트

아래 항목은 측정 결과가 아니라 실험 순서와 통과 조건을 정하기 위한 계획이다.

| 게이트 | 시험 | 남길 증거 |
|---|---|---|
| G0 파지 | 병과 컵 정적 파지 | 낙하·변형·접촉값 영상과 로그 |
| G1 기울이기 | 내용물 없이 붓기 자세 유지 | 관절 드리프트·파지 손실 기록 |
| G2 붓기 | 건식 내용물과 저울로 결과 판정 | 유입량·흘림량·작업 시간 |
| G3 통합 | 이동, 정렬, 양팔 조작 연결 | 단계별 상태 전이와 실패 위치 |
| G4 복구 | 미끄럼·넘침·미검출 상태 주입 | 재시도 결과와 안전 중단 로그 |

R30에서 제안한 첫 실물 게이트는 10회 중 7회 이상 안정 파지·기울임, 자동 판정 2종 이상, 실패 5회 중 3회 이상 안전 복구다. 이 수치는 목표 기준이며 아직 달성 결과가 아니다.

## 역할

| 역할 | 우선 담당 | 공동 작업 |
|---|---|---|
| 강사·멘토 | 로컬 LLM 실행 환경, 감독 에이전트, 기술 교육 | 통합 게이트와 실물 제약 리뷰 |
| 사용자 | SLAM/Nav2, 모바일 베이스, 작업대 접근 | 로컬 정렬 인계와 전체 통합 |
| [@jangjunseo05](https://github.com/jangjunseo05) | ACT/IK, 그리퍼, 실물 데이터 | 접촉·중량 기록과 양팔 POC |

두 학습자는 ACT, IK, Depth, 접촉 센서의 기초를 함께 공부한다. 기능별 주 담당은 두되 실물 통합 시험과 실패 분류는 같이 수행한다.

## 바로 진행할 일

1. 병과 컵 후보의 무게, 지름, 표면 재질을 기록한다.
2. V홈 TPU 패드와 컵 인서트의 치수 초안을 만든다.
3. 정적 파지와 무수 기울이기 시험표를 만든다.
4. 저울 데이터의 시간값, 목표 유입량, 흘림량 기록 형식을 정한다.
5. Nav2 완료 상태에서 로컬 정렬로 넘길 인터페이스를 정의한다.
6. G0부터 순서대로 실물 영상과 로그를 남긴다.
