# 1. 주제

# 양팔 커넥터 체결 셀

**차량 조립 라인에서 사람이 양손으로 하는 커넥터 체결을, 양팔 로봇이 시연 학습으로 수행한다.**

## 왜 이것인가

**양쪽 커넥터가 모두 유연한 케이블 끝에 달려 있어 어느 쪽도 고정되어 있지 않다.** 한 손으로 한쪽을 잡고 밀면 반대쪽이 밀려난다. 지그로 고정할 수도 없다 — 차량 하네스는 이미 배선된 상태라 커넥터가 공중에 떠 있다.

**이것이 다른 후보와 갈리는 지점이다.** 병뚜껑·단자삽입·부품조립은 전부 "지그로 고정하면 단팔로 된다"는 반론에 걸렸는데, 커넥터 체결은 **고정할 대상 자체가 없다.**

| 축 | 평가 |
|---|---|
| **양팔 근거** | **B2 물리적** — 양쪽 다 고정 불가 |
| **학습 근거** | 케이블 처짐·커넥터 자세가 매번 다르다. 삽입 힘 조절은 규칙으로 못 쓴다 |
| **하드웨어** | **실물 그대로 가능** — 하우징 2~5cm, 페이로드 수십 g, 회전 불필요 |
| **판정** | **딸깍 체결 여부가 이진.** 서보 부하 스파이크로 감지 |
| **소모품** | 없음 — 뺐다 꽂으면 재사용 |
| **현업** | **차량 조립 라인의 실제 작업.** 하네스 조립 약 90%가 수작업 |
| **선행 연구** | *AI-based Framework for Robust Model-Based Connector Mating in Robotic Wire Harness Installation* `arXiv:2503.09409` |

## 무엇을 측정하나

| 지표 | 방법 |
|---|---|
| 체결 성공률 | 조건 격자 × 반복. 실물 관측 |
| **불완전 체결 검출률** | **들어갔는데 안 잠긴 상태** — 현업의 실제 품질 문제 |
| 삽입 힘 곡선 | 서보 부하 시계열. 딸깍 순간의 스파이크 |
| **단팔 대조군** | 한 팔로 시도 — **반대쪽이 밀려 체결 불가.** 물리적으로 0% |
| 귀무 정책 대조 | 관측 무시하고 평균 궤적 재생 |
| 커넥터 종류 일반화 | 학습에 없던 커넥터에서의 성공률 |
| HIL 재학습 전후 | 개입 데이터 추가 전/후 |

## 실패 유형

| 코드 | 유형 |
|---|---|
| F1 | 파지 실패 (커넥터를 못 잡음) |
| **F2** | **정렬 실패 (암수 축이 안 맞음)** |
| **F3** | **불완전 체결 (들어갔으나 잠기지 않음)** |
| F4 | 반대쪽 밀림 (안정화 실패) |
| F5 | 과삽입·핀 손상 |

## 난이도 계단

| 수준 | 조건 |
|---|---|
| L1 | 커넥터 1종, 시작 위치 고정, 케이블 짧게 |
| L2 | 시작 위치·자세 랜덤화 |
| L3 | **커넥터 2~3종 혼합**(핀 수·크기 다름) |
| L4 | **케이블 길이 변화** — 처짐이 커져 자세 예측이 어려워짐 |
| L5 | 여러 커넥터를 순서대로 체결 |

# 2. 준비물 — 실물 제품

## 2-1. 자동차용 (현업 그대로)

국내 자동차 하네스는 **KET(한국단자공업)**이 주력이고 현대·기아 차량에 들어간다.

| 시리즈 | 단자 폭 | 용도 |
|---|---|---|
| 025 | 0.64 mm | 신호선 |
| **090** | **2.29 mm** | 일반 전원 — **권장** |
| **187** | **4.75 mm** | 중전류 |
| 250 | 6.35 mm | 대전류 |

숫자는 인치 단위 단자 폭이다(0.090″ = 2.29 mm). 하우징은 핀 수에 따라 2~5 cm.

**확인된 품번 예시**: `MG620409`, `MG651026` (KET 커넥터 하우징 계열)

**구매처**

| 판매처 | 링크 |
|---|---|
| 에이투케이샵 (KET 브랜드관) | https://www.a2kshop.kr/goods/goods_list.php?brandCd=013 |
| 하네스몰 (KET 카테고리) | https://www.harnessmall.com/43 |
| 아이씨뱅큐 (자동차용 커넥터) | https://www.icbanq.com/A02_product/productList.do?cateCode=105163111 |
| KET 공식 제품 검색 | https://www.ket.com/kr/product/search.ket |

⚠ **정확한 품번은 판매처에서 직접 확인해야 한다.** 하우징과 터미널이 별도 품번이고, 암(female)·수(male) 하우징이 짝으로 필요하다. 위 품번은 검색으로 확인된 예시일 뿐 우리 용도에 맞는지는 미검증이다.

## 2-2. 대체 후보 (구하기 쉽고 크기가 넉넉)

L1 파일럿과 그리퍼 파지 검증에는 이쪽이 낫다. 자동차용은 L3 이후에 섞는다.

| 커넥터 | 크기 | 특징 | 조달 |
|---|---|---|---|
| **Molex Mini-Fit Jr.** (5557 리셉터클 / 5559 플러그) | 4.2 mm 피치, 2~24핀 | PC 파워 커넥터. **딸깍 래치 체결**, 크기 넉넉 | 전자부품몰 어디나 |
| **JST VH** | 3.96 mm 피치 | 크고 튼튼, 저렴 | 아이씨뱅큐·디바이스마트 |
| **XT60 / XT90** | 16×8 mm / 더 큼 | RC 배터리용. 체결감 명확, 매우 저렴 | RC샵·오픈마켓 |
| **Anderson Powerpole** | 8 mm급 | 체결 확실, 극성 구조 | 전자부품몰 |

**권장 조합**: L1~L2는 **Molex Mini-Fit Jr. 6핀** 또는 **XT60**으로 시작해 파이프라인을 관통시키고, L3에서 **KET 090/187**을 섞어 "자동차 부품으로 일반화된다"를 보인다.

## 2-3. 그 외 준비물

| 항목 | 용도 | 비고 |
|---|---|---|
| 케이블 (AWG 18~22) | 커넥터 배선. 길이 변화가 L4 축 | 색을 달리하면 비전 대비 확보 |
| **커넥터 거치대** | 시작 자세를 일정하게 잡아주는 홀더 | **3D 프린팅** — M07 트랙 ③과 연결 |

| 카메라 2~3대 | 상단 + 손목 | **버스 분리 필수** (USB 교착 이력) |

## 대안 비교

| 플랫폼 | 무료 제한 | 화면 공유 | 적합도 |
|---|---|---|---|
| **Discord** | **사실상 없음** (인원·시간) | **무료** | **권장** — 상시 음성 채널, 파일·링크 공유, 개발 팀에서 표준적 |
| Google Meet | 3명 이상 **60분** | 무료 | 짧은 정기 회의용 |
| Zoom | **40분** | 무료 | 짧은 회의용 |
| MS Teams | 60분 | 무료 | 학교 계정 있으면 |
| 카카오톡 그룹콜 | 없음 | 가능 | 급할 때 |

**권장: Discord.**
- 상시 켜두는 음성 채널이 있어 **"들어와 있으면 같이 작업"**이 된다. 회의를 잡지 않아도 소통이 된다
- 채널을 파트별로 나눌 수 있다 (`#제어인식` `#학습` `#데이터` `#웹`)
- 화면 공유가 무료이고 화질 제한이 실사용에 충분하다
- 로그가 남아 나중에 "본인의 기여"를 서술할 때 근거가 된다

**문서·코드는 별도로** — 회의는 Discord, 기록은 GitHub(코드·문서) + 공유 드라이브(대용량). 채팅에만 남기면 나중에 못 찾는다.
