# 1. 주제

# 양팔 커넥터 체결 셀

**차량 조립 라인에서 사람이 양손으로 하는 커넥터 체결을, 양팔 로봇이 시연 학습으로 수행한다.**

## 왜 이것인가

**양쪽 커넥터가 모두 유연한 케이블 끝에 달려 있어 어느 쪽도 고정되어 있지 않다.** 한 손으로 한쪽을 잡고 밀면 반대쪽이 밀려난다. 지그로 고정할 수도 없다 — 차량 하네스는 이미 배선된 상태라 커넥터가 공중에 떠 있다.

**이것이 다른 후보와 갈리는 지점이다.** 병뚜껑·단자삽입·부품조립은 전부 "지그로 고정하면 단팔로 된다"는 반론에 걸렸는데, 커넥터 체결은 **고정할 대상 자체가 없다.**

| 축 | 평가 |
|---|---|
| **양팔 근거** | **B2 물리적** — 양쪽 다 고정 불가 |
| **학습 근거** | 케이블 처짐·커넥터 자세가 매번 다르다. 삽입 힘 조절은 규칙으로 못 쓴다 |
| **하드웨어** | **실물 그대로 가능** — 하우징 2~5cm, 페이로드 수십 g, 회전 불필요 |
| **판정** | **딸깍 체결 여부가 이진.** 서보 부하 스파이크로 감지 |
| **소모품** | 없음 — 뺐다 꽂으면 재사용 |
| **현업** | **차량 조립 라인의 실제 작업.** 하네스 조립 약 90%가 수작업 |
| **선행 연구** | *AI-based Framework for Robust Model-Based Connector Mating in Robotic Wire Harness Installation* `arXiv:2503.09409` |

## 무엇을 측정하나

| 지표 | 방법 |
|---|---|
| 체결 성공률 | 조건 격자 × 반복. 실물 관측 |
| **불완전 체결 검출률** | **들어갔는데 안 잠긴 상태** — 현업의 실제 품질 문제 |
| 삽입 힘 곡선 | 서보 부하 시계열. 딸깍 순간의 스파이크 |
| **단팔 대조군** | 한 팔로 시도 — **반대쪽이 밀려 체결 불가.** 물리적으로 0% |
| 귀무 정책 대조 | 관측 무시하고 평균 궤적 재생 |
| 커넥터 종류 일반화 | 학습에 없던 커넥터에서의 성공률 |
| HIL 재학습 전후 | 개입 데이터 추가 전/후 |

## 실패 유형

| 코드 | 유형 |
|---|---|
| F1 | 파지 실패 (커넥터를 못 잡음) |
| **F2** | **정렬 실패 (암수 축이 안 맞음)** |
| **F3** | **불완전 체결 (들어갔으나 잠기지 않음)** |
| F4 | 반대쪽 밀림 (안정화 실패) |
| F5 | 과삽입·핀 손상 |

## 난이도 계단

| 수준 | 조건 |
|---|---|
| L1 | 커넥터 1종, 시작 위치 고정, 케이블 짧게 |
| L2 | 시작 위치·자세 랜덤화 |
| L3 | **커넥터 2~3종 혼합**(핀 수·크기 다름) |
| L4 | **케이블 길이 변화** — 처짐이 커져 자세 예측이 어려워짐 |
| L5 | 여러 커넥터를 순서대로 체결 |

# 2. 세 후보 — 상세와 차이

마지막까지 남은 것은 셋이다. 하나를 고르는 회의이므로 **강점과 단점을 같이** 적는다.

## 2-1. ★★★ 커넥터 체결 (권장)

**정의** — 양쪽 모두 케이블 끝에 달린 암·수 커넥터를 양팔이 각각 잡고, 정렬해 딸깍 체결한다.

| 축 | 내용 |
|---|---|
| 양팔 근거 | **고정할 대상이 없다.** 한쪽을 밀면 반대쪽이 밀려난다 |
| 학습 근거 | 케이블 처짐으로 자세가 매번 다르고, 삽입 힘 조절은 규칙으로 못 쓴다 |
| 판정 | **딸깍 체결이 이진.** 서보 부하 스파이크로 감지 |

**강점**

- 양팔 근거가 **물리적**이다 — "지그로 고정하면 되잖아"에 답이 준비돼 있다
- **현업 그대로**다. 차량 하네스 조립 약 90%가 수작업
- 실물 부품을 그대로 쓴다. 축소 모형이 아니다
- 소모품이 없다. 뺐다 꽂으면 무한 반복 — 실패 비용이 0

**단점**

- **하우징 정렬 정밀도가 최대 관문.** 암수 축이 mm 단위로 맞아야 딸깍이 난다
- **벤치마크가 없다** — 참조 논문 1편(`arXiv:2503.09409`)뿐이라 비교 대상이 없다
- 커넥터가 작아 **그리퍼 파지 검증이 선행**돼야 한다 (하우징 2~5 cm)
- depth로 커넥터 자세를 읽기 어려울 수 있다 (얇은 물체 미검출 이력)

## 2-2. ★★☆ 부품 조립 셀 (대체 1순위)

**정의** — 한 팔이 본체를 들어 자세를 유지하고, 다른 팔이 부품을 끼운다. 직접 설계·출력한 부품을 쓴다.

| 축 | 내용 |
|---|---|
| 양팔 근거 | 고정+작업 분업(B1). 다만 **지그로 대체 가능하다는 반론이 있다** |
| 학습 근거 | 조립 순서, 장기 시퀀스 |
| 판정 | 결합 여부 — 관측이나 부하로 판정 |

**강점**

- **파지 리스크가 없다.** 부품을 우리가 설계하니 그리퍼에 맞춰 만들면 된다
- **벤치마크가 있다** — FurnitureBench·FurnitureVLA. 성능을 견줄 기준선이 존재
- 난이도를 설계로 조절할 수 있다. 막히면 부품을 키우면 된다
- 3D 프린팅이라 조달 대기가 없다

**단점**

- **"지그로 고정하면 단팔로 되잖아"에 답하기 어렵다** — 양팔 근거가 가장 약한 축
- **"IKEA 가구 조립"으로 들려 서사가 약하다.** 어느 산업이라고 말하기 애매
- 설계·출력에 시간이 든다. 부품 형상을 우리가 정하니 **"난이도를 스스로 낮췄다"**는 인상이 남을 수 있다
- 실패해도 부품이 안 망가져 실패 비용이 0인 건 장점이자, 물리적 긴장감이 없다는 단점

## 2-3. ★★☆ 농업 수확 셀

**정의** — 한 팔이 줄기를 잡아 고정하고, 다른 팔이 과실을 따거나 자른다.

| 축 | 내용 |
|---|---|
| 양팔 근거 | **줄기가 흔들려 단팔로는 위치가 안 잡힌다.** 물리적 |
| 학습 근거 | 과실 위치·줄기 강도가 매번 다르다 |
| 판정 | 분리 성공 + 손상 여부 |

**강점**

- **단팔 대조군이 가장 깨끗하다.** 한 팔로 하면 줄기가 흔들려 실패하는 게 눈에 보인다
- 실배치 사례가 최신이다 (DailyRobotics 2026-04)
- 데모 영상이 직관적이라 발표에서 설명이 필요 없다

**단점**

- **매다는 구조물 제작이 선행**된다 — 줄기·가지를 공중에 고정할 프레임이 필요
- 인조 과일이면 **물성 다양성이 제한**된다. 진짜 과일은 소모품
- **줄기 강도를 우리가 정한다** → "만들어낸 난이도"라는 인상
- 절단 도구를 쓰면 안전 이슈가 추가된다

## 2-4. 부품 조립과 커넥터 체결은 무엇이 다른가

둘 다 "끼우는" 작업이라 비슷해 보이지만 **양팔 근거의 성격이 정반대**다.

| 축 | 부품 조립 셀 | 커넥터 체결 |
|---|---|---|
| **고정 가능성** | 지그로 고정 가능 → **단팔로도 됨** | **고정 대상이 없음** → 양팔 필수 |
| **파지 난이도** | 설계로 제거 (손잡이·크기 조절) | 기성품이라 그대로 감수 |
| **양팔 근거** | 간접 — 장기 시퀀스·순서 | **직접 — 물리적으로 불가피** |
| **학습 근거** | 조립 순서 | 케이블 처짐·삽입 힘 조절 |
| **판정** | 결합 여부 (관측 필요) | **딸깍 이진 + 부하 스파이크** |
| **벤치마크** | **FurnitureBench 존재** | 논문 1편뿐 |
| **서사** | "IKEA 조립"으로 들림 | **"전장 조립 90% 수작업"** |
| **준비** | 설계·3D 출력 시간 | **발주만** |
| **정밀도 리스크** | 낮음 — 설계로 조절 | **높음 — 최대 관문** |

**판정: 두 안은 서로의 보험이다.** 커넥터가 정렬 정밀도에서 막히면 부품 조립으로 넘어가면 된다. 그리고 그때 **커넥터 하우징을 스케일업해 출력하는 것**이 두 안의 교집합이다 — 부품 조립의 설계 자유도로 커넥터 체결의 물리(양쪽 다 고정 불가)를 그대로 유지할 수 있다. 서사도 "IKEA 조립"이 아니라 "전장 조립"으로 남는다.

## 3-2. 대체 후보 (구하기 쉽고 크기가 넉넉)

L1 파일럿과 그리퍼 파지 검증에는 이쪽이 낫다. 자동차용은 L3 이후에 섞는다.

| 커넥터 | 크기 | 특징 | 조달 |
|---|---|---|---|
| **Molex Mini-Fit Jr.** (5557 리셉터클 / 5559 플러그) | 4.2 mm 피치, 2~24핀 | PC 파워 커넥터. **딸깍 래치 체결**, 크기 넉넉 | 전자부품몰 어디나 |
| **JST VH** | 3.96 mm 피치 | 크고 튼튼, 저렴 | 아이씨뱅큐·디바이스마트 |
| **XT60 / XT90** | 16×8 mm / 더 큼 | RC 배터리용. 체결감 명확, 매우 저렴 | RC샵·오픈마켓 |
| **Anderson Powerpole** | 8 mm급 | 체결 확실, 극성 구조 | 전자부품몰 |
| **D-sub 9핀** | 31×13 mm | **나사 고정형** — 체결 메커니즘이 다르다. 일반화 축으로 쓸 수 있음 | 전자부품몰 |
| **RJ45 (랜)** | 12×11 mm | **래치 누름형** — 또 다른 메커니즘. 매우 저렴 | 어디나 |

**권장 조합**: L1~L2는 **Molex Mini-Fit Jr. 6핀** 또는 **XT60**으로 시작해 파이프라인을 관통시키고, L3에서 **KET 090/187**을 섞어 "자동차 부품으로 일반화된다"를 보인다.

**메커니즘 다양성**: 위 표는 체결 방식이 세 갈래다 — **래치 걸림**(Molex·JST·XT60), **나사 고정**(D-sub), **래치 누름**(RJ45). L3에서 이걸 섞으면 "커넥터 종류 일반화"가 단순한 크기 차이가 아니라 **동작 자체가 다른 일반화**가 된다.

# 4. 역할 분담 (4인)

회의에서 나뉜 파트를 이 주제에 맞춰 구체화했다. **누가 어느 파트를 맡을지는 회의에서 정한다.** 인터페이스를 명시해 서로 기다리지 않게 하는 것이 핵심이다.

## A. 로봇 제어 · 인식

| 항목 | 내용 |
|---|---|
| 범위 | 커넥터 검출(RGB+depth), 좌표계·hand-eye, 양팔 IK 접근, 안전 래퍼(스톨·과삽입 차단), 서보 부하 기반 **체결 감지** |
| 산출물 | `perception/` · `control/` 모듈, 캘리브레이션 절차서, **체결 판정기** |
| 인터페이스 | 정책이 호출할 `plan(observation) → action` 과 `is_mated() → bool` 제공 |
| 선행 | 8월 말까지 두 팔 간격 실측·캘리브레이션 완료 (다른 파트가 여기 의존) |

## B. 이미테이션 러닝 · 정책

| 항목 | 내용 |
|---|---|
| 범위 | ACT 학습, π₀·SmolVLA 파인튜닝 비교, 평가 하네스, HIL 개입 재학습 |
| 산출물 | `policy/` 모듈, 학습 스크립트, **데이터량-성능 곡선** |
| 인터페이스 | A가 준 관측 규격과 C가 준 데이터셋을 입력으로 받음 |
| 선행 | 9월 초 파일럿 학습으로 파이프라인 관통 확인 |
