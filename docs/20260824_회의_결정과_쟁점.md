## 2. 회의 후 정리된 판정

### 커넥터 체결 → 보험으로 하향

난이도(정렬 정밀도·백래시)도 이유지만 결정적인 건 **명령 축이 하나뿐**이라는 점이다. 명령이 "체결해" 하나로 끝나서 음성·플래닝 층이 얹힐 자리가 없다. 음성을 주제로 세운 이상 물리 태스크는 **여러 후보 중 하나를 고르는 형태**여야 한다.

→ 스케일업 3D 출력 형태로 보험만 유지. 실물 KET·Mini-Fit 발주 보류.

### 물리 태스크 = 음성 지시 조작 3종

| 태스크 | 문장 | 양팔 등급 |
|---|---|---|
| 옮기기 | `Move the red cup to the left tray` | B0 (기준선) |
| 건네주기 | `Hand over the blue cup to the other arm` | B1 |
| **들고 있는 컵에 붓기** | `Pour the bottle into the held cup` | **B2** |

세 태스크의 양팔 등급이 갈리므로 **단팔 대조 실험이 태스크셋 안에 내장된다.**

### 붓기 — 되지만 조건 셋 (→ R27)

1. **총 무게 ≤ 300g.** SO-101 EE 권장 페이로드 400g. 500ml 생수병(≈530g)은 초과 — 회의에서 나온 콜라병은 그대로는 못 든다
2. **액체 금지, 비드·쌀.** COFFAIL도 안전상 국수로 대체했다
3. **유입량 판정 장치(저울) 필요.** 카메라로 잔량 판단이 안 되므로 없으면 성공률을 못 센다

기대치: 100~150 데모에 60~80%. 정렬 정밀도가 필요 없어 **커넥터보다 명백히 쉽다.**

### 양팔 근거 — 받는 컵을 반대 팔이 들게 해야 성립

컵을 테이블에 두면 단팔로 끝난다 — 부품 조립안을 밀어낸 "지그" 반론에 그대로 걸린다. **받는 컵이 공중에 떠 있으면** 고정으로 대체할 대상이 없어져 커넥터와 같은 논리가 되고, 정밀도 요구는 훨씬 낮다.

약점은 숨기지 않는다: 이 양팔 필요성은 **우리가 설계한 것**이라 커넥터의 "원래부터 고정 불가"보다 한 단 약하다.

### 음성 — 하드웨어 문제가 아니었다 (→ R23)

USB 마이크 꽂으면 된다. 어려웠던 건 "명령을 정책에 어떻게 넣나"였고 답은:

```
USB 마이크 → Whisper STT → 텍스트 → complementary_data["task"] → SmolVLA
```

**모델 구조 변경 0.** `rollout/inference/sync.py:73`의 `self._task`가 매 추론에서 다시 읽히므로 STT 스레드가 이 값을 갱신하면 다음 추론부터 새 명령으로 동작한다. Audio-VLA(2511.09958)는 **음성이 아니라 접촉음** 논문이라 이 경로에 쓰지 않는다.

주의: 마이크를 **Astra와 같은 USB 버스에 몰지 말 것** (depth 데몬 교착 전례).

### depth — Pointmap으로 정책 입력 가능 (→ R25)

arXiv:2607.11498 (KAIST DAVIAN). 픽셀에 로봇 좌표계 XYZ를 담은 이미지를 **두 번째 인코더(RGB 가중치로 초기화) + element-wise 덧셈**으로 넣는다. 기반이 **pi0.5·SmolVLA**, 실기는 **4태스크·180데모·시점 3개**. hand-eye가 전제라 `~/so101_tools` 자산이 그대로 입력이 된다. 코드 링크 비활성이 리스크.

순서를 뒤집지 않는다: **RGB 베이스라인 → pointmap 추가 → before/after.**

## 3. 8/25 회의 논점 4개

1. 커넥터를 보험으로 내린다 — 근거는 난이도 + **명령 축이 하나라 음성 층이 죽는다**
2. 물리 태스크는 음성 지시 3종. 붓기는 **받는 컵을 반대 팔이 드는 형태**로 고정
3. 음성은 USB 마이크 + Whisper → task 문장. 오디오 인코더 개조 없음
4. depth는 pointmap으로. 단 RGB 베이스라인 다음 순서

## 4. 조달 결정이 필요한 것

- USB 마이크 1개 (Astra와 다른 버스)
- 250ml급 경량 용기 + 컵 2~3종 (색 구분)
- 비드·쌀
- **소형 저울** — 유입량 판정. 이게 없으면 지표가 성립하지 않는다
