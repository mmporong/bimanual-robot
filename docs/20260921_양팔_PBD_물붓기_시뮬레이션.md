# 양팔 PBD 물붓기 시뮬레이션

> 2026-09-22 구성 변경: 왼손은 TPU FinRay가 아니라 SO-101 순정 회전식 죠를 사용한다.
> 이 문서의 성공 실행은 과거 80 mm 강체 패드 프록시를 사용했으므로 현행 순정 죠 성공으로
> 재해석하지 않는다. 전체 시나리오 구조는 유지하되 순정 죠 형상·재캘리브레이션 값으로 파지와
> 물붓기를 다시 검증해야 한다.

## 입구가 넓은 컵

현재 실험 컵은 높이 120 mm, 가운데 파지 지름 70 mm, 입구 외경 90 mm, 바닥 외경
56 mm다. 중앙 40 mm 높이는 원통형을 유지하고 위쪽 40 mm에서 바깥으로 벌어진다.
벽 두께 3 mm 기준 입구 내경은 84 mm다. 빈 질량 10 g은 기존 가정값이며 실제 컵 실측값이 아니다.

`cup_radius_profile_m`이 시각 메쉬, 속 빈 충돌체와 컵 안의 물 입자 판정에 함께 적용된다.
벽은 둘레 32분할·높이 3구간의 볼록 조각으로 만들며 입구를 막는 충돌체는 없다.
가운데 파지·상승·오른쪽 병을 왼쪽 컵으로 기울이는 IK 순서는 유지한다.

첫 시험 `flared01`은 내려가는 손가락이 넓어진 입구에 닿아 추종 오차로 중단됐다.
45 mm 후보 `flared02`는 기존 붓기 판정을 통과했지만, 별도 경로 검토와 기록 재판정에서
닫기 전 접촉을 확인해 채택하지 않았다. 최초 6.417초에 약 0.952 N, 해당 구간 최대
43.364 N의 고정 손가락 접촉이 있었다. 원본 결과를 덮어쓰지 않고 `review_verdict.json`에
기각 이유를 남겼다. 현재 판정은 닫기 전 접촉 0.02 N 이상 또는 XY 이동 3 mm 초과를 거부한다.

사전 접근 거리는 75 mm로 늘렸다. 같은 파지 위치를 유지하면서 컵 바깥에서 내려온 뒤
중앙 높이로 접근한다. 60/75/90/100 mm 후보를 비교했으며, 하강 2초를 120 Hz로 표본화한
양 패드·컵 벽 SAT 검사에서 60 mm는 약 4 mm, 75 mm는 약 14 mm 분리 여유였다.
90/100 mm는 ALIGN IK 조건을 만족하지 못했다. 이 검사는 해당 구간 표본 검사이지
전체 팔의 연속 충돌 증명이나 실물 공차 검증은 아니다.
유출 감소 여부는 전체 물리 실행 결과로 비교한다. 넓어진 외형만으로 덜 흘린다고 판정하지 않는다.

`flared03` 105°·20초 조건 1회는 종료 코드 0, `task_pass: true`, `preclose_clear: true`로
파지·붓기·복귀·손 분리까지 통과했다. 닫기 전 접촉/이동 위반은 0건이며 팔끼리·비파지
링크와 용기·컵과 병의 접촉 신호 최대도 0 N이다. 이는 해당 관측 범위의 결과다.

## 방향 수정과 재검증

사용자 영상 검토로 `final_record03`의 동작 방향을 기각했다. 물 전달 수치는 통과했지만
병 몸통이 로봇 왼쪽으로 넘어가고 입구는 오른쪽을 향했다. 기존 접촉 신호는 0 N이므로
이 기록을 측정된 충돌 실패로 바꾸지는 않으며, 팔 역할과 붓기 방향을 잘못 설정한 실패로 남긴다.

좌표는 X 전방, Y 왼쪽, Z 위다. 병 몸통은 컵 오른쪽에 남기고 병 축은 +Y 중심 ±30° 범위로
기울인다. 화면의 시계 방향은 카메라 시점에 따라 달라지므로 판정에는 사용하지 않는다.
입구는 컵 오른쪽 100 mm 대기점에서 컵 쪽으로 이동한다. 오른손은 초기 주차·파지부터
음수 손목 롤 분기를 사용하고, 붓기 중 관절 한계를 넘지 않도록 경로를 연결한다.

정확한 방위각 100° 고정 후보는 수평을 지나는 구간에서 팔꿈치·손목 굽힘이 크게 변했다.
이 후보 `inward01`은 중단했다. 현행 계획은 왼쪽 방향 범위를 필수 조건으로 두고,
그 범위 안의 방위각 선호와 관절 연속성을 함께 최적화한다.

`inward02` 105°·20초 조건 1회는 종료 코드 0, `task_pass: true`,
`stop_reason: sequence_finished`, `inward_pour_direction: true`로 끝났다.

## 범위

왼손 컵 파지·상승, 오른손 병 파지·상승, 작업 위치 이동, 붓기, 병과 컵 내려놓기,
손 열기·후퇴를 하나의 시간축으로 실행한다. 물체를 손에 붙이는 joint나 매 tick pose 덮어쓰기는
없다. 물은 초기화한 PhysX PBD 입자이며, 이후 생성·순간이동하지 않는다.

실물 팔·카메라·ROS는 사용하지 않는다. 컵과 병 위치는 시뮬레이터의 정답 좌표를 사용하며
RGB 인식, IL 정책, 현행 순정 죠 실물 파지, 바퀴 주행은 이 검증에 포함되지 않는다.

## 경로와 완료 판정

1. 컵 중간 높이로 접근하고 양측 접촉을 확인한 뒤 들어 올린다.
2. 병도 같은 순서로 들어 올린다. 컵은 수직축 방향을 유지한다.
3. 병을 먼저 위로 올린 뒤 컵 오른쪽 대기점으로 이동한다.
4. 병 입구 위치·기울기와 왼쪽 방향 범위를 IK로 검사한다. 몸통이 왼팔 쪽으로 넘어가는 해는 거부한다.
5. 병 몸통을 오른쪽에 두고 입구를 왼쪽 컵으로 이동하며 낮춘다.
6. 붓기 후 경로를 되짚고 병, 컵 순서로 내려놓는다. 책상 접촉 뒤 팔 위치를 유지하며 손을 연다.

완료는 phase 이름만으로 판단하지 않는다. 마지막 1초 동안 초기 입자의 50% 이상이 컵에
남고, 컵·병 밖 입자가 5% 이하여야 한다. 양쪽 물체의 책상 지지 신호, 손 분리, 실제 그리퍼
열림, 수직 자세, 위치 안정화도 함께 확인한다. 붓기 구간은 실제 병 기울기 90~110°,
병 입구와 컵 림의 상대 위치, 양측 파지 유지, 입자 보존을 검사한다.
실제 병 쿼터니언으로 왼쪽 방향 범위와 몸통 중심의 오른쪽 배치를 확인한다. 방향 정보가 없거나
반대 방향인 기록은 물 전달량이 충분해도 성공으로 처리하지 않는다. 실행 중에도 기울기 15° 이상인
붓기·복귀 구간에서 방향을 검사한다.
붓기 직전 1초에는 95% 이상의 입자가 병에 남아 있어야 하며, 붓기 구간에서 컵 내부 증가와
병 내부 감소가 각각 초기 입자의 50% 이상이어야 한다. 운반 중 0.1초 이상 연속 파지 접촉
유실은 실패다. 최종 XY 위치도 초기 위치에서 20 mm 이내여야 한다.

접촉력 값은 복합 collider의 집계 영향이 남아 있어 정량 힘·무게 검증에 쓰지 않는다.
접촉 유무 신호와 물체 위치·자세·정지 구간을 함께 사용한다. GPU 환경의 CCD 경고가 있어
연속 충돌 검증 완료로 표기하지 않는다.

## 재현

저장소 루트에서 Isaac Sim 5.1을 설치한 Python 환경으로 실행한다. 새 출력 경로가 필요하며
기존 실행 폴더는 덮어쓰지 않는다.

```bash
cd "$HOME/bimanual-robot"
python tools/simulate_bimanual_pour.py --headless --output-dir logs/pour_new
```

`--plan-only`는 CPU 계획과 manifest만 생성한다. `--settle-only`는 정지 상태의 유체 유지
진단이며 태스크 성공으로 세지 않는다. `--record`는 전체 프레임을 보존한다.

성공 결과는 `result.json`의 `task_pass: true`와 `stop_reason: sequence_finished`를 함께
확인한다. Kit 빠른 종료 전에 반환 코드를 지정하므로 태스크 실패는 프로세스 종료 코드 2다.
정지 유체 진단은 성공하더라도 `task_pass: false`이며 종료 코드만 0일 수 있다.

물리 구현 참고: [NVIDIA PhysX particles 문서](https://docs.omniverse.nvidia.com/kit/docs/omni_physics/107.3/dev_guide/particles/particles.html).
