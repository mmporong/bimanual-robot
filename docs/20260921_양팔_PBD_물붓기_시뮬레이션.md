## 범위

왼손 컵 파지·상승, 오른손 병 파지·상승, 작업 위치 이동, 붓기, 병과 컵 내려놓기,
손 열기·후퇴를 하나의 시간축으로 실행한다. 물체를 손에 붙이는 joint나 매 tick pose 덮어쓰기는
없다. 물은 초기화한 PhysX PBD 입자이며, 이후 생성·순간이동하지 않는다.

실물 팔·카메라·ROS는 사용하지 않는다. 컵과 병 위치는 시뮬레이터의 정답 좌표를 사용하며
RGB 인식, IL 정책, 실물 FinRay 변형, 바퀴 주행은 이 검증에 포함되지 않는다.

8 mm 장착 후보의 기하 검사는 손목 메쉬와 연결판 사이 Y 분리 평면을 관절 한계 내 1° 이하

오른손 두 랙의 겹친 박스는 실제 톱니 맞물림을 표현하지 못한다. 이 두 링크 사이만 충돌
필터를 둔다. 블레이드의 최소 간격은 관절 한계에서 20 mm이고 실제 죠 위치도 감시한다.
손목·반대 팔·컵·병·책상 접촉은 제외하지 않는다.

## 경로와 완료 판정

1. 컵 중간 높이로 접근하고 양측 접촉을 확인한 뒤 들어 올린다.
2. 병도 같은 순서로 들어 올린다. 컵은 수직축 방향을 유지한다.
3. 병을 먼저 위로 올려 컵을 건널 때 바닥이 림을 스치지 않게 한다.
4. 병 입구 위치와 수직축 기울기를 IK로 맞춘다. 5축 제약 때문에 방위각은 약한 선호로만 둔다.
5. 초기 기울기에서는 병을 높게 유지하고, 누운 뒤 입구를 컵 가까이 낮춘다.
6. 붓기 후 경로를 되짚고 병, 컵 순서로 내려놓는다. 책상 접촉 뒤 팔 위치를 유지하며 손을 연다.

완료는 phase 이름만으로 판단하지 않는다. 마지막 1초 동안 초기 입자의 50% 이상이 컵에
남고, 컵·병 밖 입자가 5% 이하여야 한다. 양쪽 물체의 책상 지지 신호, 손 분리, 실제 그리퍼
열림, 수직 자세, 위치 안정화도 함께 확인한다. 붓기 구간은 실제 병 기울기 90~110°,
병 입구와 컵 림의 상대 위치, 양측 파지 유지, 입자 보존을 검사한다.
붓기 직전 1초에는 95% 이상의 입자가 병에 남아 있어야 하며, 붓기 구간에서 컵 내부 증가와
병 내부 감소가 각각 초기 입자의 50% 이상이어야 한다. 운반 중 0.1초 이상 연속 파지 접촉
유실은 실패다. 최종 XY 위치도 초기 위치에서 20 mm 이내여야 한다.

접촉력 값은 복합 collider의 집계 영향이 남아 있어 정량 힘·무게 검증에 쓰지 않는다.
접촉 유무 신호와 물체 위치·자세·정지 구간을 함께 사용한다. GPU 환경의 CCD 경고가 있어
연속 충돌 검증 완료로 표기하지 않는다.

## 재현

저장소 루트에서 Isaac Sim 5.1을 설치한 Python 환경으로 실행한다. 새 출력 경로가 필요하며
기존 실행 폴더는 덮어쓰지 않는다.

```bash
cd "$HOME/bimanual-robot"
python tools/simulate_bimanual_pour.py --headless --output-dir logs/pour_new
```

`--plan-only`는 CPU 계획과 manifest만 생성한다. `--settle-only`는 정지 상태의 유체 유지
진단이며 태스크 성공으로 세지 않는다. `--record`는 전체 프레임을 보존한다.

성공 결과는 `result.json`의 `task_pass: true`와 `stop_reason: sequence_finished`를 함께
확인한다. Kit 빠른 종료 전에 반환 코드를 지정하므로 태스크 실패는 프로세스 종료 코드 2다.
정지 유체 진단은 성공하더라도 `task_pass: false`이며 종료 코드만 0일 수 있다.

물리 구현 참고: [NVIDIA PhysX particles 문서](https://docs.omniverse.nvidia.com/kit/docs/omni_physics/107.3/dev_guide/particles/particles.html).
