# IL 실제 붓기로의 전환 전략 — 흉내 붓기에서 실제 흐름 데이터로

최초 작성 2026-10-16 · 조작(IL) 담당자 작성 · 성격: 전략 판단 + 2주 실행 루트

프로젝트 최종 목표는 **병의 내용물을 컵에 붓는 것**이다. 이 문서는 현시점에서
남은 기한(약 2주, 2026-10-30 전후까지) 안에 "안정적으로 병을 집어 컵에 붓는 데모"를
확보하기 위한 경로를 정한다. 이전 계획·진행 내용에 얽매이지 않고 완수 가능한 최선의
루트를 기준으로 쓴다.

## 0. 한 줄 결론

떨림 등 구동 안정성 문제는 해결됐다(시작 자세 OOD·카메라 freeze 등). **남은 핵심
결함은 "붓기"이며, 이는 부드러움 문제가 아니라 데이터 문제다** — 학습 데이터가 실제
흐름이 없는 "흉내 붓기"였기 때문이다. 따라서 **실제로 흐르는 물질(권장: 쌀·비즈·화분자갈 등
알갱이)로 데모를 다시 수집**하는 것이 근본 해결이다. 물은 전기 위험이 커서 데이터
수집 매체로는 부적합하며, 필요 시 마지막 보호 세팅 데모로만 쓴다.

## 1. 결정적 발견 — 학습 데이터는 "흉내 붓기"였다

학습 데이터셋(`jun-seo/water-pour-position-jitter-v1`) ep32의 탑뷰를 에피소드 전
구간에서 뽑아 확인한 결과:

- 병은 **밀봉된 음료병(유자차)으로 캡이 끝까지 씌워져 있다.**
- 에피소드 끝(95% 지점)까지 **컵은 비어 있다** — 실제로 따라진 액체가 없다.
- 즉 밀봉된 가득 찬 병을 **무게 추**로 쓰고, 붓는 "동작만" 흉내 낸 데이터다.

### 이것이 현재 증상을 설명한다

- **붓기 때 병을 2번 기우는 문제 / 기우는 시간이 짧은 문제**: 캡이 있어 실제 흐름
  피드백이 없으니, 시연자가 매번 "대충" 기울였다. 정책은 "언제까지 기울여야 내용물이
  다 나오는지"를 배운 적이 없어, 일관되지 않은(2번 기울임) 짧은 붓기를 재생한다.
- 반대로 **집기·운반은 비교적 괜찮다** — 밀봉된 가득 찬 병이라 **무게와 운반 중
  내부 출렁임은 이미 학습 분포에 있었다.** 네 걱정(무게·슬로싱) 중 '운반 중 슬로싱'은
  어느 정도 커버되고, **'따르는 중 유량·무게 이동·정지 시점'만 빠져 있다.**

## 2. 핵심 판단 — 후처리로는 못 고친다, 새 데이터가 답이다

- **후처리의 한계**: 한 번도 기록되지 않은 "실제 흐름" 정보는 후처리로 만들어낼 수
  없다. 후처리는 나쁜 에피소드를 **걸러내는**(제외 기준) 정도만 가능하다.
- **근본 해결**: 실제로 흐르는 물질로 전체 에피소드(집기→붓기→반환→적재)를 다시
  수집한다. 시연자가 흐름을 **보면서** 붓게 되므로, "한 번 매끄럽게, 다 나올 때까지"의
  올바른 붓기가 자연스럽게 데이터에 담긴다.
- **이번 세션의 안정화 작업은 토대다**: 시작 자세 고정(`tools/rollout/goto_train_start.py`),
  카메라 freeze 검증, `max_relative_target=20`은 "물질을 넣고 안전하게 수십 번 데모를
  반복 수집"할 수 있는 전제 조건이었다. 떨림 해결은 버리는 작업이 아니라 이 전환의
  발판이다.

## 3. 매체 선택 — 물·슬라임보다 "알갱이(쌀·비즈·화분자갈)"

| 매체 | 흐름이 물과 유사? | 전기 위험 | 가시성/계측 | 재사용·청소 |
|---|---|---|---|---|
| 물 | ◎ | **✗ 높음(합선·부식)** | 투명해 안 보임 | 흘리면 복구 어려움 |
| 슬라임 | ✗ (느리고 끈적, 물과 딴판) | △ | △ | 끈적임·그리퍼 오염 |
| **쌀/작은 비즈/화분자갈(권장, 실사용: 화분자갈)** | ○ (붓기 모션·유량이 물에 가장 근접) | **◎ 없음** | ◎ 잘 보임, **저울로 g 측정** | ◎ 즉시, 반복 |

- **알갱이는 실제로 흐른다** → 시연자가 유량을 보며 올바른 붓기를 하게 되어, 2번
  기울임·짧은 기울임이 교정된다.
- **전기 위험이 없다** → 수십~수백 번의 반복 수집/평가에서 누적 리스크가 없다.
- **저울로 성공을 객관 측정**할 수 있다(컵에 들어간 g).
- 원래 기획서 R27도 **"비드/쌀 + 저울 판정"**을 전제했다 — 후퇴가 아니라 원안 수렴.
- **슬라임 비추천**: 흐름이 물과 가장 다르고(점성·저속), 그리퍼·컵이 끈적여 반복
  수집에 부적합하다.

## 4. 2주 실행 루트

| 기간 | 할 일 | 끝 조건(게이트) |
|---|---|---|
| 1–2일차 | 알갱이로 **스모크 10~15 에피소드**. 재생 검수로 붓기가 깨끗한지(한 번 매끈히 기울여 컵에 실제로 들어감) 확인. `goto_train_start`로 시작 자세 고정, 롤아웃/수집 전 top 라이브 확인 | 텔레옵 붓기가 일관되게 찍힘 |
| 3–5일차 | **본수집 40~60 에피소드** (집기→붓기→반환→적재 전체, 기존과 같은 작은 jitter 유지). 에피소드 메타에 **컵에 들어간 g** 기록 | 목표 수량 확보 |
| 6–7일차 | SmolVLA 재학습(원격 GPU, 기존 파이프라인), 최저 eval_loss 체크포인트 채택 | 수렴 확인 |
| 8–10일차 | 알갱이로 평가 — **붓기 성공 = 컵에 들어간 g**으로 판정. 약한 구간만 타겟 추가 수집 | 안정적 붓기 재현 |
| 11–14일차 (선택/마무리) | 알갱이로 신뢰 확보됐고 시간 남으면, **방수 보호 하에 실제 물 최종 데모** 1회 | 최종 산출물 |

## 5. 정해야 할 단 하나의 갈림길

**최종 산출물이 "진짜 물"이어야 하는가, "붓는 능력 입증(알갱이)"으로 충분한가?**

- **알갱이로 충분** → 위 10일차까지가 **보장된 완성본.** 가장 안전하고 2주 안에 확실.
- **물이 필수** → 알갱이로 먼저 시스템을 완성·검증(위험 최소화)한 뒤, 마지막에 물
  보호 세팅으로 최종 데모 또는 소량 파인튜닝. 알갱이→물은 붓기 모션은 같고 유량만
  빨라 "대체로 전이"되지만 완벽하지는 않다(물이 더 빨리 비므로 과붓기 경향 가능).

**권장**: 알갱이를 기본 매체로 데이터·학습·평가까지 완주해 **보장 산출물을 먼저
확보**하고, 물은 시간이 남을 때의 마무리 데모로 둔다.

## 6. 물을 쓸 경우 안전 수칙 (최종 데모용)

- 바닥 전장(서보 컨트롤러·배선·버스 커넥터)을 **방수 커버/트레이**로 가리고, 붓는
  구역 바로 아래에 전자부가 오지 않게 배치한다.
- **소량**으로 시작하고, 커넥터·USB 허브를 붓는 구역에서 멀리 둔다.
- 실기체 안전 규칙(CLAUDE.md)대로, 흘림·충돌 시 즉시 정지·토크 처리 경로를 유지한다.
