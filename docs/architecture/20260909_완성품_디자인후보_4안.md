# 완성품 디자인 후보 4안 — 폐기 기록

이 문서의 A~D 후보와 300×300 mm 상판 이미지는 2026-09-10 설계 변경으로 폐기했다. GitHub README나 제작 판단에 사용하지 않는다.

현행 완성품 기준은 [450×340 mm 4분할 상판 양팔 로봇 모델](20260910_450x340_4분할상판_URDF_IsaacSim_모델.md)이다. 상·하부 프레임 외곽을 450×340 mm로 맞추고, 2020 기둥 4개와 프로파일 지지형 4분할 상판을 사용한다.

이전 후보 이미지와 계산 결과는 저장소 현재 트리에서 제거하며 필요하면 Git 이력으로 확인한다.
