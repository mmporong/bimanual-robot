# 롤아웃 시작·끝 자세 저장하고 맞추기 (운영 가이드)

최초 작성 2026-10-26 · 조작(IL) 담당자 작성

## 왜 필요한가
- 모방학습 정책은 **학습 때와 비슷한 시작 자세에서 출발할 때 잘 동작한다.** 시작 자세가 학습 범위 밖이면 제자리 떨림 같은 이상 동작이 나온다(→ [20261016 시작자세 OOD](../experiments/20261016_SmolVLA_제자리떨림_시작자세_OOD_원인규명.md)).
- 그래서 텔레옵으로 맞춘 자세를 파일로 저장해 두고 이렇게 쓴다.
  - **물따르기:** 추론 직전에 그 자세로 이동한 뒤 추론을 시작한다.
  - **컵배치:** 추론과 작업 끝 감지가 모두 끝난 뒤 그 자세로 이동한다(다음 물따르기 준비).

## 1. 자세 저장 (`tools/rollout/save_start_pose.py`)
```
"C:\Users\USER\miniconda3\envs\so101_env\python.exe" tools\rollout\save_start_pose.py --name pour
"C:\Users\USER\miniconda3\envs\so101_env\python.exe" tools\rollout\save_start_pose.py --name place_end
```
- 리더를 움직이면 팔로워가 따라온다. 카메라는 연결하지 않는다.
- 원하는 자세에서 **Enter**를 누르면 팔로워 12관절 측정값이 `config/rollout_poses/<이름>.json`에 저장된다. 여러 번 눌러도 되고, 마지막 저장이 남는다.
- 덮어쓰면 이전 파일은 `<이름>_<시각>.json.bak`으로 백업된다.
- **q + Enter**로 끝낸다. 팔로워는 마지막 자세에서 토크를 유지한다.
- 저장된 자세(2026-10-26):
  - `pour.json`은 차체 결합 데이터 물따르기 60개의 시작 자세 평균과 관절별 차이가 최대 2.3°(왼쪽 wrist_roll)다.
  - `place_end.json`은 왼팔 wrist_flex만 −81.3°로, `pour`(−53.6°)와 다르다.

## 2. 롤아웃에서 사용 (`tools/rollout/rollout_handoff.py`)
| task | 붙일 인자 | 동작 |
|---|---|---|
| 물따르기 | `--start.pose=pour` | 연결 직후, 추론 전에 저장 자세로 이동 → 모든 관절이 ±10° 안이면 추론 시작 |
| 컵배치 | `--end.pose=place_end` (기존 `pour_start` 대신) | 추론과 작업 끝 자동 감지 후(또는 duration 만료 후) 저장 자세로 이동해 유지 |

예시 (나머지 인자는 기존 명령 그대로):
```
... rollout_handoff.py --start.pose=pour --end.pose=final --end.auto=pour ...물따르기 인자...
... rollout_handoff.py --end.pose=place_end --end.auto=place ...컵배치 인자...
```

**안전 동작**
- 이동 시간: max(5초, 가장 많이 움직이는 관절 각도 ÷ 20°/s). 부드러운 가속·감속(smoothstep)으로 보간한다.
  - 조절 인자: `--start.move_s`, `--start.max_speed`, `--end.move_s`
- **그리퍼는 기본으로 건드리지 않는다.** 컵을 쥔 채 시작하거나 끝날 수 있어서다. 그리퍼도 맞추려면 `--start.grippers` / `--end.grippers`를 붙인다.
- 도착 후 0.5초 뒤 저장값과 비교한다(`--start.tol`, 기본 10°). 넘는 관절이 있으면 이렇게 처리한다.
  - **현재 위치를 목표로 고정해 더 밀지 않는다.** 스톨된 서보를 계속 밀면 타기 때문이다.
  - 시작 자세 실패면 추론을 시작하지 않는다. `--end.pose` 설정과 상관없이 팔을 더 움직이지 않는다.
- 기존 `--end.pose=final|pour_start|initial`은 동작이 그대로다.

## 3. 검증 상태
- 가짜 로봇(시뮬레이션 객체)으로 네 경우를 시험해 통과했다.
  - 정상 도착 후 추론 시작
  - 한 관절이 멈춘 경우: 그 자리 고정, 추론 안 함, 끝 자세 이동 생략
  - 저장 끝 자세 이동
  - 그리퍼 미변경
- 이 문서를 쓴 시점까지 실기체 실행 결과는 보고되지 않았다. 처음 실행할 때는 손을 비상정지 가까이에 두고 이동 속도를 확인한다.
