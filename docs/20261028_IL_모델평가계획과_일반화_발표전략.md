# IL 모델 평가 계획과 일반화 발표 전략 (최종발표 준비)

2026-10-28 작성. 차체 결합 데이터로 32개 모델(4개 모델 × 2개 과제 × 데이터 20·40·60·80개) 학습이 끝났다([학습 결과 종합](experiments/20261028_차체결합_32개모델_학습결과_종합.md)).
이 문서는 두 질문에 대한 답과 실행 순서를 담는다.

1. 이 모델들의 성능을 무엇으로, 몇 번씩 재서 최종발표 PPT에 넣을 것인가?
2. 데이터를 모두 같은 위치에서 모았는데, 추가 수집 없이 "일반화"에 대해 무엇을 말할 수 있는가?

이전 계획인 [모델별·데이터 개수별 실험계획](architecture/20260922_모델별_데이터개수별_실험계획.md)의 평가 부분을 이번 32개 모델 기준으로 구체화한다.

## 0. 결론
- **실물 롤아웃 성공률이 주 지표**이고, 오프라인 지표는 보조로 쓴다.
- 32개를 모두 같은 횟수로 돌리지 않는다. 다음 두 단계로 나눈다.
  - A: 데이터 80개 모델 4종 비교
  - B: 1등 모델의 데이터 수별 비교
- 성공/실패 하나가 아니라 **단계별 통과 여부**와 **붓기 정확도(무게)**를 기록한다.
- 일반화는 새로 학습하지 않고 **"얼마나 버티는가"를 측정**한다(위치 이동 OOD 시험). 그리고 "위치 변화는 이동 로봇의 도킹이 흡수한다"는 시스템 설계 논리로 연결한다.

## 1. 무엇을 측정하나

### 1-1. 실물 롤아웃 (주 지표)
심사에서 보는 것은 "로봇이 실제로 해내는가"다. 단계별로 끊어서 기록한다. 성공/실패 하나만 적으면 0%가 많아 모델 간 차이가 보이지 않는다.

**물따르기 5단계**
1. 왼팔 컵 파지
2. 오른팔 병 파지
3. 붓기: 내용물이 컵에 들어갔는가
4. 병 내려놓기: 집은 자리 오른쪽
5. 컵을 차체에 적재하고 유지

**컵배치 3단계**
1. 컵을 쥔 채 테이블로 이동
2. 컵 내려놓기: 넘어지지 않고 세워졌는가
3. 그리퍼를 놓고 팔 빼기

**회차마다 적는 것**

| 항목 | 방법 |
|---|---|
| 단계별 통과(O/X) | 위 단계표. 앞 단계가 실패하면 뒤는 X |
| 진행 점수 | 통과한 단계 수 / 전체 단계 수 (예: 3/5) |
| 붓기 정확도 | 붓기 전 병의 내용물 무게와 컵에 들어간 무게를 주방 저울로 잰다 → 흘린 비율 % (자갈 데이터면 자갈 무게) |
| 완료 시간 | `--end.auto` 자동 종료 시각 또는 영상 기준 |
| 개입 | 사람 개입·비상정지 여부 |
| `failure_code` | **관찰된 증상만**(예: 병 미끄러짐, 컵 앞에서 정지). 원인 추정은 따로 둔다(저장소 규칙) |
| 영상 | 상단 카메라 녹화를 회차 번호와 연결 |

**모델당 한 번 적는 것**
- 추론 지연과 GPU 메모리. "노트북에서 실제로 돌아가는가"는 배치 관점의 비교 항목이다.
- 현재 값([로컬 추론 점검](experiments/20261028_노트북_로컬추론_GR00T_pi0_ACT_점검.md)):

  | 모델 | GPU 메모리 | 추론 1회 | 노트북 실행 |
  |---|---|---|---|
  | GR00T | 6.4GB | 0.46초 | 가능 |
  | ACT | 0.3GB | 0.04초 | 가능 |
  | π0 | 8.9GB 이상 | — | 불가 |

### 1-2. 오프라인 지표 (보조)
- **eval_loss**: 모델마다 손실 정의가 달라 **모델끼리 비교할 수 없다.** 같은 모델의 데이터 수별 경향만 보여 준다.
- **행동 MAE(관절 각도 오차, 도)**: 모델끼리 비교할 수 있는 오프라인 지표다.
  - 같은 시험 에피소드에서 모델이 낸 관절 명령과 사람 시연을 비교한다. 단위가 같아 32개를 한 표에 놓을 수 있다.
  - 현재 학습의 검증 에피소드는 데이터 수마다 다르다. 그래서 **모든 모델이 학습에 쓰지 않은 공통 시험 에피소드를 과제당 5개쯤 새로 녹화**한다. 학습용 재수집이 아니고 10분 정도면 된다.
- **오프라인 지표와 실물 성공률의 관계**를 산점도로 보여 준다.
  - 오프라인 지표가 실물 성공을 잘 예측하지 못하는 경우가 많고, 이는 모방학습에서 알려진 현상(누적 오차, closed-loop 차이)이다. 발표에서 할 이야기가 된다.

## 2. 몇 번 돌리나

| 단계 | 질문 | 대상 | 횟수 |
|---|---|---|---|
| A. 모델 비교 | 어떤 모델이 가장 좋은가 | 데이터 80개 모델 4종(GR00T·π0·SmolVLA·ACT) | 과제당 모델별 10회 |
| B. 데이터 수 효과 | 데이터가 늘면 얼마나 좋아지나 | A의 1등 모델 20·40·60개 (80개는 A 결과 재사용) | 과제당 데이터 수별 5~10회 |

- 합계 약 70~140회다. 1회 2분이면 3~5시간, 이틀이면 끝난다.
- π0는 노트북에서 돌지 않는다. 서버 원격 추론을 준비하지 못하면 A에서 "실행 불가(메모리 8.9GB > 8GB)"로 표기하는 것 자체가 결과다.
- 10회면 성공률 해상도가 10%다. 표에는 **"n=10"을 수치와 같은 줄에** 적는다.
- **조건 고정**: 물체 위치(테이프 표시), 시작 자세(`--start.pose`), 조명, 내용물 양
- **순서 섞기**: 한 모델 10회를 몰아서 돌리지 않는다. GR00T → SmolVLA → ACT → … 순으로 돌아가며 1회씩 한다. 그래야 조명·배터리·서보 온도 변화가 한 모델에 몰리지 않는다.

## 3. 데이터 추가 수집 없이 일반화를 말하는 방법

핵심은 질문을 바꾸는 것이다. "일반화를 시키는 것"이 아니라 "**일반화가 어디까지 되는지 재고 설명하는 것**"이다. 롤아웃만으로 할 수 있다.

### ① 분포 밖(OOD) 위치 시험 — 가장 추천
- 학습 위치에서 컵·병을 0, ±2, ±5, ±10cm 옮겨 가며 성공률을 잰다. 위치당 5회.
- 여유가 되면 다른 모양의 컵, 다른 조명, 옆에 방해 물체도 같은 방식으로 시험한다.
- 결과는 "**학습 위치에서 몇 cm까지 버티는가**" 곡선 하나로 나온다.
- 대상은 A의 1등 모델과 ACT로 충분하다. 비교 축 두 가지:
  - **사전학습 VLA와 처음부터 학습한 ACT**: 대규모 사전학습이 위치 변화에 더 강한가? 지금 로봇 학습 분야의 핵심 질문이다.
  - **같은 위치 데이터 20 → 80개**: 데이터 수만 늘려도 주변 위치에 대한 견고함이 좋아지는가?

### ② 시스템 설계로 위치 변화를 흡수한다는 논리
- 이 프로젝트는 고정 팔이 아니라 이동 로봇(AMMR)이다. 내비게이션이 테이블 앞 같은 자세로 도킹하고, 조작은 시작 자세를 맞춘 뒤 정해진 상대 위치에서 수행한다.
- "**위치 변화는 이동·도킹 단에서 흡수하고, 조작 정책은 좁은 분포에서 정확하게**"라는 모듈 분리는 실제 서빙·물류 로봇이 쓰는 방식이다.
- ①의 결과("±몇 cm까지 버팀")를 "**도킹 정밀도가 그 안에 들어와야 한다**"는 시스템 요구사항으로 연결한다. 내비게이션 파트와 맞물리는 이야기가 된다.

### ③ 이미 있는 실패 분석 활용
- [자갈 시각 의존 causal confusion 기록](experiments/20261021_물따르기_정책_자갈_시각의존_causal_confusion.md): 정책이 자갈의 시각 상태를 붓기 신호로 잘못 학습한 사례다.
- "모델이 무엇을 보고 행동하는가"라는 일반화 실패 분석으로 슬라이드 1장이 된다.
- [SmolVLA 제자리 떨림, 시작 자세 OOD 원인 규명](experiments/20261016_SmolVLA_제자리떨림_시작자세_OOD_원인규명.md)도 같은 맥락의 사례다. 시작 자세가 분포를 벗어나면 정책이 무너진다.

### ④ 시간이 남으면: 소량 적응(few-shot fine-tuning)
- 새 위치 1~2곳에서 각 10개만 녹화하고, 80개 모델에서 이어서 짧게 미세조정해 새 위치 성공률이 얼마나 오르는지 본다.
- "새 위치마다 처음부터 80개가 아니라 10개면 된다"를 보이는 실험이다. 녹화와 학습 시간이 들어 선택 사항이다.

## 4. 실행 순서
1. 과제당 공통 시험 에피소드 5개 녹화 → 32개 모델의 행동 MAE 계산(로봇 불필요)
2. 평가 A: 80개 모델 4종 × 2과제 × 10회
3. 평가 B: 1등 모델 20·40·60개 × 2과제 × 5~10회
4. OOD 위치 시험: 1등 모델과 ACT × 위치 0·±2·±5·±10cm × 5회
5. PPT 정리(5절)
6. (선택) 소량 적응 실험

## 5. PPT에 넣을 것
- 모델 × 단계별 성공률 막대그래프: 어느 단계에서 떨어지는지 보인다.
- 데이터 수 × 성공률 곡선
- 위치 이동 거리 × 성공률 곡선(OOD): VLA와 ACT 비교
- 오프라인 지표(eval_loss·행동 MAE)와 실물 성공률의 산점도
- 모델별 GPU 메모리·추론 지연 표(배치 가능성)
- 성공·실패 대표 영상 각 1개
- causal confusion 분석 1장

## 6. 아직 준비되지 않은 것
- 회차 기록용 평가 시트(CSV 또는 웹 폼)와 그래프 자동 생성 스크립트
- 공통 시험 에피소드로 행동 MAE를 계산하는 스크립트
- π0 서버 원격 추론 경로([로컬 추론 점검](experiments/20261028_노트북_로컬추론_GR00T_pi0_ACT_점검.md) 4절)
