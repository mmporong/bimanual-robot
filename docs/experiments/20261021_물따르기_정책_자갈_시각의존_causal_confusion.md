# 물따르기 정책이 "자갈의 시각 상태"에 의존함 — causal confusion 규명 (실험 기록)

최초 작성 2026-10-21 · 조작(IL) 담당자 작성

## 0. 한 줄 요약

40-ep 핸드오프 SmolVLA 물따르기 모델(best step 8000, eval_loss 0.0812)이 붓기 구간에서
**병을 끝까지 안 기울이고 90° 부근에서 망설이는** 증상의 원인을, 통제된 자연 실험으로
좁혔다. 원인은 데이터 양·시연 일관성·추론 파라미터가 아니라, **정책이 "병 안 빨간
자갈의 시각 상태(있는지·빠지는지)"를 붓기의 트리거·완료 신호로 삼도록 학습된 것**이다.
즉 모방학습의 전형적 실패인 **causal confusion / 지름길 학습**이다. 단, 실제 과제 조건
(뚜껑 열림 + 자갈 → 진짜로 부어짐)에서의 롤아웃은 아직 안 해봐서, 이 의존이 실제
배포에서 "문제"인지 "허용 가능"인지는 미결이다.

> 관련: [`20261016_IL_실제붓기_데이터수집_전환전략.md`](../20261016_IL_실제붓기_데이터수집_전환전략.md)
> (가짜 붓기→실제 자갈 붓기 전환). 이번 발견은 그 "실제 붓기" 데이터로 학습한 모델이
> **자갈 그 자체를 시각 단서로 붙잡았다**는 후속 관찰이다.

## 1. 증상과 통제 실험 (근거)

실물 롤아웃을 **부어지는 조건을 바꿔가며** 관찰했다. 세 조건의 결과가 원인을 가른다:

| # | 조건 | 모델 행동 | 자갈-시각의존 가설로 설명 |
|---|---|---|---|
| A | 뚜껑 열림 + **자갈 있음** (=학습 조건) | *아직 롤아웃 미실시* | (예측) 자갈이 움직이는 시각 신호 → 끝까지 기울여 완수 |
| B | 뚜껑 **닫힘** + 자갈 있음 | **90°까지만 기울이고 그 부근에서 기울였다 올렸다 반복** | 자갈이 물리적으로 **못 빠짐** → "아직 다 안 부어졌다"는 시각 확인을 계속 기다리며 90°에서 **무한 루프** |
| C | 뚜껑 열림 + **빈 병** | **붓기 행동 생략, 바로 병 반납** | 부을 자갈이 **안 보임** → "부을 게 없다" → 붓기 시퀀스 자체를 건너뜀 |

- **B(닫힌 루프 대기)**: 병은 물리적으로 더 기울 수 있는데도 90°에서 멈춰 미세하게
  왕복한다. 고정 자세까지 가는 정책이라면 뚜껑 유무와 무관하게 끝까지 기울였을 것이다.
  그러지 않았다 → "자갈이 빠졌다"는 감각 신호를 기다리는 **닫힌 루프**임을 시사.
- **C(트리거 부재)**: 추론 파라미터(`max_relative_target`·청킹)로는 **설명 불가**한
  결과다. 오직 "자갈이 보여야 붓기를 시작한다"는 트리거 의존으로만 설명된다. 이게
  가설의 가장 강한 증거다.

## 2. 가설 — 정책이 자갈의 시각 피드백에 의존

학습 시연에서 사람은 **자갈이 컵으로 다 빠질 때까지** 병을 기울였고, 그 과정에서
자갈이 병의 투명한 윗부분으로 이동하는 것이 손목캠·top캠에 보였다. 정책은 "병을
어디까지·언제까지 기울일지"를 **자갈의 시각 상태에 조건화**해 학습했다:
- 자갈이 보이고 움직임 → "붓는 중, 계속 기울여"
- 자갈이 다 빠짐 → "완료, 다음 동작"
- 자갈이 없음 → "부을 것 없음, 생략"

이 신호가 끊기거나(빈 병) 영원히 충족 안 되면(뚜껑) 위 B·C처럼 깨진다.

## 3. 이게 왜 causal confusion인가

모방학습 정책은 **과제 구조(병을 기울여 따른다)**가 아니라, 시연에서 그와 **상관**된
손쉬운 시각 특징(자갈의 모양·이동)을 지름길로 붙잡을 수 있다. 자갈은 붓기와 거의
완벽히 상관돼 있어 학습 중엔 구분되지 않지만, 상관을 깨는 OOD 조건(뚜껑/빈 병)에서
정책의 실제 의존 대상이 드러난다. 센서가 카메라뿐이므로 이 의존은 **시각적**이다.

## 4. 진단이 세 번 바뀐 경위 (방법론 교훈, 정직 기록)

1. **1차(틀림)**: "붓기 시연이 제각각이라 모델이 애매하게 수렴" — 근거로 `wrist_flex`
   전체범위 std 10.9°를 들었다. **오류**: 그 수치는 에피소드 전체(집기·이동·붓기·컵쥐기)를
   섞은 값이라 붓기만 분리하지 못했고, 어느 관절이 병을 눕히는지도 확인 안 했다.
2. **2차(교정)**: 붓기 절정(peak `wrist_roll`≈157°, 전 에피소드 std 3.8°로 매우 일관)
   순간의 top캠 프레임(ep5·14·16·32)을 직접 보니 **네 에피소드 모두 병을 컵 위로 거의
   뒤집어 따르고 있었다** → 시연은 일관됨. 1차 진단 철회.
3. **3차(확정 방향)**: 수집자의 통제 실험(위 A/B/C)으로 **자갈 시각의존**이 드러났다.

> 교훈: **전체범위 통계로 특정 구간을 단정하지 말 것.** 또한 로봇 IL에서 "왜 못하나"는
> 시연 영상과 **조건을 바꾼 통제 실험**으로 가르는 게 관절 통계보다 훨씬 강하다.

## 5. 아직 모르는 것 — 결정적 테스트가 공백

**조건 A(뚜껑 열림 + 자갈, = 학습 조건)의 롤아웃을 아직 안 했다.** 이게 갈림길이다:
- A에서 **끝까지 잘 부으면** → 모델은 의도한 과제엔 작동하는 것이고, B·C 실패는
  학습에서 본 적 없는 OOD라 신경 쓸 필요 없다. 자갈 피드백 사용은 사람도 하는 자연스런
  행동이다.
- A에서도 **90°에서 멈추면** → 자갈 신호가 불충분하거나(자갈량·조명·배치 차이) 더
  깊은 문제이며, 그때 본격적으로 손봐야 한다.

## 6. 함의와 선택지

- **이게 "결함"인지는 배포 조건에 달렸다.** 실제 과제가 항상 "뚜껑 열림 + 부어지는
  자갈"이면, 자갈 의존은 허용 가능할 수 있다.
- **자갈 상태와 무관하게 강건하게** 하려면(더 어려운 표현학습 문제):
  - 학습 데이터에 자갈 조건을 **다양화**(양·색·때론 없음)해 정책이 자갈 하나에 못
    매달리게 한다. 단 과제 정의가 바뀐다.
  - 붓기를 "자갈 빠질 때까지"가 아니라 **정해진 자세까지** 가도록 시연을 바꾼다(사람이
    시각 피드백을 안 쓰고 고정 각도로 붓기).
- **데이터 양 추가는 해법이 아니다** — 같은 자갈 상관을 더 쌓을 뿐이다.
