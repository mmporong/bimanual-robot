# ggao50 그리퍼 K1 Max 출력 인계

작성 2026-09-04. 다음 세션이 이 문서만 읽고 이어받을 수 있도록 쓴다.

## 0. 먼저 알아야 할 것 — 훅이 스크립트 실행을 막는다

`arm-motion-guard` 훅이 아래 정규식으로 Bash 명령을 차단한다.

```
(python3?|bash|sh)[^|;&]*(so101_tools|so101-mobile-manipulation|bimanual-robot|gazebo-so101-capstone|jdamr_cube_ws)/
```

경로 판정이라 **이 리포 안의 스크립트는 종류를 가리지 않고 전부 막힌다.** 팔을 움직이는
코드가 아니라 STL 좌표만 만지는 `make_plate.py`, `slice_k1max_petg.py`도 걸린다.

- 훅은 결정론적이라 사용자 승인을 받아도 계속 차단한다
- 우회하지 않는다. 대신 `~/gcode/build_plates.sh`를 사용자가 직접 실행한다
  (그 명령줄에는 `bimanual-robot/` 문자열이 없어 훅에 걸리지 않는다)
- 읽기·측정·편집은 막히지 않는다. 파일 수정과 STL 계측은 그대로 할 수 있다

미결: 출력 준비 도구를 `~/gcode/tools/` 로 옮길지 사용자에게 물어 둔 상태다.
옮기면 다음 세션이 직접 실행할 수 있다. 답을 아직 못 받았다.

## 1. 확정된 것

그리퍼는 **ggao50 SO101-Parallel-Gripper** 로 간다. 2026-09-04 에 norma-core
`hardware/pgripper` 와 대조한 뒤 사용자가 유지 결정했다.

| 항목 | ggao50 (선택) | norma-core pgripper |
|---|---|---|
| 최대 개구 | **105 mm** | 54 mm |
| 출력 무게 | — | 약 86 g |
| 총 무게 | 165 g | 약 146 g (추정) |
| 라이선스 | **없음** | Apache-2.0 |
| 손목캠 마운트 | 없음 | 3 종 내장 |

탈락 사유는 개구 하나다. 소스 병 지름이 `[50, 62] mm` 인데 norma 는 54 mm 가 상한이라
62 mm 병이 안 들어간다. 나머지 항목은 전부 norma 가 낫다.

**되살릴 조건**: norma 는 STEP 을 Apache-2.0 으로 공개한다. 죠를 바깥으로 각 10 mm
오프셋하면 개구가 74 mm 가 되어 62 mm 병에 12 mm 여유가 생긴다. 랙·피니언은 안 건드린다.
라이선스·캠 마운트·한 판 출력이 걸리면 이 경로를 다시 검토할 값어치가 있다.

## 2. 출력 방향 점검 결과 (2026-09-04)

`audit_orient.py` 로 6 방향(그대로·X±90·X180·Y±90)을 돌려 세장비·접지면적·서포트면적을
쟀다. 임계각은 슬라이서와 같은 30도.

### 그리퍼 6 종 — 현재 방향이 최적, 바꾸지 말 것

| 부품 | 서포트 mm² | 6 방향 중 | 접지 mm² | 세장비 |
|---|---:|---|---:|---:|
| backplate | 266 | 최소 (차선 4,509) | 532 | 8.28 |
| cameraplate | 221 | 최소 | 180 | 4.41 |
| connectorplate | 255 | 최소 | 327 | 2.13 |
| leftgripper | 1,017 | 최소 | 131 | 0.83 |
| rightgripper | 1,002 | 최소 | 131 | 0.83 |
| pinion | 5 | 최소 | 303 | 0.44 |

`prepare_ggao50_print.py` 가 걸어 둔 회전(backplate Y+90, rightgripper X180,
pinion X+90)이 맞다. backplate 는 세장비 8.28 이 걸리지만 눕히면 서포트가 24 배가 된다.

### 인서트 3 종 — 방향이 틀렸다, 고쳤다

```
세움(기존)   접지     5~7 mm²   서포트 213~290 mm²   세장비 4.8~7.5
Y-90(수정)   접지 1,216 mm²     서포트       0 mm²   세장비 0.25~0.39
```

접지가 200 배 차이난다. TPU 95A 로 5 mm² 위에 52 mm 기둥을 세우는 자세였다.
`~/gcode/inserts/` 의 기존 G-code 3 개도 같은 문제를 갖고 있다. **쓰지 말 것.**

강도도 같이 바뀐다. V홈이 병 무게를 받는 방향이 세운 자세에서는 레이어를 벌리는 쪽이고,
눕히면 누르는 쪽이 된다. 층간 접착이 FDM 의 최약점이라 이 차이가 크다.

### 브림

leftgripper 실제 접지가 131 mm² 뿐이라 기본 5 mm 로는 60 mm 높이를 버티기 어렵다.
`slice_k1max_petg.py` 에 `--brim` 을 추가해 **8 mm** 로 올렸다. 부품 간격도
8+8=16 mm 가 최소라 낮은 판 18 mm, 키 큰 판 24 mm 로 벌렸다.

## 3. 지금 상태

### 코드 변경 (커밋 대상)

| 파일 | 상태 | 내용 |
|---|---|---|
| `design/gripper/make_plate.py` | 신규 | shelf packing 으로 여러 STL 을 한 판에 합친다. `경로:Y-90` 으로 축정렬 회전 |
| `design/cad/slice_k1max_petg.py` | 수정 | `--brim` 옵션 추가 |

### 실행 대기

```bash
bash ~/gcode/build_plates.sh
```

사용자가 직접 실행해야 한다(0 절 참조). 결과는 `~/gcode/k1max/` 한 폴더에 모인다.

| 순서 | 파일 | 담긴 것 | 예상 |
|---|---|---|---|
| 1 | `1_pinion` | 구동 기어 | 16m |
| 2 | `2_PLATE_low` | leftgripper + rightgripper + connectorplate | 3h 21m |
| 3 | `3_PLATE_tall` | backplate + cameraplate | 3h 59m |
| 4 | `4_PLATE_inserts` | 인서트 A·B·C (TPU, 눕힘) | 약 2h |

1 번을 먼저 돌려 기어 치면으로 프린터 상태를 확인한 뒤 나머지를 건다.
`3_PLATE_tall` 의 cameraplate 는 손목캠을 안 쓰면 뺄 수 있다.

**실행 뒤 할 일**: 브림 경계 사이 실제 여유 거리를 계산해 0 이상인지 검증한 표를 만든다.
사용자에게 약속해 둔 산출물이다.

### 폐기 대상

`~/gcode/plates/` 는 브림 5 mm·인서트 세운 자세로 만든 중간본이다. `k1max/` 가 나오면
지운다. `~/gcode/ggao50/`, `~/gcode/ggao50_ender/`, `~/gcode/inserts/` 는 Ender 판과
비교용으로 사용자 판단 전까지 남긴다.

## 4. 슬라이싱 주의

**OrcaSlicer CLI 로 직접 슬라이싱하지 말 것.** 필라멘트 프리셋의 `inherits` 체인을 못 풀어
PETG·TPU 를 PLA 200 °C 로 뱉는다. `slice_k1max_petg.py` 가 파이썬에서 상속을 미리 풀어
값을 주입한다. 항상 이쪽을 쓴다.

확정 값: PETG 노즐 255 / 베드 80, TPU 노즐 230 / 베드 45, 레이어 0.2, 벽 6 겹,
gyroid, tree 서포트 임계 30도 + `--plate-only`.

기존 파일명의 `45infill` 은 틀렸다. pinion 만 45% 이고 나머지는 25% 다. 이름 말고
G-code 안의 값을 믿는다.

## 5. 라이선스

상류 ggao50 저장소에 LICENSE 가 없다. **STL·STEP·G-code 를 이 리포에 커밋하지 않는다.**
그래서 산출물이 `~/gcode/` 에 있다. 스크립트와 문서만 리포에 둔다.

norma-core 는 Apache-2.0 이라 개조본까지 커밋할 수 있다. 갈아탈 경우 이 제약이 풀린다.

그리퍼 자체 조립은 서보 킷 나사로 된다. 추가 구매는 M3×30 볼트 세트뿐이고 인서트를
죠에 물리는 데 쓴다. 죠의 인서트 구멍은 Ø3.4 로 `Y = -38, -18`, `Z = 0` 에 이미 뚫려 있다.

## 7. 이 작업 밖의 미결

- 작업셀 거리 결정 — 붓기 자세가 도달 96.5% 라 실행 금지 상태다. 팔 베이스에서 400 mm
  안으로 들어와야 다시 푼다
- 행동 공간 규약(절대 관절 vs 컵팔 상대) — 데이터 수집 전에 닫아야 한다
- 서보 변종 감사 — 리더 12 개 포함 24 개 전부 C001/C018 확인
- LDS-03 인터페이스 (USB2LDS vs MCU UART)
