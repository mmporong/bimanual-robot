## 2. 아직 안 정해진 것 (금요일 16:00 재논의 대상)

- **2차 태스크**: 음성 명령 제어가 유력하다(구현 난이도 대비 데모 효과). 좁은 공간 픽앤플레이스는 "문제를 미리 가정하지 말자"는 합의에 따라 후순위로 밀렸다.
- **에이전틱 태스크 분해(VLM/LLM)** 채택 여부: 3개월 안에 소화 가능한지가 쟁점이다. 연산은 API 방식(서버 처리)으로 해결되므로 라즈베리파이 성능은 제약이 아니다.
- **학습 모델**: SmolVLA / ACT 등 경량 모델이 후보다. 파인튜닝에 VRAM 20GB 이상이 필요해 클라우드 학습 후 가중치만 내려받는 방식을 검토 중이며, 비용 확인이 선행 조건이다.
- **월드 모델(NVIDIA Cosmos)**: A100급 요구와 디퓨전 추론 속도 때문에 현실성이 낮다. 학교 자원 협조가 되지 않으면 제외한다.
- **IK vs 이미테이션**: 둘 다 적용 가능하게 만들고 잘 되는 쪽을 채택한다. 판정 기준을 아직 정하지 않았다 (내 담당 파트의 첫 과제).

## 5. 회의에서 나온 것 중 내가 따로 잡아둘 쟁점

**양팔 동시 텔레옵이 이 프로젝트의 첫 미검증 지점이다.** 한 팔 리더-팔로워 구성은 익숙하지만 양팔 동시는 팀 내에 검증 경험이 없다. 회의에서 나온 접근안은 팔별로 캘리브레이션한 뒤 리더 없이 팔로워 기준으로 각각 구성하는 방식이다. 데이터 수집 전체가 여기에 걸려 있으므로 리서치 A2를 최우선으로 둔다.

**"잘 잡는 것"의 정의가 아직 없다.** IK와 이미테이션 중 잘 되는 쪽을 채택하기로 했는데, 채택 기준이 없으면 비교 자체가 성립하지 않는다. 픽앤플레이스 기준선(A4)을 성공률·조건·반복 횟수까지 포함해 먼저 정의한다.
