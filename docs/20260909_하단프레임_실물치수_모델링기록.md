# 하단 프레임 실물 치수와 모델링 기록

갱신: 2026-09-09. 상태: 사용자 설명 수집 중, CAD·URDF 반영 전.

이 문서는 조립된 실물에 대한 사용자의 확인을 누적한다. 이후 구성 설명은 이 문서에
추가한다. 하단 프레임에 대해서는 이전 300×300 mm 모델보다 이 기록이 우선한다.
기존 YAML·URDF는 아직 이전 모델이며, 이 기록을 반영한 모델로 간주하지 않는다.
상부 구조·팔·센서 배치는 이번 대화에서 다시 확정되지 않았다.

상부 구조는 [상승 프레임 경량화·구조 검토](20260909_상승프레임_경량화_구조검토.md)에
1차 후보·리서치·계산·이미지를 기록했다. 사용자 확정 실물 치수와 구분되는 제안이다.

## 1. 사용자 확인 치수

단위는 mm. 높이는 바퀴와 볼캐스터가 바닥에서 차체를 받치는 조립 상태 기준이다.

| 항목 | 확정 내용 |
|---|---|
| 프레임 외곽 | 좌우 450 × 전후 340 |
| 알루미늄 프로파일 단면 | 20 × 20 |
| 프레임 윗면 높이 | 바닥에서 60 |
| 가로재 | 앞·뒤 각 1개, 가장 긴 부재 |
| 세로재 | 외측 2개 + 내부 2개, 모두 같은 길이 |
| 내부 세로재 위치 | 좌우 외곽 끝에서 각각 안쪽으로 155~175 구간 |
| 프레임 연결 브래킷 | ㄴ자 8개, 세로재 양 끝과 가로재 연결부에 각 1개 |
| 구동 바퀴 | 앞쪽 좌우 2개, 지름 70, 프레임 좌우 바깥으로 돌출 |
| 바퀴 외측 면까지의 거리 | 좌우 방향에서 프레임 외측 면부터 바퀴 가장 바깥 면까지 45, 양쪽 동일 기준 |
| 바퀴 축의 전후 위치 | 프레임 앞 끝에서 뒤로 60 |
| 볼캐스터 | 뒤쪽에만 2개, 뒤 끝에서 앞으로 중심까지 60 |
| 캐스터의 좌우 위치 | 외측 세로 프로파일 아래 같은 라인, 프레임 밖으로 돌출되지 않음. 앞바퀴와 중심선이 같다는 이전 기록은 취소 |
| 구동 서보 | JDAMR에 포함된 것과 동일한 FEETECH STS3215, 사용자 설명상 12V |

ㄴ자 브래킷 8개는 프로파일끼리의 연결 부품이다. 이를 바퀴 장착 브래킷으로
해석하지 않는다. 바퀴는 모터를 통해 차체에 연결된 상태다.

| 항목 | 계산 | 결과 |
|---|---|---|

| 세로재 길이 | 340 − 앞 가로재 20 − 뒤 가로재 20 | 300, 4개 |
| 프레임 아랫면 높이 | 60 − 20 | 40 |
| 바퀴 반지름·축 높이 | 70 / 2, 평평한 바닥·타이어 변형 무시 | 35 |
| 축과 프레임 아랫면 높이 차이 | 40 − 35 | 5（연결 틈을 뜻하지 않음） |

## 3. 모델링 좌표 기준

이 절의 좌표는 실물 치수를 표현하기 위한 정의이며 기존 URDF 좌표를 변경한 것은 아니다.
차체 평면 중심을 원점으로 하고 x는 앞, y는 왼쪽, z는 위로 정한다. z=0은 바닥이다.

| 부품 | x 범위 또는 중심 | y 범위 또는 중심 | z 범위 또는 중심 |
|---|---|---|---|
| 앞 가로재 | 150~170 | −225~225 | 40~60 |
| 뒤 가로재 | −170~−150 | −225~225 | 40~60 |
| 왼쪽 외측 세로재 | −150~150 | 205~225 | 40~60 |
| 오른쪽 외측 세로재 | −150~150 | −225~−205 | 40~60 |
| 왼쪽 내부 세로재 | −150~150 | 50~70 | 40~60 |
| 오른쪽 내부 세로재 | −150~150 | −70~−50 | 40~60 |
| 앞바퀴 축 중심 | 110 | 좌우 값 미정 | 35 (계산값) |
| 바퀴 최외측 면 | 바퀴 형상에 따름 | 왼쪽 +270, 오른쪽 −270 | 바퀴 형상에 따름 |
| 뒤 볼캐스터 중심의 평면 위치 | −110 | 외측 세로재 아래. 세로재 중심선 기준 배치 시 ±215, 정확한 장착 오프셋은 미정 | 미정 |

45는 바퀴 폭 자체나 바퀴와 프레임 사이 빈 간격이 아니라, 프레임 외측 면에서
바퀴 최외측 면까지의 거리다. 전체 폭 540과 바퀴 중심 간 거리를 혼동하지 않는다.
좌우 바퀴 폭이 동일하게 w라면 중심 간 거리는 540 − w로 계산되지만 w는 아직 미정이다.
볼캐스터는 바퀴 중심선에 맞추지 않고 외측 세로재 아래에 배치한다.

## 4. 부품 근거와 미정 사항

- 구동 서보 STS3215는 로컬 JDAMR 기록
  `~/jdamr_cube_ws/src/jdamr_cube_ros/IMU_DEBUG_HANDOFF_20260825.md`의
  「하드웨어 식별」에 명시되어 있다. 사용자가 동일 부품이라고 확인했다.
- 12V는 사용자 설명이다. 세부 품번·감속비·토크·외형 치수는 이번 확인으로 확정되지 않았다.
- 바퀴 돌출량은 한쪽 45로 확인했다. 바퀴 폭, 좌우 바퀴 중심 간 거리, 허브 및 모터
  장착 방향·고정 형상은 미정이다.
- 볼캐스터 제품·크기·장착 높이·고정 형상은 미정이다.
- ㄴ자 브래킷의 크기·두께·체결 구멍과 프로파일 상세 단면·질량은 미정이다.
- 실측 질량·관성·마찰·서보 응답은 확보되지 않았다. 이 치수 기록만으로 sim-to-real
  검증이 완료되었다고 표현하지 않는다.

## 5. 이미지 오류 기록

대화에서 생성된 이미지는 치수 기반 CAD가 아니다. 첫 이미지에는 캐스터 수·위치 오류,
두 번째에는 바퀴가 앞 가로재에 연결된 듯한 배치 오류가 있었다. 후속 상면도 역시
정밀 치수·장착 형상 검증을 거치지 않았다. 생성 이미지를 제작·URDF의 원본으로 사용하지 않는다.
모델링은 1~3절의 확정 치수와 좌표를 기준으로 한다.
마지막 생성 상면도도 캐스터 중심이 뒤 끝에서 60인 기준선보다 뒤로 그려져 있으므로
위치 측정에 사용하지 않는다. 대화 답변 중 중앙 빈 폭을 140이라고 쓴 것은 오류이며,
확정값은 100이다.

### 2026-09-09 추가·정정 이력

- 캐스터 좌우 위치: 앞바퀴와 동일 중심선 → 외측 세로 프로파일 아래, 외부 돌출 없음.
- 바퀴 돌출량: 미정 → 프레임 외측 면부터 바퀴 최외측 면까지 한쪽 45.
- 바퀴 포함 전체 폭: 미정 → 좌우 동일 돌출량 기준 540.
- 캐스터 전후 위치는 변경 없음: 뒤 끝에서 중심까지 60.

## 6. 추가 설명을 이어가는 방법

사용자가 부품이나 치수를 추가하면 1절에 확정 사실, 2절에 계산값, 3절에 위치를 반영하고
4절에서 해결된 미정 항목을 갱신한다. 기존 치수를 수정하면 변경 전후와 확인 날짜를 남긴다.
미정 장착부를 임시 형상으로 만들 경우 가정임을 표시한다. CAD·YAML·URDF 변경 후에는
해당 파일과 실행 검증 결과를 이 문서에 연결한다.
