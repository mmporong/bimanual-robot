# 상승 프레임 1차 검토 — 폐기 기록

이 문서의 300×300 mm 상판과 후보 구조는 2026-09-10 설계 변경으로 폐기했다. 현재 제작·CAD·URDF 기준으로 사용하지 않는다.

현행 기준은 [450×340 mm 4분할 상판 양팔 로봇 모델](20260910_450x340_4분할상판_URDF_IsaacSim_모델.md)이다.

폐기 사유:

- 상부 프레임을 하부와 같은 450×340 mm 외곽으로 변경했다.
- 수직 기둥은 2020 후보 4개로 확정했다.
- 한 장 상판 대신 K1 Max에서 출력 가능한 4분할 6 mm PETG 판을 사용한다.
- 배터리와 LDS-03도 별도 출력 장착판으로 바꿨다.
- SO-101 두 대의 중심은 전면에서 150 mm로 다시 정의했다.

이전 계산과 이미지는 Git 이력에서만 확인한다. 명목 질량·COM·출력물·Isaac Sim 검증은 현행 문서와 `design/mechanical/hold_flow_mechanical_v0_3.yaml`을 따른다.
