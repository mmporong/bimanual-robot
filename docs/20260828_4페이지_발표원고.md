# 양팔 로봇 프로젝트 — 4페이지 발표 원고

> 상태: 이 원고는 두 후보를 비교하던 발표 초안이다. 물 따르기 Plan A 확정 이후에는 [20260828_HANDOVER_양팔로봇_5페이지_발표자료.pptx](20260828_HANDOVER_양팔로봇_5페이지_발표자료.pptx)를 사용한다.

## 1쪽 · 회의 결과

### 제목

이동하고, 양팔로 작업하고, 실패를 복구하는 로봇

### 핵심 문장

봉지 열어 담기와 비정형 용기 붓기를 함께 기초검증한 뒤 9월 중순 실물 게이트에서 메인 시나리오를 고른다.

### 발표 메모

- 팀은 강사/멘토 1명과 학습자 2명으로 진행한다.
- SO-101 한 대의 한계를 소프트웨어만으로 극복하지 않는다.
- VLA는 중심에서 빼고 SLAM, IK, ACT, Depth, 센서 같은 검증 가능한 기술을 적극적으로 결합한다.
- 로컬 LLM은 모터가 아니라 실패 상태와 스킬 재실행을 관리한다.

## 2쪽 · 두 가지 시나리오

### Plan A

**이동형 비정형 용기 붓기**

- SLAM으로 작업대 접근
- 한 팔이 총중량 300g 이하 용기 파지
- 다른 팔이 컵을 들거나 안정화
- 접촉 센서로 미끄럼·파지 상태 확인
- 비드·쌀로 안전하게 시작

### Plan B

**봉지 열기·물체 담기**

- 양팔로 봉지 입구 개방
- 한 팔 유지, 다른 팔 물체 투입
- 미개방·찢어짐·미삽입을 자동 판정
- 평행 그리퍼와 진공+평행 조합 비교

### 발표 메모

Plan A는 SLAM부터 양팔 ACT까지 전체 시스템을 보여주는 데 강하다. Plan B는 실패 상태가 뚜렷해 에이전틱 복구를 보여주는 데 강하다.

## 3쪽 · 기술 구조와 그리퍼

### 구조

`로컬 LLM 감독 → FSM/스킬 → SLAM·정렬·ACT/IK·검증 → 하드웨어`

### 안전 경계

LLM은 `재파지`, `재관측`, `다음 물체`, `안전 중단` 같은 허용 행동만 선택한다. 좌표·토크·모터 명령을 직접 생성하지 않는다.

### 그리퍼

- 물병: 평행 그리퍼 2개 + V-groove/TPU 패드 + 저가 접촉 센서
- 봉지: 평행 2개와 진공 1개+평행 1개를 POC에서 비교
- 공통: 손목 퀵스왑 마운트로 교체 가능하게 설계

### 발표 메모

Depth는 새 시나리오가 아니라 작업대 최종 정렬과 성공 판정을 보완한다. 접촉 센서는 처음부터 학습 입력으로 복잡하게 넣기보다 안전 인터록과 성공 판정부터 쓴다.

## 4쪽 · 역할과 일정

### 역할

- 강사/멘토: 로컬 LLM·감독 에이전트, 교육과 리뷰
- 사용자: SLAM/Nav2 우선, 모바일 베이스·작업대 접근, 통합 참여
- 다른 팀원: 세부 전담은 다음 회의에서 확정
- 공통 학습: ACT, IK, Depth, 실물 데이터 수집과 평가

### 일정

1. 지금~9월 중순: 두 시나리오 실물 POC와 공통 기반 학습
2. 9월 중순 전후: 성공률·하드웨어 위험으로 메인 시나리오 결정
3. 이후: 그리퍼·접촉 센서·SLAM·ACT·로컬 LLM 통합
4. 1차 테스트 → 보완 → 최종 반복 시험·영상

### 최종 문장

포트폴리오 메인은 이동형 비정형 용기 붓기, 병행 기술 데모는 봉지 열기·에이전틱 실패 복구로 제안한다.
