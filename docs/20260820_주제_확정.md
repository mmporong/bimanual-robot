## 주제

# 데스크톱 와이어 하네스 조립 셀

**전선을 집어 지정 경로에 배치하고 클립에 끼우는 양팔 로봇.**
자동차 전장 조립의 하네스 작업을 테이블탑 규모로 축소한다.

**연구 질문**: 저비용 양팔 플랫폼에서 **데이터를 얼마나, 어떻게 다양하게 모아야** 케이블 라우팅이 되는가.

---

## 왜 이것으로 정했나

지금까지 검토한 후보 20여 개 중 **모든 제약을 동시에 통과하는 유일한 후보**다.

| 제약 | 케이블 라우팅 | 탈락한 후보들 |
|---|---|---|
| **자유도 5축** | 통과 — 동작이 단순하다 | 신발끈·넥타이·리본 매듭 **탈락**(다단계 매듭에 손목 자유도 부족) |
| **페이로드 수백 g** | 통과 — 케이블 수십 g | 박스 적재·셔츠 걸기 **탈락** |
| **회전 토크 전달 취약** | 통과 — 회전이 필요 없다 | 용기 뚜껑 개폐 **탈락**(그리퍼 마찰로 1 N·m 전달 불가) |
| **그리퍼 닫힘 15초** | 통과 — 얇아서 완전 폐쇄 불필요 | 개폐가 잦은 태스크 불리 |
| **백래시** | 통과 — 유연물이 오차를 흡수 | peg-insertion 단독은 공차 설계 필요 |
| **양팔 필수성** | 통과 — **안정화 팔이 장력을 놓으면 형상이 즉시 무너진다** | 픽앤플레이스·진열·테이블세팅 **탈락**(B0) |
| **학습 필수성** | 통과 — 형상이 예측 불가, **고혼합 환경의 재프로그래밍이 업계가 지적하는 병목** | 뚜껑·스냅핏·커넥터 단독 **탈락**(규칙으로 풀림) |
| **산업 근거** | 통과 — **하네스 조립의 약 90%가 수작업** | — |
| **데이터 규모** | 통과 — 조건 다양성이 어려움의 원천이라 수천 시연이 그대로 성능이 된다 | ALOHA Unleashed급 태스크는 26,000 시연 필요 |
| **평가 가능성** | 통과 — 클립 삽입은 이진 판정, 경로 이탈은 mm 측정 | 닦기·검수 등은 판정 애매 |

**핵심 논리 한 줄**: 자유도로 막힌 태스크는 데이터를 아무리 모아도 안 되고, 조건 다양성이 어려움인 태스크는 데이터로 풀린다. 우리는 후자만 할 수 있고, 그중 산업 근거가 가장 강한 것이 케이블이다.

## 두 얼굴을 갖는다

같은 산출물을 청중에 따라 다르게 부른다. 기술은 하나다.

| 청중 | 부르는 이름 | 첫 문장 |
|---|---|---|
| 발표장·대중 | **엉킨 전선을 정리하는 로봇** | "가방에서 이어폰 꺼내면 항상 엉켜 있죠" |
| 면접·이력서 | **와이어 하네스 조립 자동화** | "자동차 전장 조립은 지금도 90%가 수작업입니다" |

## 시스템

```
[인식]   RGB-D → 케이블 위치·경로·클립 위치
   ↓
[조정]   arbiter — 구간별로 IK 경로와 IL 정책을 전환
   ├ IK  : 접근·이송 (규칙으로 충분)
   └ IL  : 파지·장력 유지·클립 삽입 (규칙으로 불가)
   ↓
[실행]   양팔 제어 + 안전 래퍼(스톨 감지·도달 검사·토크 한계)
   ↓
[판정]   실물 관측 기반 성공 판정, 실패 유형 분류, 메타데이터 기록
   ↓
[개선]   HIL 개입 수집 → 재학습 → 재평가
```

## 측정 — 이 프로젝트의 산출물

**주장은 태스크 성공이 아니라 스케일링 곡선이다.**

### 주 실험

| 축 | 값 |
|---|---|
| 데이터량 | 50 · 200 · 500 · 1,000 · 2,000 |
| 다양성 | 케이블 1종 / 3종 / 5종 |
| 방법 | scratch ACT / π₀·SmolVLA 파인튜닝 |
| 평가 | **학습에 없던 케이블·배치**에서의 성공률 |

**답할 질문 셋**
1. 조건 고정 시 60회로 80%(ACT 기준). **다양화하면 몇 배가 필요한가?**
2. 사전학습 파인튜닝은 곡선을 얼마나 왼쪽으로 옮기는가?
3. **같은 조건을 더 찍는 것과 다양성을 늘리는 것 중 무엇이 더 기여하는가?**

### 대조군 (수치 신뢰도)

- **단팔 대조군** — 한 팔로 시도. 장력을 못 걸어 무너질 것. 양팔 필수성의 실측
- **귀무 정책** — 관측 무시하고 평균 궤적 재생. 지표가 뭔가를 재고 있음을 증명
- **HIL 재학습 전후** — 개입 데이터 추가 전/후

### 실패 유형

| 코드 | 유형 |
|---|---|
| F1 | 파지 실패 (못 집음 / 여러 가닥 딸려옴) |
| **F2** | **장력 실패 — 안정화 팔이 놓쳐 형상 붕괴** |
| F3 | 클립 삽입 실패 |
| F4 | 경로 이탈 |
| F5 | 도달 실패 |

## 백업안

1번(케이블 파지)이 실패하면 **보호필름 박리**로 전환한다. 테솔로(국내, R4 공고 실측)가 DG-4F 그리퍼로 푸는 문제이고, 양팔 근거(안정화 팔이 제품을 눌러 고정)와 판정 명확성(벗겨짐·찢어짐 이진)을 갖췄다. 다만 얇은 필름 모서리 파지가 같은 종류의 리스크다.
