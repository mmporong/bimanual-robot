# HOLD THE FLOW 기구설계 검증 체크리스트 v0.1

> 기준 명세: [기구설계·제작 명세 v0.1](20260901_기구설계_제작명세_v0.1.md)  
> 목적: CAD를 그리기 전에 측정할 것과, 출력 후 조립·동작에서 반드시 증명할 것을 분리한다.

체크박스는 실제 증거 파일이 있을 때만 완료 처리한다. 렌더, 시뮬레이션 화면, 육안상 가능해 보인다는 판단은 실기체 통과 증거가 아니다.

## M0. 부품 실측

- [ ] SO-101 베이스 두 대의 실제 외곽 치수 측정
- [ ] SO-101 베이스 체결 구멍 중심 좌표와 나사 규격 측정
- [ ] 좌우 follower의 12개 서보 라벨을 촬영하고 C001/C018 모델·정격전압 기록
- [ ] 좌우 팔 무게를 그리퍼 포함·제외로 각각 측정
- [ ] Astra S 본체 외곽과 하부 M6 위치 측정
- [ ] Astra S USB 케이블 최소 굽힘 반경 측정
- [ ] 평행그리퍼 완성 질량과 손목축 기준 무게중심 측정
- [ ] 배터리·SBC·모터 드라이버·모터 후보 외피 측정
- [ ] LiDAR 모델 확정과 외피·스캔 평면 높이 측정

기록 파일:

```text
docs/evidence/mechanical/M0_component_measurements.csv
docs/evidence/mechanical/M0_component_photos/
```

통과 조건: 모든 체결 구멍은 실측값과 CAD 투영값의 차이가 0.5 mm 이하다.

## M1. 출력 공차 시험

최종 판을 출력하기 전에 작은 시험편 하나로 다음을 검사한다.

- [ ] M3 여유홀 3.2/3.4/3.6 mm 비교
- [ ] M4 여유홀 4.2/4.4/4.6 mm 비교
- [ ] 황동 인서트 홀 3종 비교
- [ ] 0.20/0.25/0.30/0.35 mm 끼움 여유 비교
- [ ] 60 mm 키드 오버랩 결합부 조립
- [ ] TPU 패드와 PETG 죠 결합

통과 조건:

- 볼트가 층을 깨지 않고 통과한다.
- 인서트가 회전하거나 빠지지 않는다.
- 분할 이음은 손으로 조립 가능하고 횡방향 유격이 0.5 mm 이하다.

## M2. 차체 건식조립

- [ ] 하판·중판·상판이 모두 `250 ±0.5 mm` 정사각형
- [ ] 두 대각선 길이 차이 1 mm 이하
- [ ] 상판 뒤틀림 1 mm 이하
- [ ] 6개 이상 층간 지지점 설치
- [ ] 4분할 판 사용 시 팔 보강판과 카메라 보강판 설치
- [ ] 볼트 끝이 케이블이나 배터리를 찌르지 않음
- [ ] 휠과 판 사이 최소 3 mm 간격
- [ ] 후방 캐스터만 설치되고 전방 캐스터가 없음

증거:

- 상·측·하부 사진
- 대각선과 높이 측정 사진
- 빈 차체 질량

## M3. 팔과 카메라 정적 하중

- [ ] 왼팔 중심 `(25, +70) mm`
- [ ] 오른팔 중심 `(25, -70) mm`
- [ ] 좌우 베이스 높이 차이 0.5 mm 이하
- [ ] 두 베이스가 상판 밖으로 돌출되지 않음
- [ ] 카메라 기둥 중심 `(-80, 0) mm`
- [ ] 카메라 광학 중심 `Z=480 ±5 mm`
- [ ] 카메라 1 N 횡하중 변위 1 mm 이하
- [ ] 10분 정적 유지 뒤 판·기둥의 영구변형 없음

중단 조건:

- 층 분리, 균열, 인서트 회전
- 팔 베이스가 손으로 흔들림
- 카메라 기둥이 복원되지 않거나 이음부가 미끄러짐

## M4. 3점 지지와 전도 시험

세 접지점 아래에 저울을 놓고 하중을 기록한다.

| 자세 | 왼바퀴 | 오른바퀴 | 후방 캐스터 | 총질량 | 계산 COM X/Y |
|---|---:|---:|---:|---:|---:|
| 운반 홈 |  |  |  |  |  |
| 양팔 준비 |  |  |  |  |  |
| 200 g 붓기 |  |  |  |  |  |
| 250 g 붓기 |  |  |  |  |  |
| 300 g 붓기 |  |  |  |  |  |

- [ ] 모든 접지점 하중이 총질량의 5% 이상
- [ ] 명목 붓기 자세 COM X `+35 mm` 이하
- [ ] 명목 붓기 자세 `|COM Y| ≤ 60 mm`
- [ ] COM 투영점에서 지지 삼각형 세 변까지 최소거리 20 mm 이상
- [ ] 급정지 시험은 팔을 운반 홈에 넣은 상태에서만 수행
- [ ] 바닥 경사 5°에서 미끄러짐·들림 없음

200 g에서 실패하면 250 g와 300 g 시험을 진행하지 않는다.

## M5. 전원과 비상정지

- [ ] 배터리 극성·퓨즈·메인 스위치 확인
- [ ] 서보 모델에 맞는 팔 전원전압 확인. C001이 있으면 3S 직결 금지
- [ ] 좌우 팔 전원 분기 퓨즈 확인
- [ ] 이동부 전원 분기 퓨즈 확인
- [ ] 5 V SBC 전원과 모터 전원 분리
- [ ] E-stop으로 팔과 이동 모터 전원이 끊김
- [ ] E-stop 뒤 SBC는 로그를 남길 수 있음
- [ ] 모터 기동 시 5 V 레일이 허용 범위 아래로 떨어지지 않음
- [ ] Astra S와 추가 UVC 카메라가 같은 USB 컨트롤러를 공유하지 않음

기록:

- 무부하·이동·단팔·양팔 동작별 배터리 전압
- 5 V 최소 전압
- 좌우 팔 최대 전류
- E-stop 반응 영상과 로그

## M6. 단팔 하중 시험

왼팔과 오른팔을 따로 시험한다.

1. 빈 평행그리퍼
2. 100 g 더미
3. 200 g 병
4. 실측 통과 뒤 250 g 병

- [ ] 완전 수평 전개 자세를 사용하지 않음
- [ ] 물체를 든 어깨 수평 투영거리 200 mm 이하
- [ ] 30초 유지 중 눈에 띄는 처짐·미끄럼 없음
- [ ] 서보 온도 55°C 미만
- [ ] 과전류·과부하 보호 반복 발생 없음
- [ ] TPU 패드와 FSR 값이 좌우에서 재현됨

정지 조건: 60°C, 연속 과전류, 진동 증가, 그리퍼 기어 점프, 물체 낙하.

## M7. 양팔 간섭 시험

### 정적 자세

- [ ] 운반 홈
- [ ] 관측 자세
- [ ] 병 접근
- [ ] 컵 접근
- [ ] 양팔 파지
- [ ] 기울이기 전
- [ ] 명목 붓기
- [ ] 복귀
- [ ] 병·컵 내려놓기

### 자동 검사

- [ ] 카메라 기둥 반경 55 mm 금지영역 적용
- [ ] 팔 링크 최소거리 25 mm 적용
- [ ] 그리퍼-반대팔 최소거리 40 mm 적용
- [ ] 양팔 trajectory 100회 충돌 0
- [ ] 좌우 독립 명령 동시 주입 차단
- [ ] 베이스 이동 중 팔 lease 차단

계획상 충돌이 없어도 첫 실물 시험은 저속·무부하로 수행한다.

## M8. Astra S와 LiDAR

- [ ] Astra S 광학 중심과 하향각 측정
- [ ] 명목 붓기 중심까지 거리 0.4 m 이상
- [ ] 병·컵·양쪽 그리퍼의 depth 유효 픽셀 비율 기록
- [ ] 팔 정지 뒤 영상 흔들림 0.5초 안에 안정
- [ ] 기둥이 두 팔의 shoulder sweep와 충돌하지 않음
- [ ] LiDAR 스캔 평면이 상판에 가리지 않음
- [ ] 팔 때문에 가려지는 LiDAR 각도를 기록하고 필터 마스크에 반영
- [ ] Nav2 costmap에 자기 몸체가 장애물로 누적되지 않음

## M9. URDF·MoveIt·Isaac Sim 대조

- [ ] `base_footprint→base_link`가 구동축 기준과 일치
- [ ] 좌우 팔 mount 좌표가 실측과 1 mm 이내
- [ ] Astra 외부파라미터가 실측과 일치
- [ ] optical frame 축이 REP-103 규약과 일치
- [ ] 휠 반경과 간격이 실측값과 일치
- [ ] 평행그리퍼 mimic joint 방향이 실물과 일치
- [ ] collision mesh가 시각 mesh보다 작아 관통하지 않음
- [ ] MoveIt self-collision matrix를 실물 검증 전 과도하게 비활성화하지 않음
- [ ] Isaac Sim 관절축과 실물 양의 방향이 일치
- [ ] CAD 질량·무게중심·관성을 URDF에 반영

## 완료 판정

기구 v0.1은 M0~M4를 통과하면 `조립 가능`, M5~M8을 통과하면 `실기체 POC 가능`, M9까지 통과하면 `URDF/Isaac 기준선 준비`로 표시한다. 한 단계가 실패하면 뒤 단계의 성공으로 덮지 않는다.
