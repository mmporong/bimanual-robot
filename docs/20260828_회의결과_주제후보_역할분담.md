# 2026-08-28 회의 결과 — 주제 후보·기술 경계·역할 분담

> 팀 제출용 정리본. 회의 중 나온 농담·강사 개인 사업 구상·커피 사례는 프로젝트 요구사항과 분리했다.
>
> 상태: 이 문서는 두 후보를 비교하던 회의 당시 기록이다. 같은 날 후속 결정에서 `이동형 비정형 용기 붓기`를 Plan A와 메인 시나리오로 확정했다. 현재 기준은 [20260828_1안_확정_이동형_양팔_붓기.md](20260828_1안_확정_이동형_양팔_붓기.md)다.

## 1. 회의 결론

팀은 **강사/멘토 1명, 학습자 2명**이 함께 진행한다. 당장 하나의 주제를 고정하지 않고 아래 두 시나리오를 같은 기반 기술로 기초검증한 뒤, **9월 중순 전후의 실물 게이트**에서 하나 또는 둘 다를 확정한다.

1. **비정형 물병 붓기·테이블 세팅**
2. **봉지 열기·물체 담기**

프로젝트의 중심은 VLA나 음성이 아니다. `SLAM/Nav2 + Depth + IK/ACT + 교체형 그리퍼 + 접촉 센서 + 로컬 LLM 감독 에이전트`를 계층적으로 묶어, 이동·양팔 조작·실패 복구가 이어지는 시스템을 만든다.

## 2. 확정된 전제

| 구분 | 합의 내용 | 프로젝트에 미치는 영향 |
|---|---|---|
| SO-101 | 한 대의 한계를 소프트웨어만으로 끝까지 극복하지 않는다 | 힘·속도·그리퍼 한계가 확인되면 센서와 전용 엔드이펙터를 추가한다 |
| VLA | 핵심 기술로 두지 않는다 | 범용 모델보다 ACT·IK·상태기계처럼 검증 가능한 레거시 기술을 우선한다 |
| 로컬 LLM | 저수준 모터 제어를 맡기지 않는다 | 성공·실패 상태를 보고 허용된 스킬의 재시도·중단·전환만 결정한다 |
| Depth | 별도 시나리오를 만들지 않는다 | 봉지 입구·병·컵 위치 추정과 작업대 최종 정렬을 보완한다 |
| 접촉 센서 | 물병 시나리오에서 우선 검토한다 | 파지력, 미끄럼, 내용물 변화에 따른 하중 차이를 관측한다 |
| 그리퍼 | 평행 그리퍼 교체 가능, 전용/진공 그리퍼도 제작 가능 | 공통 퀵스왑 마운트를 먼저 설계하고 시나리오별 도구를 바꾼다 |
| 일정 | 두 안을 당분간 병행한다 | 실물 페이로드·흡착·파지 시험 뒤 하나를 버려도 프로젝트 전체가 멈추지 않는다 |

## 3. Plan A — 이동형 비정형 용기 붓기·테이블 세팅

### 시나리오

모바일 베이스가 지정된 테이블로 이동한다. 한 팔은 **총중량 300g 이하의 눌리는 용기**를 잡고, 다른 팔은 컵을 잡거나 위치를 안정화한다. 로봇은 비드·쌀 같은 안전한 내용물을 붓고, 컵을 내려놓은 뒤 다음 위치로 이동한다.

### 이 안을 1순위로 보는 이유

- 사용자가 맡을 가능성이 높은 **SLAM/Nav2**가 부가 기능이 아니라 전체 데모 흐름에 들어간다.
- ACT, Depth, 접촉 센서, 양팔 협응을 한 장면에서 보여줄 수 있다.
- 병의 변형과 내용물 감소 때문에 파지 상태가 바뀌어, 단순 픽앤플레이스보다 학습·센서 융합의 이유가 분명하다.
- 로봇 친화적인 용기·컵을 직접 설계하면 하드웨어 설계 결과도 남는다.

### 반드시 지킬 조건

- 500ml 생수병을 그대로 쓰지 않는다. **병과 내용물 합계 200~300g**으로 제한한다.
- 초기에는 물 대신 비드·쌀을 쓴다.
- 받는 컵을 반대 팔이 들거나 안정화해야 양팔의 필요성이 명확해진다.
- SLAM은 작업대 근처까지 이동시키고, 마지막 수 cm 정렬은 AprilTag/Depth 기반 로컬 정렬로 분리한다.

### 실패 상태 예시

`병 미파지 → 파지 재시도`, `미끄럼 감지 → 파지력 보정`, `컵 미검출 → 재관측`, `유입량 부족 → 추가 붓기`, `기울임 한계 초과 → 중단 후 홈 복귀`

## 4. Plan B — 봉지 열기·물체 담기

### 시나리오

두 팔이 구겨진 봉지를 찾아 입구를 벌린다. 한 팔이 열린 상태를 유지하는 동안 다른 팔이 물체를 담고, 담기 결과를 확인한다. 봉지가 찢어졌거나 입구가 덜 열렸다면 감독 에이전트가 정해진 복구 스킬을 선택한다.

### 강점

- 변형 물체 조작이라 시각적으로 차별화되고, 양팔 사용 이유가 강하다.
- `입구 미개방`, `봉지 찢어짐`, `물체 미삽입`처럼 실패 상태가 명확해 **에이전틱 복구**를 설명하기 좋다.
- 진공·평행 그리퍼를 바꿔 쓰며 엔드이펙터 설계와 비교 실험을 만들 수 있다.

### 핵심 리스크

- 두 팔이 모두 입구를 잡으면 물체를 넣을 팔이 부족하다. `양팔 개방 → 한 팔 유지 → 다른 팔 투입` 전환이 실물에서 유지되는지 먼저 확인해야 한다.
- 얇은 PE 봉지는 주름 때문에 진공이 샐 수 있다. 흡착컵 지름·봉지 재질 조합을 실측해야 한다.
- 병 붓기보다 SLAM을 자연스럽게 결합하기 어렵다.

### 권장 엔드이펙터

- 1차 비교: **평행 그리퍼 2개**와 **진공 1개 + 평행 그리퍼 1개**
- 설계 원칙: 같은 손목 마운트에 교체할 수 있게 만들고, 접촉 패드·흡착컵만 바꾼다.

### 실패 상태 예시

`BAG_NOT_FOUND → 재관측`, `OPEN_INCOMPLETE → 다시 벌리기`, `BAG_TORN → 폐기 후 다음 봉지`, `OBJECT_NOT_INSERTED → 재투입`, `GRIP_LOST → 안전 정지`

## 5. 권장 시스템 구조

```text
사용자 목표
   ↓
로컬 LLM 감독 에이전트
  - 상태 요약 읽기
  - 허용된 스킬 선택
  - 재시도·중단·다음 단계 결정
   ↓
결정론적 스킬 오케스트레이터 / FSM
  ├─ navigate_to_station()  : SLAM + Nav2
  ├─ align_to_workcell()    : Depth / AprilTag
  ├─ manipulate()           : IK 또는 ACT
  ├─ verify_result()        : RGB-D + 접촉 + 저울
  └─ recover_safe()         : 홈 복귀·재파지·재시도
   ↓
모터·그리퍼·센서
```

LLM은 자유 형식 모터 명령을 만들지 않는다. `RETRY_GRASP`, `REOPEN_BAG`, `ABORT_AND_HOME`, `MOVE_TO_NEXT_STATION`처럼 **미리 검증한 행동 목록**에서만 고르게 한다. 이 경계가 안전성과 재현성을 지킨다.

## 6. 역할 분담

### 합의된 내용

| 역할 | 우선 담당 | 함께 공부할 내용 |
|---|---|---|
| 강사/멘토 | 로컬 LLM 실행 환경, 감독 에이전트 구조, 기술 교육·리뷰 | 통합 게이트와 실물 제약 판단 |
| 사용자 | **SLAM/Nav2 우선**, 모바일 베이스·작업대 접근, 전체 통합 참여 | ACT, IK, Depth, 그리퍼·접촉 센서 기초 |
| 다른 팀원 | 세부 전담은 다음 회의에서 확정 | ACT, IK, Depth, 실물 데이터 수집과 평가 |

### 잠정 해석 — 다음 회의에서 이름 기준으로 재확인

- 그리퍼 설계·접촉 센서 부착은 사용자와 다른 팀원이 함께 기초검증한다.
- 두 학습자는 9월 중순까지 ACT·IK·Depth를 공통으로 익힌다.
- 전담은 기능을 완전히 분리하는 방식이 아니라, 각자 주 담당을 두되 통합 시험은 함께 진행한다.

## 8. 아직 확정하지 않은 것

1. 최종 메인 시나리오가 물병인지 봉지인지
2. 실제 모바일 베이스 크기와 허용 탑재중량
3. 봉지용 엔드이펙터가 진공인지 평행 그리퍼인지
4. 접촉 센서가 단순 FSR인지 촉각 배열 센서인지
5. 로컬 LLM을 PC에서 돌릴지 Jetson에서 돌릴지
6. 다른 팀원의 주 담당

## 9. 회의 잡담에서 분리한 아이디어

- 커피 추출 조건을 관리하는 전용 로컬 LLM은 강사의 장기 사업 아이디어이며, 현재 팀 프로젝트 범위에는 넣지 않는다.
- 로봇에 맞춰 용기·컵·공간을 설계하는 `robot-friendly environment` 관점은 물병·컵 제작에 반영할 수 있다.
- 결과물을 강의·메이커 커뮤니티에서 재사용한다는 이야기는 활용처이지, 성공 조건은 아니다.
