# R14 — 대중이 관심 가질 태스크 10종

작성 2026-08-20 · 기준: **발표장에서 설명 없이도 "저게 뭘 하는지" 바로 보이는가.** 산업 근거보다 데모 임팩트와 공감대를 앞세웠다.

## 먼저 — 빨래 계열이 양팔인 이유

가사 태스크를 다룬 자료에서 나온 정리가 명쾌하다. 빨래의 기본 동작인 **모서리-모서리 펴기, 반대 회전으로 꼬임 풀기, 흔들어 정착시키기**는 근본적으로 양팔 동작이다.

> **단팔은 미리 펴서 방향까지 맞춰 둔 티셔츠는 접을 수 있다. 그러나 뭉쳐진 더미에서 접힌 상태까지 가는 것은 두 번째 팔 없이는 못 한다** — 의류 종류마다 전용 기구를 만들지 않는 한.

이 문장이 대중형 태스크에서 양팔을 정당화하는 가장 좋은 표현이다.

---

## 1. 양말 짝 맞추기 ★

빨래 더미에서 양말을 골라 뒤집고 짝을 맞춘다.

| 항목 | 내용 |
|---|---|
| 공감대 | **최상.** 누구나 겪는 귀찮은 일. 설명이 필요 없다 |
| 선례 | **Willow Garage PR2**(UC Berkeley) — 양말을 **안쪽/바깥쪽으로 분류해 뒤집고 짝을 맞추는** 데모. 수건 개기도 함께 시연했다 |
| 양팔 | 뒤집기가 양팔 필수 — 한 팔이 입구를 벌려 잡고 다른 팔이 안쪽을 끌어낸다 |
| HW | **최적** — 양말 30~50g, 회전 불필요, 백래시를 천이 흡수 |
| 난점 | 짝 판정(색·무늬·크기 매칭)이 인식 문제. 더미에서 한 짝만 집기 |
| 데모 | 짝이 맞춰져 쌓이는 그림이 직관적 |

## 2. 엉킨 케이블 풀기 ★

이어폰·충전 케이블이 엉킨 것을 양팔로 풀어 정리한다.

| 항목 | 내용 |
|---|---|
| 공감대 | **최상.** "가방에서 이어폰 꺼내면 항상 엉켜 있다"는 보편 경험 |
| 선례 | 엉킨 와이어 하네스 **양팔 빈피킹 연구가 성공률 91.2%** 보고. 매듭 풀기(unknotting)는 DLO 벤치마크의 표준 태스크 |
| 양팔 | **한 팔이 한쪽을 고정하지 않으면 당길 때 매듭이 더 조여진다.** 물리적으로 명확 |
| HW | **최적** — 케이블 수십 g, 회전 불필요 |
| 난점 | 엉킴 상태 인식. 어디를 잡아 당길지 판단 |
| 데모 | **풀리는 과정 자체가 극적이다.** 영상 소재로 최고 |

산업 버전(와이어 하네스)과 **같은 기술, 다른 표면**이라는 것도 장점이다. 발표는 이어폰으로 하고, 문서에는 자동차 전장 연결을 적는다.

## 3. 수건 개기

작은 수건을 펴서 반듯하게 갠다.

| 항목 | 내용 |
|---|---|
| 공감대 | 높음 — 가사의 대표 |
| 선례 | PR2 수건 개기(Berkeley), SpeedFolding, FabricFlowNet 등 양팔 천 조작 연구가 두텁다 |
| 양팔 | **B2** — 두 모서리를 동시에 잡아야 펴진다 |
| HW | 손수건급이면 가능. 큰 수건은 무게·크기 초과 |
| 난점 | **2D 유연물의 자기가림.** 접히면 아래가 안 보인다. 최신 모델이 최근에야 80%대 |
| 데모 | 좋음 |

## 4. 선물 포장 리본 묶기

상자에 리본을 두르고 매듭·나비 모양을 만든다.

| 항목 | 내용 |
|---|---|
| 공감대 | 높음 — 계절감 있고 시각적 |
| 선례 | 매듭 묶기(knot tying)는 양팔 필수 태스크로 자주 인용된다 |
| 양팔 | **B2 극단** — 한 팔이 장력을 유지하지 않으면 매듭이 풀린다 |
| HW | 리본 자체는 가벼움. 다만 **매듭 동작이 5축에 버겁다** |
| 난점 | 매듭은 손목 자유도가 많이 필요하다. 나비 모양은 특히 어렵다 |
| 데모 | **최상** — 완성품이 예쁘다 |

**난이도를 낮추면**: 나비 없이 한 번 묶기(오버핸드 매듭)까지만.

## 5. 넥타이 매기

넥타이를 매듭 짓는다.

| 항목 | 내용 |
|---|---|
| 공감대 | 높음 — "나도 못 매는데 로봇이" |
| 선례 | **TieBot** — 시각 시연으로 넥타이 매듭을 학습하는 Real-to-Sim-to-Real 연구가 실재한다 |
| 양팔 | **B2 극단** |
| HW | **어렵다** — 다단계 매듭에 손목 자유도가 부족하다 |
| 난점 | 이 목록에서 가장 어려움 |
| 데모 | 최상 |

**참고용으로 둔다.** 도전 과제로 언급하되 주 태스크로 잡지 않는 것이 안전하다.

## 6. 종이접기

종이를 접어 간단한 모양(비행기, 학의 초기 단계)을 만든다.

| 항목 | 내용 |
|---|---|
| 공감대 | 높음 — 시각적이고 결과물이 남는다 |
| 선례 | 로봇 종이접기(robotic origami) 연구가 있다(Dartmouth 등) |
| 양팔 | **B2** — 한 팔이 종이를 눌러 고정해야 다른 팔이 접을 수 있다 |
| HW | 종이는 무게 없음. 다만 **얇은 종이 모서리 파지가 까다롭다** |
| 난점 | 접은 선을 누르는 힘 조절 |
| 데모 | 좋음 — 단계가 쌓이는 것이 보인다 |

## 7. 김밥·롤 말기

김 위에 재료를 올리고 말아 김밥을 만든다.

| 항목 | 내용 |
|---|---|
| 공감대 | **한국 발표에서 최상** — 즉시 이해되고 친근하다 |
| 선례 | 초밥·롤 제조 기계는 있으나 로봇팔로 하는 사례는 드물다 |
| 양팔 | **B2** — 발이나 김을 한 팔이 눌러 고정하고 다른 팔이 말아 올린다 |
| HW | 재료가 가벼움. 다만 **끈적이고 부서지는 재료**는 파지가 어렵다 |
| 난점 | 위생·재료 관리. 실험 반복 시 재료 소모 |
| 데모 | **최상** — 먹을 수 있는 결과물 |

**대체안**: 실제 음식 대신 펠트·스펀지로 모사한 재료를 쓰면 반복 실험이 쉬워진다. 대신 "먹을 수 있음"의 임팩트는 잃는다.

## 8. 약통 요일별 채우기

일주일 약통에 요일별로 약을 나눠 담는다.

| 항목 | 내용 |
|---|---|
| 공감대 | 높음 — **고령 가구의 실제 문제**. 사회적 의미가 붙는다 |
| 선례 | 약국 조제 자동화는 있으나 가정용 소분은 사람이 한다 |
| 양팔 | B2 — 한 팔이 약통을 잡아 고정하고 다른 팔이 알약을 넣는다 |
| HW | **최적** — 매우 가볍고 회전 불필요 |
| 난점 | 알약이 작아 파지가 어렵다. 실제 약 대신 모사품 필요 |
| 데모 | 좋음 — 실용성이 즉시 전달된다 |

## 9. 카드 섞기·나누기

카드를 섞고 인원수대로 나눠 준다.

| 항목 | 내용 |
|---|---|
| 공감대 | 높음 — 놀이 맥락이라 친근하다 |
| 선례 | 딜링 머신은 있으나 로봇팔 양팔 구현은 드물다 |
| 양팔 | B1~B2 — 한 팔이 덱을 잡고 다른 팔이 한 장씩 밀어낸다 |
| HW | **얇은 카드 한 장 분리가 어렵다.** 석션이 유리 |
| 난점 | 한 장만 집기 |
| 데모 | 좋음 — 동작이 리드미컬해서 영상이 잘 나온다 |

## 10. 테이블 세팅

접시·수저·컵을 정해진 자리에 놓는다.

| 항목 | 내용 |
|---|---|
| 공감대 | 중간 — 이해는 쉬우나 놀랍지는 않다 |
| 선례 | 서비스 로봇의 전형적 데모 |
| 양팔 | **B0~B1** — 대부분 단팔로 된다. **양팔 근거가 약하다** |
| HW | 접시 무게가 부담 |
| 난점 | 양팔 정당화 |
| 데모 | 보통 |

### 권고

**엉킨 케이블 풀기(2)가 1위다.** 대중 공감과 산업 근거를 동시에 갖는 유일한 후보이기 때문이다.

- 발표에서는 **"이어폰 줄 엉킨 것을 로봇이 푼다"**로 설명한다. 설명이 필요 없다
- 문서와 면접에서는 **"엉킨 와이어 하네스 분리 — 자동차 전장 조립의 미해결 구간"**으로 적는다
- **같은 기술, 다른 표면**이라 두 개를 따로 만들 필요가 없다

**양말 짝 맞추기(1)가 2위다.** PR2 선례가 있고 하드웨어 궁합이 최적이며, "안쪽/바깥쪽 판정 후 뒤집기"라는 인식+조작 결합이 기술적으로도 볼거리가 있다.

**둘을 합치는 것도 가능하다.** "빨래 정리 로봇"이라는 한 프레임 안에서 수건 개기(3) → 양말 짝 맞추기(1)로 태스크 계단을 만들면, 대중형 서사 하나로 여러 태스크를 묶을 수 있다.
