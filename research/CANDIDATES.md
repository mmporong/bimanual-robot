# 태스크 후보 마스터 인덱스

최종 갱신 2026-08-20 · 지금까지 검토한 **모든** 후보를 한곳에 모은다. 새 아이디어가 나오면 여기에 추가하고, 판정이 바뀌면 여기를 고친다.

## 판정 기준 (요약)

| 축 | 통과 조건 |
|---|---|
| **양팔** | B2(동시 협응) 또는 B1(순차). **B0면 탈락** |
| **학습** | 규칙으로 못 쓰는 어려움이 있을 것 |
| **하드웨어** | 5축 · 리치 346mm · 페이로드 수백 g · 회전 토크 취약 · 그리퍼 닫힘 15초 · **depth가 얇은 것 못 봄** |
| **판정** | 성공/실패를 이진으로 셀 수 있을 것 |
| **소모품** | 없을 것 (수천 에피소드 수집 전제) |
