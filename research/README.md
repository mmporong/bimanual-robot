## 작성 규칙

- 파일명은 `R<번호>_<주제>.md`. 계획 문서의 항목 번호를 그대로 쓴다.
- 문서 맨 위에 **판정 질문별 답변 상태 표**를 둔다 (답함 / 부분 / 확인 안 됨).
- 출처 URL을 반드시 남긴다. 출처 없는 문장은 내 추정임을 명시한다.
- **확인 못 한 것을 그럴듯한 문장으로 채우지 않는다.** "확인 안 됨"이 정직한 답이고, 그 상태가 다음 할 일을 만든다.
- 결론을 문서 끝이 아니라 맨 앞에 쓴다. 팀에 공유할 때 첫 문단만 읽어도 판단이 되게.
