# R26 · 음성 명령 문장 규격 (초안)

작성 2026-08-24 · 근거: R23의 `single_task` 구조

## 왜 먼저 고정하는가

`lerobot_record.py:337`이 에피소드당 task 문자열 **하나**를 박는다. 나중에 어휘를 바꾸면 이전 에피소드의 문장과 어긋나 학습셋이 갈라진다 — 좌우 표현 규약과 같은 종류의 선결 항목이다.

## 3축

```
<대상> <목적지|수용체> <스킬>
```

| 축 | 값 | 비고 |
|---|---|---|
| 대상 | `red cup` · `blue cup` · `bottle` | 색으로 갈라야 비전이 실제로 구분한다 |
| 목적지 | `left tray` · `right tray` · `held cup` | `held cup` = 반대 팔이 들고 있는 컵 |
| 스킬 | `move` · `handover` · `pour` | 3종 태스크에 대응 |

## 문장 템플릿 (영문 고정)

| 태스크 | 문장 | 양팔 등급 |
|---|---|---|
| 옮기기 | `Move the red cup to the left tray` | B0 |
| 건네주기 | `Hand over the blue cup to the other arm` | B1 |
| 붓기 | `Pour the bottle into the held cup` | B2 |

- **학습 문장은 영문 고정.** SmolVLA 사전학습 언어 분포가 영문이다. 한국어 음성은 Whisper가 받고 정규화 단계에서 위 템플릿으로 매핑한다
- 정규화: `"콜라를 컵에 따라줘"` → `{대상: bottle, 수용체: held cup, 스킬: pour}` → 템플릿 문장
- 정규화기는 규칙 사전으로 시작. 어휘가 늘면 LLM 플래너로 교체

## 메타데이터 확장안

`data/schema`의 에피소드 메타데이터에 추가:

| 필드 | 타입 | 값 |
|---|---|---|
| `command_text` | string | 학습에 쓴 영문 task 문장 |
| `command_source` | enum | `typed` \| `stt` |
| `stt_raw` | string \| null | STT 원문(한국어). `command_source=stt`일 때만 |
| `skill` | enum | `move` \| `handover` \| `pour` |
| `bimanual_grade` | enum | `B0` \| `B1` \| `B2` |

`tools/validate_episode_meta.py`를 이 필드로 확장해 통과 확인이 필요하다 (미착수).
