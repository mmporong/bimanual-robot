# R30 · 봉지·물병·에이전틱 감독·SLAM 재평가

작성 2026-08-28 · 회의 결과를 기존 조사와 최신 논문에 다시 대입한 판정

## 결론

| 후보 | 실현 가능성 | 포트폴리오 연결 | 핵심 위험 | 판정 |
|---|---:|---:|---|---|
| 이동형 비정형 용기 붓기 | 중상 | **매우 높음** | SO-101 페이로드·미끄럼·유입량 판정 | **Plan A** |
| 봉지 열어 물체 담기 | 중 | 높음 | 개방 후 투입 전환·흡착 누설 | **Plan B / 병행 POC** |

두 후보에 VLA를 넣을 필요는 없다. ACT는 접촉이 긴 양팔 동작을 학습하고, SLAM/Nav2는 작업 구역까지 이동하며, Depth와 접촉 센서는 성공 판정을 보강한다. 로컬 LLM은 이 결과를 읽고 **검증된 스킬의 재시도·중단·순서 변경**만 맡는다.

## 1. 논문이 직접 지지하는 부분

### 봉지는 실제로 양팔·변형 물체 난제다

**ShakingBot**은 임의의 초기 형상에 놓인 비닐봉지에서 핵심 영역을 찾고, 봉지 조정·양팔 흔들기·한 팔 유지로 입구를 연 뒤 물체를 넣었다. 여러 초기 형상에서 적어도 한 물체를 넣는 데 **21/33 성공**을 보고했다. 따라서 봉지 태스크는 단순한 아이디어가 아니라, 인식·양팔 동적 조작·한 팔 유지 전환이 모두 필요한 연구 문제다.

우리 적용:

1. 처음부터 ACT 하나로 전체를 학습하지 않는다.
2. `FIND_BAG → OPEN → HOLD → INSERT → VERIFY`로 나눈다.
3. `OPEN`은 양팔, `HOLD/INSERT`는 역할 전환으로 별도 성공률을 잰다.

### ACT는 저가 양팔 하드웨어의 접촉 작업 기준선이다

**Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware**는 저가 양팔 시스템과 ACT로 정밀 접촉 태스크 6개를 수행했고, 일부 작업에서 80~90% 성공을 보고했다. 우리에게 중요한 점은 숫자를 그대로 기대하는 것이 아니라, **짧은 동작 묶음(action chunk)**이 오차 누적을 줄이는 검증된 기준선이라는 점이다.

우리 적용:

- 이동·정렬은 고전 제어로 분리하고, 작업대 안의 양팔 조작에만 ACT를 쓴다.
- 데이터 수집 전에 성공 판정과 실패 라벨을 고정한다.
- 긴 전체 시퀀스보다 봉지 개방·붓기 스킬을 따로 수집한다.

### 접촉 센서는 물병 파지와 붓기에 실제 이득이 있다

**Pouring by Feel**은 고유수용감각과 손끝 촉각을 이용해 붓는 양을 추정했고, 새로운 위치와 파지에서도 평균 목표 오차 10ml 이내를 보고했다. 또 변형 물체 비전-촉각 파지 연구는 촉각과 시각을 함께 사용해 안전한 파지력을 예측한다.

우리 적용:

- 1단계는 저가 FSR/접촉 스트립으로 `접촉 있음`, `압력 임계 초과`, `좌우 불균형`만 읽는다.
- 2단계에서 값의 시간 변화로 미끄럼 후보를 검출한다.
- 접촉값을 ACT 관측에 바로 넣기 전에 규칙 기반 안전 인터록으로 먼저 검증한다.

### LLM은 피드백을 읽는 상위 감독자로 둘 때 근거가 선다

**Inner Monologue**는 성공 탐지·장면 설명·사람 피드백을 언어로 되먹임해 로봇의 고수준 계획을 갱신했다. 이는 회의의 “LLM이 모터를 직접 제어하지 않고 상황을 보고 다시 하라고 지시한다”는 구상과 맞는다.

우리 적용:

```text
센서/검증기 → 구조화 상태 JSON → 로컬 LLM → 허용 행동 enum → FSM 실행
```

LLM 출력은 자유로운 좌표·토크가 아니라 `RETRY`, `REGRASP`, `REOBSERVE`, `SKIP_OBJECT`, `ABORT` 중 하나로 제한한다. 정상 경로는 LLM 없이도 동작해야 하며, LLM의 가치는 **실패 복구 성공률과 불필요한 재시도 감소**로 따로 측정한다.

### 모바일 양팔은 별도 평가축으로 가치가 있다

**BiGym**은 이동형 양팔 조작을 위한 40개 태스크와 RGB·Depth·고유수용감각 관측을 제공한다. Nav2 공식 구조 역시 행동트리로 독립 서버를 조합해 고수준 행동을 만든다. 따라서 SLAM/Nav2와 양팔 ACT를 한 모델에 섞기보다 아래 경계가 적절하다.

```text
Nav2: 작업대 인근 목표 자세까지
Depth/표식: 마지막 수 cm 작업 셀 정렬
IK/ACT: 팔의 작업
검증기: 성공·실패 판정
LLM: 실패 시 다음 스킬 선택
```

## 2. 엔드이펙터 판정

### 공통

- 손목에 **퀵스왑 어댑터**를 둔다.
- 평행 그리퍼 본체는 가볍게 유지하고, 손가락 끝 패드·FSR·흡착컵만 교체한다.
- 출력물보다 먼저 질량·개구폭·손목 모멘트를 계산한다.

### Plan A 물병

**평행 그리퍼 2개 + 접촉 패드**가 기본이다.

- 병 손: 곡면을 잡는 V-groove 또는 고마찰 TPU 패드
- 컵 손: 넓은 평행 패드 또는 컵 전용 반원형 인서트
- 총중량 300g 이하, 초기 내용물 비드·쌀
- 성공 지표: 파지 손실 0, 흘림량, 목표 유입량, 붓기 시간, 컵 자세 오차

### Plan B 봉지

두 구성을 짧게 비교한다.

1. 평행 그리퍼 2개: 추가 장비가 없지만 얇은 필름 분리가 어렵다.
2. 진공 1개 + 평행 그리퍼 1개: 봉지 면 고정과 물체 파지의 역할을 나눌 수 있지만 진공 누설과 개방 유지가 위험하다.

성공 지표: 한 장 분리율, 입구 면적, 개방 유지 시간, 투입 성공률, 봉지 손상률.

## 3. SLAM 담당자가 만들어야 할 포트폴리오 증거

단순히 “SLAM을 붙였다”로 끝내지 않는다.

| 증거 | 측정 |
|---|---|
| 지도 품질 | 루프 폐합 전후 지도 겹침, 왜곡 구간 |
| 위치 재현성 | 같은 작업대에 10회 접근한 최종 자세 분산 |
| 작업 연계 | Nav2 완료 후 Depth/표식 정렬 성공률 |
| 안전성 | 팔 전개 상태 footprint, 정지·감속 구역 |
| 전체 성능 | 이동 포함 사이클 타임, 실패 복구 시간 |

모바일 베이스의 목표는 mm급 조작 정밀도가 아니다. 작업대를 카메라 시야와 팔 작업공간 안에 반복해서 넣고, 정밀 정렬 계층으로 안정적으로 넘기는 것이다.

## 4. 게이트 기준

9월 중순 전후에 아래 실측으로 결정한다.

| 항목 | Plan A 통과 | Plan B 통과 |
|---|---:|---:|
| 기본 물리 성공 | 10회 중 7회 이상 안정 파지·기울임 | 10회 중 7회 이상 입구 개방 |
| 센서 판정 | 파지/미끄럼/유입량 중 2개 이상 자동 판정 | 미개방/파손/미삽입 중 2개 이상 자동 판정 |
| 복구 | 실패 5회 중 3회 이상 안전 복구 | 실패 5회 중 3회 이상 안전 복구 |
| 양팔 근거 | 반대 팔이 컵 안정화 | 양팔 개방과 한 팔 유지 전환 |
| 통합성 | SLAM 이동과 자연스럽게 연결 | 이동 없이도 작업 셀 가치가 충분함 |

둘 다 통과하면 **물병을 메인 데모**, 봉지를 **에이전틱 실패 복구 데모**로 구성한다. 하나만 통과하면 통과한 안에 집중한다.
