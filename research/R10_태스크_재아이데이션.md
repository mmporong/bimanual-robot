# R10 — 태스크 재아이데이션: 뚜껑 대신 무엇을 할 것인가

작성 2026-08-20 · 계기: 뚜껑 개폐의 토크 전달 문제와 태스크 자체의 재검토

## 결론 먼저

**와이어 하네스(케이블) 조립을 권한다.** 뚜껑보다 모든 축에서 낫다.

핵심은 이것이다. **뚜껑은 사실 규칙으로 풀 수 있는 문제다.** 용기 위치와 뚜껑 축만 알면 나머지는 정해진 궤적이다. 그래서 "왜 학습이어야 하는가"에 답하기 어렵고, 회전 토크 전달이라는 하드웨어 문제까지 떠안는다.

**케이블은 원천적으로 규칙으로 못 푼다.** 한쪽 끝을 잡아도 나머지 형상이 미정이고, 놓는 순간 형상이 바뀐다. 상태가 고차원이고 부분 관측만 가능하다. 이것이 학습을 쓰는 정당한 이유이고, 동시에 양팔이 필요한 물리적 이유다.

그리고 **자동차 와이어 하네스 조립은 지금도 사람이 한다.** 고도로 커스터마이즈된 제품이라 기존 자동화가 비용 효율이 나오지 않아서다. 발표 도입부가 한 문장으로 서는 주제다.

---

## 1. 유연물 난이도 계층

유연물 조작은 변형 차원으로 난이도가 갈린다. 이 계층을 알면 기간 안에 가능한 것이 정해진다.

| 차원 | 대상 | 난이도 요인 |
|---|---|---|
| **1D** | **로프, 케이블, 튜브** | 형상이 곡선 하나. 자기가림이 적고 상태 표현이 상대적으로 단순 |
| 2D | 천, 종이, 비닐 | **자기가림(self-occlusion)** — 접히면 아래가 안 보인다 |
| 3D | 반죽, 점토 | 부피 변형. 되돌릴 수 없는 상태 변화 |

**1D가 가장 낮은 계층이다.** 우리 기간(수집 마감 10/13, 정규 15일)과 하드웨어를 고려하면 1D에서 시작하는 것이 합리적이다.

참고로 2D의 대표인 빨래 접기는 최근까지 미해결이었고, π₀가 flow matching과 긴 액션 청크로 티셔츠 접기 80%대를 달성하면서 풀렸다. 다만 얇거나 미끄럽거나 다층인 직물로의 일반화는 아직 미검증이다. **우리가 2D로 들어가면 최신 파운데이션 모델이 겨우 푼 영역에 SO-101로 도전하는 셈**이 된다.

## 2. 후보 비교

전부 회전 토크가 필요 없고 페이로드가 낮아 하드웨어 제약을 통과한다.

| 후보 | 차원 | 양팔 근거 | 산업 근거 | IL 필수성 | 기간 적합 |
|---|---|---|---|---|---|
| **A. 와이어 하네스** | **1D** | 양쪽을 잡아야 형상이 결정된다 | **자동차 전장 — 지금도 수작업** | **높음** (형상 예측 불가) | **적합** |
| B. 봉지 열어 담기 | 2D | 양면 동시 견인 | 식품 포장, 물류 파우치 | 높음 | 석션 조달 필요 |
| C. 천·시트 취급 | 2D | 두 모서리 동시 파지 | 의류, 세탁 물류 | 높음 | **자기가림으로 난이도 급증** |
| D. 커넥터 삽입(강체) | — | 고정 + 삽입 | 전자 조립 | **낮음** (규칙 가능) | 백래시 문제 |
| E. 뚜껑 개폐(강체) | — | 회전 반작용 | 실험실 | **낮음** (규칙 가능) | **토크 전달 문제** |

**D와 E의 공통 약점**은 강체라서 규칙으로 풀 수 있다는 점이다. 학습을 쓸 이유를 따로 만들어야 한다("여러 물체를 섞으면 파라미터를 다시 재야 한다" 같은 논리). 반면 A·B·C는 유연물이라 학습이 기본값이다.

## 3. 와이어 하네스 — 상세

### 산업 근거

- 와이어 하네스 제조는 **여전히 수작업에 의존**한다. 하네스와 케이블 조립품이 고도로 커스터마이즈된 제품이라 산업 자동화가 비용 효율적이지 않기 때문이다
- 유연물이라 실제 환경에서의 로봇 조립이 어렵고, 지금까지 나온 해법 대부분이 **단순화된 산업 설정**에서만 동작한다
- **다분기 하네스**는 복잡도가 한 단계 더 올라간다

### 연구 동향 — 양팔이 주류 방향

- 엉킨 하네스 빈피킹을 위해 **양팔 + 동적 조작**으로 엉킴을 푸는 연구가 나왔고, 햅틱 피드백으로 실시간 엉킴을 감지해 **평균 성공률 91.2%**를 보고했다
- **자동차 산업의 다분기 하네스 조립을 위한 양팔 로봇 시스템** 연구가 진행 중이다
- 3D 비전 기반 다중 분기 검출 기법도 별도 연구 주제다

즉 **우리가 하려는 것이 현재 연구의 최전선과 같은 방향**이다. 이건 발표와 면접 양쪽에서 강한 위치다.

### 양팔이 필요한 물리적 이유

강체와 근본적으로 다르다. 강체는 한 점을 잡으면 전체 자세가 결정되지만, **케이블은 한쪽 끝을 잡아도 나머지가 어디 있는지 모른다.** 양쪽을 잡아 장력을 걸어야 비로소 형상이 결정된다.

그리고 한쪽을 놓으면 즉시 형상이 무너진다. **고정을 유지한 채로만 작업이 성립하므로 시간 분리가 불가능하고, 단팔 두 대로도 순차 녹화로도 대체되지 않는다.** B2 등급이 물리적으로 보장된다.

### 우리 하드웨어와의 궁합

| 제약 | 케이블 태스크 |
|---|---|
| 페이로드 수백 g | 케이블은 수십 g. **여유 충분** |
| 회전 토크 전달 불가 | **회전이 필요 없다** |
| 그리퍼 닫힘 15초 | 케이블은 얇아 완전 폐쇄까지 안 가도 된다. 개폐 횟수도 적다 |
| 리치 346mm | 테이블탑 하네스 보드로 충분 |
| 5축 | 케이블 파지는 임의 6D 자세가 필요 없다 |
| 백래시 | 유연물이라 mm 단위 오차를 케이블이 흡수한다 |

**뚜껑에서 문제가 됐던 항목이 전부 해소된다.**

## 4. 태스크 설계 — 데스크톱 하네스 조립 셀

하네스 보드(케이블 경로가 그려진 판)에 케이블을 배치하는 작업을 축소한다.

| # | 태스크 | 등급 | 무엇을 검증하나 |
|---|---|---|---|
| **T1** | 케이블 더미에서 한 가닥 집어 올리기 | B0 | 파이프라인 관통, 인식 |
| **T2** | **양팔로 양끝을 잡고 펴기 (장력 유지)** | **B2** | **양팔 협응. 단팔 대조군이 여기서 무너진다** |
| **T3** | **한 팔 장력 유지 + 다른 팔이 클립·가이드에 눌러 끼우기** | **B2** | 유지 중 작업 — 하네스 조립의 핵심 동작 |
| **T4** | 커넥터 하우징에 단자 삽입 | B1 | 정밀 삽입 (선택, 공차 크게 설계) |

**확장 태스크**: 두 케이블이 엉킨 상태에서 양팔로 당겨 분리. 연구에서 성공률 91.2%가 보고된 작업이라 비교 대상이 있다.

### 난이도 손잡이

| 수준 | 조건 |
|---|---|
| L1 | 케이블 1종, 시작 위치 고정 |
| L2 | 시작 위치 랜덤화 |
| L3 | **케이블 길이·굵기 2~3종 혼합** |
| L4 | 시작 형상 랜덤(구부러진 상태) 또는 엉킴 포함 |

L3·L4가 이 태스크의 진짜 시험대다. **케이블 물성이 바뀌면 같은 동작이 다른 결과를 낸다** — 학습이 필요한 이유가 여기서 수치로 드러난다.

### 측정 지표

기존 측정 골격을 그대로 쓰되 케이블 특성을 반영한다.

| 지표 | 재는 방법 |
|---|---|
| 라우팅 성공률 | 지정 클립에 케이블이 끼워졌는지 (실물 관측) |
| **장력 유지 실패율** | 작업 중 케이블이 빠지거나 처진 비율 — **양팔 협응이 무너진 지표** |
| 경로 이탈 거리 | 목표 경로 대비 케이블 실제 위치 오차(mm), 비전으로 측정 |
| **단팔 대조군** | 한 팔로 시도 — 장력을 못 걸어 성공률이 무너질 것 |
| 물성 일반화 | 학습에 없던 굵기·길이 케이블에서의 성공률 |
| HIL 재학습 전후 | 실패 상태 개입 데이터 추가 전/후 |

**실패 유형**도 케이블용으로 재정의한다.

| 코드 | 유형 |
|---|---|
| F1 | 파지 실패 (케이블을 못 집음, 여러 가닥이 딸려옴) |
| **F2** | **장력 실패 (한쪽을 놓쳐 형상이 무너짐)** |
| F3 | 클립 삽입 실패 |
| F4 | 경로 이탈 (끼웠으나 목표 경로에서 벗어남) |
| F5 | 도달 실패 |

## 5. 뚜껑 대비 무엇이 나아지는가

| 축 | 뚜껑 개폐 | 와이어 하네스 |
|---|---|---|
| 학습 필요성 | 약함 — 규칙으로 가능 | **강함 — 규칙으로 원천 불가** |
| 하드웨어 문제 | **회전 토크 전달, 어댑터 필요** | 없음 |
| 산업 근거 | 실험실 워크스테이션(전용기 경쟁) | **자동차 전장 — 자동화 미해결** |
| 연구 정합 | 낮음 | **양팔+동적 조작이 현재 연구 주류** |
| 그리퍼 15초 문제 | 개폐 4회 = 60초/에피소드 | 얇은 케이블이라 완전 폐쇄 불필요 |
| 발표 도입부 | "뚜껑을 엽니다" | **"자동차 전장은 지금도 사람이 손으로 조립합니다"** |

## 6. 리스크

| 리스크 | 대응 |
|---|---|
| 케이블이 얇아 그리퍼가 못 집음 | 굵은 케이블(지름 3~5mm)부터 시작. 그리퍼 패드에 홈 가공 |
| 여러 가닥이 딸려 올라옴 | L1에서는 케이블을 분리 배치. 엉킴은 L4 확장 |
| 성공 판정이 애매 | **클립 삽입 여부는 이진 판정이 가능하다.** 경로 이탈은 비전으로 mm 측정 |
| 케이블 상태 관측이 어려움 | 상단 카메라 + 대비 높은 색(빨강·노랑 케이블, 흰 보드) |
| 시연이 어려워 텔레옵 품질이 낮음 | 리더암 조작은 사람 손 움직임 그대로라 유연물에 오히려 유리 |

**가장 불확실한 것**: SO-101 그리퍼가 케이블을 안정적으로 집는지. 뚜껑의 토크 문제처럼 **실물로만 확인된다.** 케이블 몇 종을 그리퍼에 물려보는 것으로 30분 안에 판정 가능하다.
