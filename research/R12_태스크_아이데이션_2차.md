# R12 — 태스크 아이데이션 2차: 서비스·리테일·순환경제 축

작성 2026-08-20 · 와이어 하네스(R10·R11) 외의 선택지를 넓힌다

## 먼저 — 학계 용어 하나

양팔 조작 연구에서 우리가 계속 말해 온 "한 팔이 고정하고 다른 팔이 작업한다"는 패턴에 **정립된 이름**이 있다. **stabilizing arm(안정화 팔)과 acting arm(작업 팔)의 역할 분리**다. VoxAct-B 같은 정책 연구가 이 구분을 제목에 넣고 있다.

이 용어를 쓰면 발표와 문서의 밀도가 올라간다. "한 손으로 잡고 한 손으로 한다"가 아니라 "**안정화 팔과 작업 팔의 역할 분리를 정책이 학습한다**"가 된다.

## 후보 A. 전자제품 분해·부품 회수

폐기된 기기를 분해해 부품을 분류·회수한다.

| 항목 | 내용 |
|---|---|
| 원본 | **Apple Daisy** — 팔 5개, 길이 10m, **시간당 아이폰 200대 분해**, 23개 모델 대응. 나사 뽑기·배터리 제거·모듈 분류·필요 시 부품 냉각. 코발트·알루미늄·주석 회수. 대당 연 120만 대 처리. 후속 로봇 Taz도 운용 |
| 양팔 근거 | **B2** — 안정화 팔이 기기를 눌러 고정하지 않으면 커버를 뜯을 때 기기가 딸려 온다 |
| 학습 근거 | **높음** — 분해는 조립보다 어렵다. 조립은 새 부품이 정해진 상태로 오지만 **분해 대상은 마모·접착 열화·변형 상태가 매번 다르다.** 같은 모델도 개체마다 다르다 |
| 하드웨어 | 스마트폰급 200g은 페이로드 경계. **나사는 회전이라 제외**하고 클립·접착 분리로 한정하면 가능 |
| 판정 | 명확 — 분리 성공 여부, 파손 여부 |
| 국내 맥락 | 폐배터리·폐전자 재활용이 성장 산업. ESG·순환경제 서사가 붙는다 |

**난점**: 나사 체결부를 피해야 한다. 클립 결합 제품(리모컨, 완구, 구형 기기)으로 대상을 골라야 한다.

## 후보 B. 신발 짝 맞추기·포장

뒤섞인 신발에서 짝을 찾아 맞추고 상자에 포장한다.

| 항목 | 내용 |
|---|---|
| 원본 | **신발 산업 양팔 로봇 연구가 실재한다** — "Bimanual Robot Manipulation and Packaging of Shoes in Footwear Industry"에서 **양팔 인간형 핸드**로 신발 포장을 구현했다. 신발 산업 자동화에 필요한 유연성과 손재주를 이유로 든다 |
| 양팔 근거 | **B1~B2** — 두 짝을 동시에 들어 맞대 비교하고, 포장 시 신발은 보통 앞뒤를 반대로 넣으므로 두 짝을 동시에 다뤄야 한다 |
| 학습 근거 | 중간~높음 — 신발은 모델마다 형상이 다르고 재질이 변형된다. 파지점이 매번 달라진다 |
| 하드웨어 | **문제 있음** — 성인 운동화 300~400g은 페이로드 한계를 넘는다. **아동화·미니어처로 축소해야** 한다 |
| 판정 | **명확** — 짝이 맞는지 이진, 포장 상태 |
| 부가 | 인식 문제가 재밌다 — 좌/우, 모델, 사이즈를 동시에 매칭해야 한다 |

**난점**: 무게. 그리고 "간이 버전"이라기엔 축소 폭이 커서 원본과의 연결이 흐려질 수 있다.

## 후보 C. 선반 진열·페이싱

음료를 선반에 채우고 앞으로 정렬한다.

| 항목 | 내용 |
|---|---|
| 원본 | **Telexistence** — 일본 **패밀리마트 300개 매장** 배치, 최근 **세븐일레븐 도쿄 매장**으로 확대(TX Ghost). SCARA + 리니어 축 + 그리퍼 + 다중 카메라. 하루 최대 1,000병·캔, **자동 성공률 98%** |
| 양팔 근거 | **약함(B0)** — 원본이 단팔이다. 양팔로 하려면 "안정화 팔이 앞 상품을 눌러 두고 작업 팔이 뒤에 채운다" 같은 구성을 따로 만들어야 한다 |
| 학습 근거 | 중간 |
| 하드웨어 | 음료캔 350g은 경계. 소형 용기로 대체 필요 |
| 판정 | 명확 |
| **아키텍처 근거** | **여기가 진짜 가치다** — Telexistence는 **AI가 98%를 처리하고 나머지는 원격 조작자가 VR로 개입**한다. 우리가 설계한 HIL(사람 개입) 루프와 **똑같은 구조가 상용으로 돌고 있다** |

**결론**: 태스크로는 양팔 근거가 약해 추천하지 않는다. 다만 **"자율 + 사람 개입" 아키텍처의 상용 근거**로 인용할 가치가 크다. 어느 태스크를 고르든 이 사례는 발표에 넣는다.

## 후보 D. 의류 행거 걸기·분류

옷을 행거에 걸고 분류한다.

| 항목 | 내용 |
|---|---|
| 원본 | 의류 물류 자동화. 행거에 매달린 옷을 컨베이어로 옮기며 카메라·센서가 태그를 읽어 분류한다. **반품 처리에서 경쟁 우위**로 꼽힌다 |
| 양팔 근거 | **B2** — 옷의 두 어깨를 동시에 잡아야 행거에 제대로 걸린다. 한쪽만 잡으면 옷이 흘러내린다 |
| 학습 근거 | **높음** — 2D 유연물. SpeedFolding 등 양팔 의류 조작 학습 연구가 활발하다 |
| 하드웨어 | 옷 100~300g은 경계. **얇은 티셔츠·손수건급으로 축소** 필요 |
| 판정 | 보통 — "제대로 걸렸는가"의 정의가 필요(어깨 정렬 각도로 측정 가능) |

**난점**: 2D 유연물이라 자기가림 문제가 있다. 다만 행거 걸기는 접기보다 단순하다.

## 후보 E. 모종 이식

육묘 트레이에서 모종을 뽑아 다른 트레이·화분에 옮긴다.

| 항목 | 내용 |
|---|---|
| 원본 | 스마트팜 육묘 자동화. **아이오크롭스**(R4 국내 실측)가 "원격 제어 + 반복된 모방 학습으로 점차 완전 자율"을 로드맵으로 명시한 회사다 |
| 양팔 근거 | **B2** — 안정화 팔이 트레이나 모종 줄기를 잡아 주고 작업 팔이 뿌리째 뽑아 옮긴다. 고정 없이 당기면 줄기가 끊어진다 |
| 학습 근거 | **매우 높음** — 식물은 개체마다 형상·크기·강도가 다르다. 규칙으로 쓸 수 없다 |
| 하드웨어 | **최적** — 모종은 수 g. 회전 불필요. 백래시를 유연한 줄기가 흡수 |
| 판정 | 명확 — 이식 성공, **줄기 손상 여부**가 좋은 품질 지표 |
| 국내 맥락 | **아이오크롭스가 텔레옵+모방학습을 실제 로드맵으로 쓴다** — 우리 접근과 같은 방향 |

**난점**: 살아 있는 식물을 반복 실험에 쓰기 어렵다. **인조 모종으로 대체**하면 학습 필수성(개체차)이 약해진다. 이 절충이 핵심 리스크다.

## 후보 F. 약 소분·블리스터 개봉

블리스터 팩에서 알약을 꺼내 분류·소분한다.

| 항목 | 내용 |
|---|---|
| 원본 | 약국·병원 조제 자동화. 기존 자동조제기(ATC)는 있지만 **블리스터 개봉은 사람이 한다** |
| 양팔 근거 | **B2** — 안정화 팔이 팩을 고정하고 작업 팔이 알약을 밀어낸다. 고정 없이 누르면 팩이 밀린다 |
| 학습 근거 | 중간 — 팩 형상이 제품마다 다르고 알약이 튄다 |
| 하드웨어 | **최적** — 매우 가볍고 회전 불필요 |
| 판정 | **명확** — 알약이 나왔는지, 파손됐는지 |

**난점**: 실제 의약품을 쓸 수 없으니 모사품이 필요하다. 다만 블리스터 팩 자체는 문구용으로 구할 수 있다.

## 후보 G. 반품 검수·재포장

반품된 상품을 꺼내 상태를 확인하고 재포장한다.

| 항목 | 내용 |
|---|---|
| 원본 | 이커머스 반품 처리. 물류에서 자동화가 가장 안 된 구간 중 하나 |
| 양팔 근거 | B1~B2 — 안정화 팔이 상품을 잡고 작업 팔이 뒤집어 검사, 포장재 조작 |
| 학습 근거 | **높음** — **반품은 상태가 매번 다르다.** 포장이 뜯긴 정도, 내용물 배치가 제각각 |
| 하드웨어 | 상품 선정에 따라 조절 가능 |
| 판정 | 보통 — "검수"의 정의가 필요 |

**난점**: 태스크 경계가 흐릿하다. 무엇까지가 검수인지 정의해야 한다.

### 권고 순위

**1위 — E. 모종 이식.** 하드웨어 궁합이 가장 좋고(수 g, 회전 불필요), 학습 필수성이 압도적이며(식물 개체차), **아이오크롭스가 "텔레옵 + 모방학습"을 실제 로드맵으로 쓰는 국내 회사**라 연결도 있다. 리스크는 살아 있는 식물의 실험 반복성이다.

**2위 — A. 전자제품 분해.** Apple Daisy라는 강력한 원본과 순환경제 서사가 있다. "분해는 조립보다 어렵다 — 대상 상태가 매번 다르기 때문"이라는 논리가 학습 필요성을 자연스럽게 설명한다. 나사를 피해 클립 결합 제품으로 한정하면 하드웨어도 통과한다.

**3위 — F. 약 소분.** 하드웨어와 판정이 가장 깔끔하지만 학습 필수성이 중간이다.

**C(선반 진열)는 태스크로 추천하지 않되, 어느 태스크를 고르든 발표에 인용한다** — 자율 98% + 사람 VR 개입이라는 구조가 우리 HIL 설계의 상용 근거이기 때문이다.

**B(신발)는 무게가 관건이다.** 아동화급으로 축소하면 가능하지만 원본과의 연결이 흐려진다.
