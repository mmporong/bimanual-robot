# R9 — 엔드이펙터 구성 검토: 석션 도입

작성 2026-08-20 · 계기: 그리퍼 대신 진공 흡착을 쓰는 안 검토 요청

## 결론 먼저

**석션은 회전 토크를 전달하지 못한다.** 흡착판은 축 방향으로만 힘을 받고 비틀림에는 미끄러진다. 따라서 **석션을 쓰면 뚜껑 개폐 태스크가 성립하지 않는다** — 지금 확정한 프로젝트 정의와 정면으로 상충한다.

**그런데 SO-101 그리퍼에는 실측된 심각한 약점이 있다.** 파지 닫힘에 약 15초가 걸리고 과부하 보호가 빈발한다. 200 에피소드에 개폐가 4회씩만 들어가도 **그리퍼 대기에만 3시간 넘게** 쓴다. 석션은 밸브 전환이라 수백 ms다.

**결론은 구성을 바꾸는 것이 아니라 태스크를 구성에 맞춰 고르는 것이다.** 셋 중 하나를 택해야 하고, 각각 다른 프로젝트가 된다.

| 구성 | 가능한 프로젝트 | 원본 |
|---|---|---|
| 그리퍼 2 | 용기 개폐 (회전 필요) | ABB YuMi 실험실 워크스테이션 |
| **석션 2** | **봉지·파우치 벌려 담기** | 물류 파우치 패킹, 식품 포장 |
| 석션 1 + 그리퍼 1 | 고정은 흡착, 조작은 파지 | 비대칭 양팔 — 실제 연구 주제 |

## 1. 석션의 물리 — 무엇이 되고 무엇이 안 되나

| 항목 | 석션 | 평행 그리퍼 |
|---|---|---|
| **회전 토크 전달** | **불가** (비틀면 미끄러짐) | 가능 |
| 평면·매끈한 표면 | **강함** | 약함 (얇은 것은 집기 어려움) |
| 다공성·불규칙 표면 | 불가 (천, 그물, 곡면) | 가능 |
| 얇은 시트·비닐 | **강함** | **매우 어려움** |
| 측면(전단) 힘 | 약함 | 강함 |
| 파지 위치 정밀도 | **낮아도 됨** (넓은 면 아무데나) | 높아야 함 |
| 파지·해제 속도 | **밸브 전환, 수백 ms** | SO-101 실측 **약 15초** |
| 추가 하드웨어 | 진공 펌프 + 솔레노이드 밸브 + 튜브 | 없음 (서보 내장) |

### SO-101 그리퍼의 실측 약점

기존 실물 작업에서 확정된 사항이다.

- **닫힘 정착에 약 15초** — 고정 sleep으로 짧게 주면 덜 문 채 들어올려 실패한다
- **과부하 보호가 빈발** — 파지 후 목표를 현재값으로 되쓰지 않으면 계속 쥐어짜다 보호가 걸려 열기 명령이 거부된다
- **열기 전 보호해제 goto 필요** — 현재값 재전송으로 플래그를 풀어야 한다
- 절대각 명령만 안전 (delta 방식은 이중 개방 사고를 낸다)

**사이클 타임 계산**: 에피소드당 그리퍼 개폐 4회 × 15초 = 60초. 200 에피소드면 **3.3시간이 그리퍼 대기**다. 순수 조작 시간(100분)보다 대기가 두 배 길다.

석션이면 4회 × 0.3초 = 1.2초. **에피소드당 약 1분을 회수한다.**

## 2. 구성별 가능 태스크

### A. 그리퍼 2개 (현재 확정안)

용기 개폐가 가능한 유일한 구성이다. 회전 반작용이라는 양팔 근거가 가장 명확하다.

- 원본: ABB YuMi 실험실 워크스테이션
- 양팔 근거: 반작용 토크 (한 손이면 용기가 같이 돌아감)
- 약점: **사이클 타임, 과부하 보호, 미끄러짐**

### B. 석션 2개

**킬러 태스크는 봉지 입구 벌리기다.**

비닐봉지의 양쪽 면을 각각 흡착한 뒤 서로 반대로 당기면 입구가 벌어진다. 한 면만 잡으면 봉지가 열리지 않으므로 **단팔로는 원천 불가능하고, 고정을 놓는 순간 입구가 닫히므로 시간 분리도 불가능하다.** B2 등급이 물리적으로 보장된다.

그리고 이건 그리퍼로는 애초에 어려운 작업이다. 얇은 비닐은 평행 그리퍼로 집기가 매우 까다롭다. **석션이 아니면 성립하지 않는 태스크**라, 엔드이펙터 선택 자체가 설계 논거가 된다.

| 시퀀스 | 등급 |
|---|---|
| 1. 봉지 더미에서 한 장 분리 (석션으로 상단 한 장만 흡착) | B0 — 석션의 전형적 강점 |
| 2. **양팔이 봉지 양면을 흡착 후 이격해 입구 개방** | **B2** |
| 3. 개방 유지 상태에서 물품 투입 | B1 (제3의 수단 필요) |
| 4. 흡착 해제 후 봉지 밀봉·이송 | B1 |

3단계가 문제다. 양팔이 봉지를 벌리고 있으면 물건을 넣을 팔이 없다. 해법 둘 중 하나다 — 벌린 상태에서 흡착을 유지한 채 한 팔만 놓고 투입하거나(입구가 반쯤 닫힘), 물품을 미리 배치해 두고 봉지를 물품 위로 씌우는 순서로 뒤집는다.

- 원본: 물류 파우치 패킹, 식품 포장 자동화
- 양팔 근거: 양면을 동시에 당겨야 열림
- 약점: **투입 단계에서 팔이 부족하다**

### C. 석션 1 + 그리퍼 1 (비대칭)

**이 구성이 3단계 문제를 푼다.** 그리고 그 자체로 설계 논점이 된다.

한 팔은 흡착으로 대상을 고정·유지하고, 다른 팔은 그리퍼로 조작한다. 역할이 구조적으로 분리되므로 **좌우가 대칭이 아닌 양팔**이 된다. 이종 엔드이펙터 양팔(heterogeneous bimanual)은 실제 연구 주제이기도 하다.

| 시퀀스 | 석션 팔 | 그리퍼 팔 | 등급 |
|---|---|---|---|
| 1. 봉지를 작업대에 고정 | 봉지 한 면 흡착·유지 | — | B0 |
| 2. **입구 개방** | 한 면을 당겨 유지 | 반대 면을 집어 반대로 당김 | **B2** |
| 3. **물품 투입** | 개방 유지 | 물품을 집어 넣음 | **B2** |
| 4. 밀봉·이송 | 해제 | 봉지 상단 파지 후 이송 | B1 |

2·3단계 모두 B2다. 석션 팔이 상태를 유지하는 동안 그리퍼 팔이 작업하는 구조라, **"한 팔이 작업 가능한 상태를 만들고 다른 팔이 그 위에서 작업한다"는 양팔의 공통 패턴에 정확히 부합한다.**

- 원본: 물류 파우치 패킹 (실제 라인에서 석션과 파지를 혼용)
- 양팔 근거: 유지와 조작의 역할 분리
- 강점: 그리퍼 개폐 횟수가 절반으로 줄어 사이클 타임 개선
- 논점: **"왜 두 팔이 다른 도구인가"** — 설계 의사결정 자체가 산출물이 된다

## 3. 구현 방법

### 하드웨어

석션 그리퍼는 DIY 로봇팔용으로 상용 판매된다(싱글·듀얼·쿼드 컵). SO-100/101용 옵션 엔드이펙터도 유통된다. 진공원은 둘 중 하나다.

- **소형 다이어프램 펌프 + 솔레노이드 밸브** — 압축공기 불필요, 소음 있음, 전원 필요
- **주사기식 자작 진공원** — 저비용이지만 유량이 작아 반복 작업에 부적합

밸브 제어는 릴레이나 MOSFET으로 GPIO에서 켜고 끈다.

### LeRobot 액션 공간에 태우기

**그리퍼 서보를 떼고 그 자리에 석션 밸브를 매핑하면 데이터 스키마를 바꾸지 않아도 된다.**

LeRobot의 SO 팔로워는 `gripper` 축을 `RANGE_0_100`으로 정규화한다. 석션 팔에서는 이 값을 임계로 이진화해 밸브를 켜고 끄면, 액션 벡터의 형태가 그대로 유지된다.

```
action["left_gripper.pos"]  → 임계 50 기준 → 밸브 ON/OFF
action["right_gripper.pos"] → 기존 그리퍼 서보 그대로
```

`bi_so_follower`가 좌우에 각각 별도의 `SOFollowerConfig`를 받는 구조라, 좌우를 다르게 구성하는 것이 설정 수준에서 이미 열려 있다. 다만 좌우가 같은 `SOFollower` 클래스를 쓰므로 **석션 팔용 래퍼를 따로 만들어야 한다** — 이건 커스텀 코드이고, 회의에서 나온 "라이브러리만 쓰면 클론한 것처럼 보인다"는 우려에 대한 답이 된다.

## 4. 권고

**석션 1 + 그리퍼 1 (구성 C)를 권한다.**

| 축 | 판단 |
|---|---|
| 양팔 필수성 | B2가 두 단계(개방·투입)에서 물리적으로 보장된다 |
| 하드웨어 적합 | 얇은 비닐은 석션이 아니면 다루기 어렵고, 물품 파지는 그리퍼가 낫다. **각 도구를 강점에만 쓴다** |
| 사이클 타임 | 그리퍼 개폐 횟수가 절반으로 줄어 수집 시간이 크게 준다 |
| 설계 논점 | "왜 비대칭인가"가 그 자체로 설명할 거리다. 대칭 구성에는 없는 서사 |
| 커스텀 코드 | 석션 래퍼가 LeRobot에 없는 부분이라 자기 코드가 들어간다 |
| 리스크 | 진공 펌프·밸브·배선 추가. 하드웨어 셋업 시간이 늘어난다 |

**다만 구성 A(그리퍼 2)를 완전히 버리지 않는다.** 용기 개폐는 회전 반작용이라는 가장 깔끔한 양팔 근거를 갖고 있고, 추가 하드웨어가 필요 없다. **엔드이펙터를 바꿔 끼울 수 있게 설계하면 두 태스크를 같은 파이프라인에서 비교할 수 있다** — 그러면 "엔드이펙터 구성에 따라 어떤 태스크가 가능해지는가"라는 실험 자체가 산출물이 된다.

### 절충안

1. **구성 A로 먼저 시작한다** (추가 하드웨어 없음). T1 이송과 T2 용기 개폐로 파이프라인을 관통시킨다
2. 석션 하드웨어를 병행 조달·조립한다
3. **구성 C로 전환해 봉지 태스크를 추가**한다. 같은 파이프라인, 다른 엔드이펙터
4. 두 구성의 성공률·사이클 타임을 같은 프로토콜로 비교한다

이렇게 하면 석션 조달이 늦어져도 프로젝트가 멈추지 않고, 성공하면 **"엔드이펙터 구성 비교"라는 축이 하나 더 생긴다.**

# ✎ 2026-08-21 보강 — 석션 재조사

주제가 커넥터 체결로 바뀐 뒤 석션을 다시 조사했다. 새로 확인된 것을 추가한다.

## 1. 석션이 물류 표준인 이유 (네 가지)

업계 자료가 드는 근거다. 앞서 우리는 ①만 알고 있었다.

| # | 이유 |
|---|---|
| ① | **평면 물체 파지가 쉽다** — 박스처럼 평평한 큰 물체 |
| ② | **계산이 싸다** — 흡착은 **한 점·한 자세로 파지가 결정**되므로 파지 계획 연산이 크게 준다. 평행 그리퍼는 접근 각도·개폐 폭·접촉점을 다 풀어야 한다 |
| ③ | **큰 물체 안정성** — 다중 흡착컵으로 넓은 면을 잡으면 자세가 안정된다 |
| ④ | **양팔 사이클 타임** — 좌우 흡착을 독립 제어하면 사이클이 짧아진다 |

**②가 우리에게 새롭다.** 파지 계획을 학습에 맡기는 대신 **흡착점 하나만 고르면 되므로 정책이 풀어야 할 문제가 줄어든다.** 데이터가 적을 때 유리하다.

## 2. 상보성 — 업계가 명시하는 것

> **평행 그리퍼 파지와 실리콘 흡착컵 파지는 서로 보완적이다.** 전자는 작은 물체를, 후자는 평면이 있는 큰 물체를 쉽게 집는다. 둘을 결합하면 **다양한 기하·재질에 대한 적응력이 올라간다.**

우리가 R9에서 제안한 **비대칭 구성(석션 1 + 그리퍼 1)**이 이 상보성을 하드웨어로 구현한 형태다.

## 3. Ambidextrous 파지 — 비대칭 구성의 학술 근거

**어느 손으로 잡을지 정책이 고르는 것**이 연구 주제로 존재한다.

| 논문 | 내용 |
|---|---|
| **Learning Tri-mode Grasping for Ambidextrous Robot Picking** `2302.06431` | 파지 모드 세 가지(그리퍼·석션·복합)를 학습으로 선택 |
| **Combined Task and Motion Planning for a Dual-arm Robot to Use a Suction Cup Tool** `1909.00192` | 양팔 로봇이 **석션 컵을 도구로 집어 사용**하는 태스크·모션 통합 계획 |
| **A Dual-Arm Robot that Manipulates Heavy Plates Cooperatively with a Vacuum Lifter** `2203.10585` | 양팔 + 진공 리프터로 무거운 판을 협응 조작 |
| **Multiple-object Grasping Using a Multiple-suction-cup Vacuum Gripper in Cluttered Scenes** `2304.10693` | 다중 흡착컵으로 어질러진 장면에서 여러 물체를 동시에 |
| **Fast Object Learning and Dual-arm Coordination for Cluttered Stowing, Picking, and Packing** `1810.02977` | 양팔 협응 + 빠른 물체 학습 |

**"어느 손을 쓸지 학습이 고른다"가 그 자체로 주제가 될 수 있다.** 대칭 양팔에는 없는 문제이고, 비대칭 구성에서만 생긴다.

## 4. 석션이 풀어주는 기존 조건

앞서 "조건" 때문에 밀린 후보 중 석션으로 조건이 사라지는 것들이다.

| 후보 | 종전 조건 | 석션 도입 시 |
|---|---|---|
| **보호필름 박리** | **얇은 모서리를 그리퍼로 못 집음** | **면으로 흡착한다 — 조건 해소.** 테솔로 원본도 4지 그리퍼로 같은 문제를 푼다 |
| **봉지 열어 담기** | 얇은 비닐을 그리퍼로 못 집음 | 양면 흡착 후 이격 — 조건 해소 |
| **종이·카드 한 장 분리** | 얇은 것 분리 | 석션이 산업 표준 해법 |
| 시트·평판 이송 | (미검토) | 새로 열림 |
| 박스 플랩 열기 | (미검토) | 새로 열림 |
| 라벨·스티커 부착 | 얇은 것 파지 | 새로 열림 |

**필름 박리의 유일한 하드웨어 조건이 석션으로 사라진다.** 남는 건 필름 소모품 문제뿐이다.

## 5. 커넥터 체결(현행 주제)과 석션의 관계

**커넥터에는 석션이 맞지 않는다.** 커넥터 하우징은 요철이 있고 곡면이라 흡착이 안 되고, 체결에는 축 방향 밀기 힘이 필요한데 석션은 전단·비틀림에 약하다.

다만 **주변 작업에는 쓸 수 있다** — 커넥터가 놓인 트레이를 옮기거나, 배선 정리용 시트를 다루는 보조 작업.

## 6. 갱신된 권고

| 구성 | 언제 |
|---|---|
| **그리퍼 2** | **커넥터 체결(현행 주제)** — 요철 파지가 필요하므로 유일한 선택 |
| **석션 1 + 그리퍼 1** | **필름 박리·봉지·시트 계열로 전환할 때.** Ambidextrous 파지라는 축이 덤으로 생긴다 |
| 석션 2 | 평면 물체 양면 취급 전용. 범용성이 낮아 우선순위 낮음 |

**석션 조달은 주제와 무관하게 해두는 편이 낫다.** 필름·봉지·시트 계열로 전환할 가능성이 남아 있고, 조달·조립에 시간이 걸린다.
