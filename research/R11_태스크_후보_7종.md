# R11 — 태스크 후보 7종 비교

작성 2026-08-20 · 전제: SO-101 2세트(5축+그리퍼, 리치 346mm, 페이로드 수백 g, 회전 토크 전달 취약, 그리퍼 닫힘 15초)

## 평가 축

후보마다 다섯 가지를 본다. **양팔 필수성**과 **학습 필수성**이 동시에 높아야 프로젝트가 선다. 하나만 높으면 "왜 양팔인가" 또는 "왜 학습인가" 중 하나에 답을 못 한다.

| 축 | 판정 기준 |
|---|---|
| 양팔 | B2(동시 협응) / B1(순차) / B0(병렬 — 양팔 근거 없음) |
| 학습 | 규칙으로 못 쓰는 정도. 유연물·물성 변동이 크면 높음 |
| 산업 | 실제 회사가 미해결로 두고 있는가. 국내 회사면 가점 |
| HW | 우리 하드웨어에서 되는가 |
| 판정 | 성공/실패를 이진으로 셀 수 있는가 |

---

## 후보 1. 와이어 하네스 라우팅 ★

케이블을 하네스 보드의 지정 경로에 배치하고 클립에 끼운다.

| 축 | 평가 |
|---|---|
| 양팔 | **B2** — 케이블은 한쪽만 잡으면 나머지 형상이 미정. 양쪽에 장력을 걸어야 형상이 결정되고, 놓는 순간 무너진다 |
| 학습 | **매우 높음** — 유연물. 게다가 고혼합 환경에서는 **코봇을 계속 재프로그래밍해야 해서 생산성 이득이 깎인다**는 것이 업계가 지적하는 한계다. 학습이 정확히 그 문제를 겨냥한다 |
| 산업 | **최상** — **와이어 하네스 조립 작업의 약 90%가 수작업**이다. 고도 커스터마이즈 제품이라 기존 자동화가 비용 효율이 안 난다 |
| HW | 회전 불필요 · 케이블 수십 g · 백래시를 케이블이 흡수 · 얇아서 그리퍼 완전 폐쇄 불필요 |
| 판정 | **명확** — 클립 삽입 여부는 이진. 경로 이탈은 비전으로 mm 측정 |

연구 동향도 정합한다. 엉킨 하네스를 **양팔 + 동적 조작**으로 푸는 연구가 성공률 91.2%를 보고했고, 자동차용 다분기 하네스 양팔 조립 시스템이 연구 중이다.

**난점**: 케이블 더미에서 한 가닥만 집기(여러 가닥 딸려옴). L1에서는 분리 배치로 회피.

---

## 후보 2. 케이블 타이 묶기 ★

케이블 다발을 케이블 타이로 묶고 조인다.

| 축 | 평가 |
|---|---|
| 양팔 | **B2** — 한 팔이 다발을 모아 쥐고 있어야 다른 팔이 타이를 두를 수 있다. 놓으면 다발이 흩어진다 |
| 학습 | 높음 — 다발 형상이 매번 다르다 |
| 산업 | **강함 + 인체공학 근거** — **케이블 타이 배치가 하네스 작업자에게 인체공학 문제를 가장 많이 일으키는 공정**이다(반복성·부자연스러운 자세). 협동로봇 도입 사례 연구가 비인체공학적 자세를 크게 줄였다고 보고한다 |
| HW | 회전 불필요. 다만 **타이를 조이는 힘**이 관건 |
| 판정 | 명확 — 묶였는지 이진, 조임 정도는 다발 지름으로 측정 |

**"사람이 다치는 작업을 로봇이 대신한다"**는 서사가 붙는다. 발표에서 강한 도입부다.

**난점**: 타이를 당겨 조이는 동작에 힘이 필요하다. 타이 헤드를 통과시키는 정밀도도 요구된다. **후보 1의 확장 단계로 두는 것이 안전하다.**

---

## 후보 3. 보호필름 박리 ★★ (국내 회사 직결)

디스플레이 패널이나 부품에 붙은 보호필름을 벗긴다.

| 축 | 평가 |
|---|---|
| 양팔 | **B2** — 한 팔이 제품을 눌러 고정하지 않으면 필름을 당길 때 제품이 딸려온다. 실제 특허도 **양쪽에서 두 개의 필러가 모서리를 잡고 회전시키며 벗기는** 구성을 쓴다 |
| 학습 | 높음 — 접착력과 필름 상태가 매번 다르다. 너무 빠르면 찢어지고 느리면 안 벗겨진다. **힘·속도 조절이 규칙으로 안 잡힌다** |
| 산업 | **최상 + 국내 직결** — **테솔로가 2025년 8월 DG-4F 4지 그리퍼로 디스플레이 필름 박리 자동화 솔루션을 발표**했다. 테솔로는 R4 국내 공고 실측에도 잡힌 회사다 |
| HW | 회전 불필요(들어올리며 벗김) · 필름은 무게 없음 · **모서리를 집는 파지가 관건** |
| 판정 | **명확** — 벗겨졌는지, 찢어졌는지 이진 판정 |

**국내 회사가 지금 이 문제를 풀고 있고, 그 회사가 채용 실측에 잡혀 있다.** "테솔로가 4지 그리퍼로 푸는 문제를, 저는 양팔 협응과 학습으로 접근했습니다"는 면접에서 강한 문장이다.

**난점**: 필름 모서리를 집는 것이 어렵다. 그리퍼로 얇은 필름 끝을 집기가 까다로워 **석션이나 전용 픽 도구가 유리**하다. 시작 탭(들린 모서리)을 미리 만들어두면 L1에서 회피 가능하다.

## 후보 4. 봉지 열어 담기

파우치를 벌리고 물품을 투입한다.

| 축 | 평가 |
|---|---|
| 양팔 | **B2** — 양면을 반대로 당겨야 열린다. 한 면만 잡으면 안 열린다 |
| 학습 | 높음 — 2D 유연물, 봉지가 매번 다르게 구겨진다 |
| 산업 | 강함 — 식품 포장, 물류 파우치 패킹 |
| HW | **석션 필요** — 얇은 비닐은 평행 그리퍼로 집기 어렵다 |
| 판정 | 보통 — "열렸다"의 정의가 필요(개구 폭 mm로 측정 가능) |

**난점**: 양팔이 벌리고 있으면 투입할 팔이 없다. **석션 1 + 그리퍼 1 비대칭 구성**이 이 문제를 푼다(R9). 석션 조달 기간이 변수다.

---

## 후보 5. 튜브 연결 (의료·바이오 공정)

실리콘 튜브를 피팅이나 커넥터에 끼운다.

| 축 | 평가 |
|---|---|
| 양팔 | **B2** — 한 팔이 피팅을 고정하지 않으면 밀어 넣을 때 밀린다 |
| 학습 | 중간~높음 — 1D 유연물이지만 삽입 자체는 규칙성이 있다 |
| 산업 | 중간 — 의료기기 조립, 바이오 공정 배관. **국내 회사 근거는 확인 안 됨** |
| HW | 회전 불필요 · 가벼움 · 삽입 정밀도가 필요하나 튜브가 유연해 오차를 흡수 |
| 판정 | **명확** — 끼워졌는지 이진, 삽입 깊이 mm 측정 |

후보 1과 성격이 비슷하면서 삽입 요소가 강하다. **후보 1의 T4(커넥터 삽입)와 사실상 같은 동작**이라, 독립 프로젝트보다는 후보 1의 한 단계로 흡수하는 것이 낫다.

## 후보 6. 스냅핏 조립

플라스틱 부품을 눌러 끼운다(딸깍 결합).

| 축 | 평가 |
|---|---|
| 양팔 | **B2** — 한 팔이 하부 부품을 고정하고 다른 팔이 상부를 눌러 끼운다 |
| 학습 | **낮음** — 강체이고 위치가 정해지면 규칙으로 가능. **학습을 쓸 이유를 따로 만들어야 한다** |
| 산업 | 중간 — 가전·완구 조립. ABB YuMi의 소형 부품 조립과 같은 계열 |
| HW | 회전 불필요 · 다만 **누르는 힘**이 필요하고 백래시에 취약 |
| 판정 | 명확 — 결합 여부 이진 |

**학습 필수성이 약한 것이 결정적 약점**이다. 뚜껑·커넥터와 같은 부류다.

## 후보 7. 종이·카드 한 장 분리

더미에서 한 장만 집어 분류한다.

| 축 | 평가 |
|---|---|
| 양팔 | **B1** — 한 팔이 더미를 눌러 고정하고 다른 팔이 한 장을 당긴다. 다만 지그로 대체 가능해 근거가 약하다 |
| 학습 | 중간 — 정전기·마찰이 변수 |
| 산업 | 중간 — 문서 처리, 카드 발급, 인쇄 |
| HW | **석션이 유리** |
| 판정 | 명확 — 한 장인지 여러 장인지 |

**양팔 근거가 약하다.** 실제 산업에서는 석션 한 개와 지그로 푼다.

### 권고

**후보 1(보호필름 박리)과 후보 2(와이어 하네스)를 놓고 고른다.**

- **보호필름**은 국내 회사(테솔로)가 지금 풀고 있는 문제라 **채용 연결이 가장 직접적**이다. 다만 얇은 필름 모서리 파지가 하드웨어 난점이다
- **와이어 하네스**는 **하드웨어 궁합이 가장 좋고** 학습 필수성이 가장 높다. 산업 근거도 "90% 수작업"으로 명확하다

**둘을 합치는 길도 있다.** 하네스 조립 공정에는 보호 슬리브·테이프 작업이 포함되므로, "전장 조립 셀"이라는 하나의 셀 안에서 케이블 라우팅(후보 2) → 케이블 타이(후보 3)를 태스크 계단으로 두고, 여력이 되면 필름 박리를 별도 태스크로 추가할 수 있다. 전부 같은 파이프라인·같은 측정 프로토콜을 쓴다.

### 탈락 사유 요약

- **뚜껑 개폐 · 스냅핏 · 커넥터 단독**: 강체라 규칙으로 풀 수 있어 학습 필수성이 약하다. 뚜껑은 회전 토크 전달 문제까지 있다
- **천 접기**: 2D 유연물이라 자기가림으로 난이도가 급증한다. 최신 파운데이션 모델이 최근에야 80%대를 냈다
- **종이 분리**: 양팔 근거가 약하다
