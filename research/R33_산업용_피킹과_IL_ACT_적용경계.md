# 산업용 피킹과 IL·ACT 적용 경계

- 조사일: 2026-09-08
- 목적: 산업용 피킹에서 모방학습을 쓰는 범위와 휴머노이드·범용 조작에서의 차이를 확인하고,
  물 서빙 로봇의 `PLANNED / ACT / HYBRID` 비교 구조를 정한다.

## 판정 요약

| 질문 | 판정 | 근거 수준 |
|---|---|---|
| 산업용 물체 피킹에서 AI를 사용하지 않는가 | 아니다. 인식·깊이 복원·피킹 순서·그립 후보 계산에 널리 사용한다 | 공식 제품 자료 확인 |
| 산업용 피킹이 사람 시연 기반 IL로 관절 동작 전체를 만드는가 | 공개된 대표 구조는 비전 AI와 경로계획·로봇 제어를 결합한 모듈형이다 | 공식 자료로 구조 확인, 전체 업계 빈도는 확인 안 됨 |
| 씨메스로보틱스가 IL을 전혀 사용하지 않는가 | 공개 자료만으로는 단정할 수 없다 | 학습 방법 비공개 |
| 휴머노이드에서는 IL·VLA 비중이 더 큰가 | 범용 작업·전신 협응을 다루기 위해 학습형 행동 정책의 범위가 더 넓다 | Figure·RT-1 공식 자료 확인 |
| 물 서빙 로봇에 전체 ACT가 필수인가 | 아니다. 고정 station·컵·물통 조건에서는 PLANNED 기준선이 먼저다 | 프로젝트 조건에 대한 공학적 판정 |
| 전체 PLANNED·전체 ACT·HYBRID를 모두 비교할 수 있는가 | 가능하다. phase별 공통 인터페이스와 정지 상태 전환이 필요하다 | 구현 설계 판정 |

## 1. 용어를 먼저 분리한다

### 산업용 티칭

작업자가 티치 펜던트나 hand-guiding으로 웨이포인트·자세·프로그램을 기록한다. 기록한 경로를
결정론적으로 재생하는 방식이며, 새로운 상황에 일반화하는 신경망을 학습한다는 뜻은 아니다.

### 학습형 인식·그립 선택

신경망이 영상이나 point cloud에서 물체, 깊이, 그립 후보의 성공 가능성, 피킹 순서를 계산한다.
그 뒤의 관절 경로는 IK·모션 플래너·산업용 제어기가 만들 수 있다. AI를 사용하지만 사람의
관절 시연을 모방하는 IL과는 다르다.

### 모방학습 IL·ACT

사람이 조작한 관측·행동 시계열에서 정책을 학습한다. ACT는 현재 영상·관절 상태에서 여러
스텝의 관절 행동 묶음을 예측한다. 정책이 학습 분포 밖의 상태에서 시작하면 누적 오차와
잘못된 단계 진행이 발생할 수 있다.

### End-to-End

산업 자료의 `End-to-End`는 고객 공정 전체를 제공하는 턴키 서비스나 인식부터 실행까지의
전체 파이프라인을 뜻할 수 있다. `pixels-to-joints` 단일 신경망을 의미하는지 별도로 확인해야
한다.

## 2. 씨메스로보틱스 공개 자료에서 확인되는 구조

씨메스로보틱스의 피스피킹 공식 설명은 다음 구성요소를 하나의 셀로 묶는다.

- AI 기반 3D 비전
- 물체의 위치·형태·재질 인식
- 최적 피킹 포인트 계산
- 현장 맞춤형 그리퍼
- 산업용 또는 협동 로봇
- PLC, 바코드 스캐너, 원격 모니터링
- 실패 시 리커버리 플랜

CTO 발표 요약에서는 AI Depth, 물체 사이 관계, 멀티모달 피킹 순서 결정 모델, 그리퍼에 맞는
피킹 포인트 계산을 설명한다. 팔레타이징은 3D Vision·스태킹 알고리즘·정밀 로봇 제어로
구성한다고 밝힌다.

이 공개 설명은 AI를 쓰지 않는 구조가 아니라 **AI 인식·판단과 정밀 로봇 제어를 분리해
결합한 구조**에 가깝다. 그러나 학습 데이터가 사람의 관절 시연인지, 합성·지도학습·자기지도
데이터인지 공개하지 않았으므로 씨메스가 IL을 전혀 쓰지 않는다고 단정하지 않는다.

## 3. 다른 산업용 피킹 제품과의 대조

ABB Item Picking은 사전 학습된 AI 비전이 물체를 식별하고, 별도 모션 플래닝 소프트웨어가
각 pick/place 경로를 충돌 없이 계획한다. 로봇·그리퍼·카메라·애플리케이션 제어기를 한
플랫폼으로 통합한다.

FANUC iRVision 3D Guidance는 3D 센서와 CAD 매칭으로 부품 위치·자세를 찾고, 로봇 제어기가
그 결과로 동작을 보정한다. 정밀 지그 없이 bin picking·pick-and-place를 수행하는 모듈형
구조다.

Dex-Net 2.0은 딥러닝 그립 모델의 대표 사례지만 사람 시연 IL이 아니다. 3D 모델과 물리 기반
그립 지표로 670만 개의 합성 point cloud·grasp 쌍을 만들고 GQ-CNN을 학습한다. 따라서
`학습형 피킹 = 모방학습`으로 묶으면 안 된다.

이 사례들로 전체 산업의 사용 빈도를 통계적으로 확정할 수는 없다. 다만 상용 제품의 공개
구조가 학습형 인식·그립 선택과 검증된 경로계획·제어를 결합한다는 점은 확인된다.

## 4. 휴머노이드·범용 조작에서 IL 범위가 넓어지는 이유

산업용 셀은 카메라·조명·지그·그리퍼·투입 위치를 로봇에 맞게 설계할 수 있다. 휴머노이드와
범용 모바일 매니퓰레이터는 사람 환경에서 많은 물체와 장기 작업을 처리해야 하므로 작업마다
경로와 상태기계를 손으로 만드는 비용이 커진다.

Figure Helix 02는 카메라·촉각·고유수용감각을 받아 전신 관절을 제어하는 학습형 계층을
사용한다. 사람 동작 데이터와 시뮬레이션 강화학습으로 전신 제어기를 학습하지만, 느린 의미
판단·빠른 시각운동 정책·1 kHz 전신 제어라는 계층은 유지한다.

Google RT-1은 13대 로봇에서 17개월 동안 수집한 13만 개 사람 원격조작 시연으로 700개 이상의
작업을 학습했다. 집기·놓기 자체가 IL에서 제외되는 것이 아니라, 많은 물체·환경·명령을 한
정책으로 일반화하려 할 때 큰 데이터 비용을 감수하고 사용하는 사례다.

따라서 구분 기준은 로봇 외형만이 아니다.

| 기준 | 산업용 피킹 셀 | 범용 휴머노이드 | 현재 물 서빙 로봇 |
|---|---|---|---|
| 작업 범위 | 좁은 공정·높은 반복성 | 다수 작업·장기 행동 | 물 서빙 한 태스크 |
| 환경 구조화 | 지그·조명·그리퍼로 적극 구조화 | 사람 환경을 수용 | station·컵·물통 고정 가능 |
| 이동·조작 관계 | 고정 베이스가 많음 | 전신 연속 협응 | 이동 후 베이스 정지 |
| 우선 목표 | 처리량·재현성·가동률 | 일반화·적응·전신 협응 | 작동 증거와 비교 실험 |
| 학습 정책 범위 | 인식·선택 중심인 공개 사례가 많음 | 행동·전신 제어까지 넓음 | phase별 비교가 적합 |

현재 물 서빙 로봇은 형태는 이동형 양팔이지만 운영 조건은 범용 휴머노이드보다 구조화된
산업용 셀에 가깝다.

## 5. ACT 원 논문이 겨냥한 범위

ACT 원 논문은 일반적인 pick-and-place를 broad-stroke motion으로 구분하고, 컵 뚜껑 열기,
배터리 삽입, 케이블 타이 끼우기처럼 밀리미터 오차·양손 접촉·폐루프 시각 협응이 필요한
fine manipulation을 대상으로 한다. 일부 작업에서 80~90%를 보고했지만 작업별 성능 차이,
사람 시연의 비정상성, 누적 오차를 한계로 함께 적는다.

따라서 `양팔이므로 ACT` 또는 `접촉이 있으므로 ACT`는 충분한 채택 근거가 아니다. 비전·IK·
시각 서보·그리퍼 피드백·폐루프 제어로 해결한 기준선보다 실제로 나은지를 같은 조건에서
확인해야 한다.

## 6. 프로젝트 적용 결정: 세 실행 전략

`policy 1`과 `policy 2`는 미션의 작업 구간 이름으로 유지하되, 그 안의 실행 방법은 별도
`control_strategy`와 phase별 `backend`로 기록한다.

### `PLANNED_ALL`

- RGB-D·YOLO로 대상과 자세를 계산한다.
- IK·사전 검증 궤적으로 접근·들기·반환·배치를 수행한다.
- 기울임 기준 궤적과 액면 피드백으로 붓는다.
- 그리퍼 부하·관절·충돌·물 양을 외부 감독기가 판정한다.

### `ACT_ALL`

- 주방 조작 phase를 모두 ACT checkpoint로 실행한다.
- 미션 상태기계, 베이스 이동, 안전, 물 양 독립 평가는 ACT 밖에 둔다.
- 하나의 긴 checkpoint와 phase별 checkpoint를 각각 실험할 수 있지만, 배포 비교의 기본은
  실패 위치와 전환을 분리할 수 있는 phase별 checkpoint다.

### `HYBRID`

- 기본 후보는 컵·물통 파지와 반환·배치를 `PLANNED`, 붓기 phase를 `ACT`로 둔다.
- 실험 결과에서 ACT 파지가 유리하면 마지막 접근·접촉 phase만 ACT로 교체할 수 있다.
- phase 경계에서 관절 속도 0, 허용 자세, command lease 해제·획득, 남은 action chunk 폐기를
  확인한다.

세 전략은 같은 미션 Action과 안전 계층을 사용한다. 두 backend가 같은 관절에 동시에 명령을
쓰거나 움직이는 중간에 교체하지 않는다.

## 7. HYBRID를 위해 새 모델이 필요한 경우

### phase별 순차 전환

별도 통합 신경망은 필요하지 않다. 미션 관리자가 phase별 backend를 선택한다. 기존 전체
시연에 phase timestamp가 있으면 구간을 잘라 로컬 ACT checkpoint를 학습할 수 있다.

다만 사람이 만든 phase 시작 상태와 IK가 만든 시작 상태가 다를 수 있다. 실제 IK 도착 상태에서
rollout한 뒤 분포 차이로 실패하면 해당 경계의 성공 시연이나 검토된 사람 개입 복구 데이터를
보강한다. 전체 데이터를 처음부터 다시 모으는 것이 아니라 필요한 phase만 갱신한다.

### 같은 제어 틱에서 더하는 residual 정책

`q_command = q_planned + delta_q_learned`처럼 두 출력을 수치적으로 합치려면 출력 의미가 다른
새 residual 정책과 별도 안정성 검증이 필요하다. 기존 절대 관절 목표 ACT를 그대로 더하면
안 된다. 현재 첫 구현에서는 residual 결합을 사용하지 않는다.

## 8. 공정한 비교와 채택 조건

세 전략은 같은 scenario matrix, 같은 시작 범위, 같은 컵·물통·보정표, 같은 안전 한계에서
평가한다.

- phase별 성공 횟수와 전체 실행 횟수
- 목표 물 양 오차와 `UNDER / OVER / SPILL / UNKNOWN`
- 사람 개입과 리커버리 횟수
- cycle time
- 관측→명령 적용 지연과 지터
- 위치·조명·초기 잔량 변화에 대한 성능
- 미학습 범위에서의 안전 거부
- 물체·station 변경 시 재설정·재수집 비용

IL은 미리 정한 holdout에서 성공·일반화·복구 또는 변경 비용을 실제로 개선할 때 해당 phase의
배포 backend로 채택한다. 차이가 없으면 설명 가능하고 유지보수하기 쉬운 `PLANNED`를 기본으로
둔다. ACT 결과는 실패하더라도 적용 범위를 데이터로 판단한 비교 실험 증거로 남긴다.

## 9. 확인된 사실과 추론

### 확인된 사실

- 씨메스로보틱스는 3D 비전, AI 판단, 피킹 포인트, 맞춤형 그리퍼, 정밀 로봇 제어를 결합한다.
- ABB와 FANUC의 공개 피킹 구조는 비전·그립 판단과 모션 계획·제어를 분리한다.
- Dex-Net은 학습형 그립이지만 사람 시연 IL은 아니다.
- ACT와 RT-1은 사람 시연으로 행동을 학습한다.
- Figure Helix 02는 사람 동작 데이터와 시뮬레이션 학습을 전신 제어에 사용한다.

### 추론 또는 확인 안 됨

- 씨메스로보틱스 내부 모델이 IL을 전혀 사용하지 않는지는 확인 안 됨.
- 산업 전체에서 IL 피킹이 몇 퍼센트 사용되는지는 공식 통계가 없어 확인 안 됨.
- 현재 SO-101 물 서빙에서 어느 전략이 우수한지는 아직 데이터·모델·실물 비교가 없어 확인 안 됨.
