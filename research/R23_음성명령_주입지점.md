# R23 · 음성 명령을 정책에 넣는 최소 경로 — 로컬 소스 확인

작성 2026-08-24 · 근거: 로컬 `~/lerobot` (`bad0260a`)

## 결론

**모델 구조 변경 0.** 음성은 오디오 인코더가 아니라 **task 문자열**로 들어간다. SmolVLA는 이미 언어 조건 정책이고, 우리가 손댈 곳은 문자열을 넣는 한 줄뿐이다.

```
USB 마이크 → Whisper STT → 텍스트 → complementary_data["task"] → 토크나이저 → SmolVLA
```

## 확인된 경로 (파일:라인)

| 단계 | 위치 | 내용 |

| 롤아웃 시 문자열 결정 | `rollout/context.py:491` | `task_str = cfg.dataset.single_task if cfg.dataset else cfg.task` |

## 실행 시 명령을 바꾸려면

`self._task`가 **평범한 인스턴스 속성**이라(sync.py:73, rtc.py:133) 매 추론마다 다시 읽힌다(rtc.py:299-301). 즉 STT 스레드가 이 값을 갱신하면 **다음 추론부터 새 명령으로 동작한다.**

```python
# STT 스레드
text = whisper.transcribe(audio)["text"].strip()
engine._task = normalize(text)     # 또는 set_task() 한 줄 추가
```

추가 작업은 setter 하나와 STT 루프뿐이다. 정책·프로세서·데이터 스키마는 그대로다.

## 수집 쪽 함의

`lerobot_record.py`는 에피소드당 `single_task` 하나를 박는다. **명령이 여러 개인 태스크셋은 명령별로 따로 녹화**하거나 `--dataset.single_task`를 매 에피소드 바꿔 기록해야 한다. 태스크 문장 어휘를 먼저 고정해야 하는 이유(→ R26).

참고: `lerobot_record.py:65`의 공식 예시가 `"Grab and handover the red cube to the other arm"` — 양팔 핸드오버 문장이 이미 레퍼런스에 있다.

## 하지 않기로 한 것

- ACT에 MLP를 붙여 오디오 임베딩을 만드는 개조 — 사전학습 모달리티가 image+state뿐이라 이득 없이 리스크만 는다
- Audio-VLA(2511.09958) 채택 — 그 논문의 오디오는 **명령이 아니라 접촉음**이다. 커넥터 체결을 되살릴 때 판정용으로만 재검토
