# R31 — 1안 이동형 양팔 붓기: 논문을 구현 규격으로 바꾸기

작성: 2026-08-31
상태: 설계 반영 완료, 실물 검증 전
범위: `HOLD THE FLOW` 이동형 양팔 붓기만 다룬다.

## 판정 상태

| 판정 질문 | 상태 | 답 |
|---|---|---|
| 양팔을 써야 하는 기술적 근거가 있는가 | 답함 | 받는 컵을 유지하는 팔과 붓는 팔을 분리하는 `STABILIZE / ACT` 구조가 직접 대응한다. |
| 어떤 제어 구조로 시작해야 하는가 | 답함 | Nav2와 조작을 분리하고, 조작은 상태기계·IK·보정 붓기·도킹 저울 사후 검증으로 먼저 통과시킨다. |
| 접촉 센서로 붓는 양을 추정할 수 있는가 | 답함 | 주 판정기로 쓰지 않는다. FSR은 접촉·과압·좌우 불균형만 맡고, 유입량은 별도 중량 센서로 측정한다. |
| 컵을 든 상태에서 작업대 저울로 실시간 제어할 수 있는가 | 답함 | 불가능하다. 1차는 병과 컵을 각각의 도킹 저울로 반환한 뒤 전후 질량을 검증하고, 실시간 폐루프는 컵 홀더에 로드셀을 넣은 수신 모듈이 있을 때만 사용한다. |
| ACT를 언제 붙여야 하는가 | 답함 | G0~G2a의 결정론적 기준선이 통과한 뒤 짧은 조작 구간에만 적용한다. |
| 이동과 양팔 조작을 한 정책으로 학습해야 하는가 | 답함 | 현재 범위에서는 아니다. Nav2 접근과 로컬 조작을 분리하고 인터페이스로 연결한다. |
| 실패 데이터를 어떻게 남겨야 하는가 | 답함 | 성공 에피소드와 의도적으로 주입한 이상 에피소드를 함께 수집하고 실패 구간을 시간 범위로 라벨링한다. |
| 실제 성공률은 얼마인가 | 확인 안 됨 | 실물 G0~G4 반복 시험 전에는 수치화할 수 없다. 논문 수치를 예상 성공률로 전용하지 않는다. |

## 결론

이 프로젝트의 가장 현실적인 기술 조합은 다음과 같다.

```text
Nav2 접근
  → Depth / AprilTag 로컬 정렬
  → IK + 상태기계 기준선
  → 컵 팔 STABILIZE / 병 팔 ACT
  → FSR 파지 안전 + 붓기 후 병·컵 도킹 저울 검증
  → 규칙 기반 실패 판정과 제한된 복구
  → 로드셀 수신 모듈이 준비되면 실시간 유입량 폐루프
  → 기준선 통과 뒤 ACT 및 학습형 실패 감지 확장
```

핵심은 센서를 많이 붙이는 것이 아니라 **센서마다 한 가지 책임을 주는 것**이다. FSR은 병과 컵을 안전하게 잡았는지 판단하고, 중량 센서는 실제로 얼마나 옮겨졌는지 판단한다. RGB-D와 표식은 작업 셀 좌표를 만들고, 관절 상태는 동작 진행과 과부하 보호에 사용한다.

`Pouring by Feel`의 결과는 기존 가정을 수정하게 만든다. 이 논문에서 촉각 신호는 1~2mm의 파지 위치 차이에도 크게 흔들렸고, 촉각 단독 추정기는 실제 붓기에서 실패했다. 따라서 SO-101의 저가 FSR을 유입량 추정기로 쓰는 주장은 버린다.

또한 컵을 다른 팔이 들고 있는 동안에는 작업대 저울이 컵 무게를 읽지 못한다. 초기 구현은 병과 컵의 시작·종료 위치를 각각 **로드셀 도킹 패드**로 만들고, 집기 전과 반환 후 질량 차이로 유입량과 흘림을 검증한다. 실시간 중량 폐루프는 컵과 함께 들 수 있는 로드셀 수신 모듈을 별도로 제작한 뒤에만 적용한다. 두 구성 모두 현재 프로젝트의 하드웨어 설계 제안이다.

## 2. 논문을 반영한 제어 상태기계

### G2a — 병·컵 도킹 저울을 쓰는 1차 구현

```text
APPROACH
  Nav2 완료 + 작업대 목표 자세 허용오차 통과
      ↓
ALIGN
  RGB-D / AprilTag로 병·컵·로봇의 상대 자세 갱신
      ↓
GRASP_BOTH
  컵 팔 STABILIZE, 병 팔 ACT 역할 고정
      ↓
VERIFY_GRASP
  FSR 접촉 범위 + 좌우 차이 + 10~20mm 미세 들기 검사
      ↓
PRETILT_SLOW
  낮은 각속도로 유출 시작 영역까지 기울임
      ↓
POUR_CALIBRATED
  매체별로 보정한 각도·시간만큼 짧게 붓기
  FSR·컵 자세·팔 간 거리 위반 시 SAFE_RETURN
      ↓
RETURN_UPRIGHT
  병을 세우고 잔류 낙하가 끝날 때까지 대기
      ↓
WEIGH_BOTH_DOCKS
  병과 컵을 각 로드셀 도킹 패드에 놓고 질량 판정
      ↓
POUR_MORE 또는 PLACE_BOTH
  부족하면 재파지 후 작은 추가 붓기 1회, 아니면 종료
```

이 방식은 붓는 도중 목표량을 직접 읽지 못한다. 대신 실시간 센서가 없어도 `컵 증가량`, `병 감소량`, `병 감소량−컵 증가량`을 계산해 **최종 양과 흘림을 자동 판정**할 수 있어 G2의 현실적인 기준선이 된다.

### G2b — 로드셀 수신 모듈을 쓰는 확장

컵을 담는 경량 홀더와 로드셀을 하나의 수신 모듈로 만들고, 컵 팔은 평행 그리퍼로 이 모듈의 손잡이를 잡는다. 로드셀이 컵과 내용물의 질량 변화를 계속 읽을 수 있을 때만 다음 폐루프를 사용한다.

```text
PRETILT_SLOW
  → POUR_CONTROL: delta_mass = filtered_loadcell - baseline
  → delta_mass >= target_mass - stop_margin
  → RETURN_UPRIGHT
  → VERIFY_TRANSFER
```

로드셀은 팔의 가속과 컵 기울기에 영향을 받는다. 따라서 컵 팔이 정지하고 수신 모듈의 방향이 보정 범위 안에 있을 때만 값이 유효하다. 이 조건은 실물 시험으로 확인해야 하며, 현재는 미검증 설계다.

### 공통 붓기 제어 규칙

1. G2a는 병과 컵을 각각 로드셀 도킹 패드에 둔 상태에서 `source_before_g`, `receiver_before_g`를 고정한다.
2. 붓기 뒤 두 물체를 같은 도킹 패드에 반환해 `source_after_g`, `receiver_after_g`를 측정한다.
3. `transferred_mass_g = receiver_after_g - receiver_before_g`로 실제 유입량을 계산한다.
4. `spill_estimate_g = (source_before_g - source_after_g) - transferred_mass_g`로 흘림을 추정한다. 두 도킹 패드가 없으면 질량 기반 흘림량을 주장하지 않고 `spill_detected`만 기록한다.
5. G2b의 `baseline_mass_g`는 컵 팔이 정지한 뒤 로드셀 수신 모듈에서 고정한다.
6. 중량값에는 이동평균 또는 저역통과 필터를 적용하고 필터 지연을 로그에 기록한다.
7. 내용물은 명령을 멈춘 뒤에도 낙하하므로 `stop_margin_g`를 둔다.
8. `stop_margin_g`는 비드·쌀·작은 건면 조각처럼 매체별로 따로 보정한다.
9. 목표량에 못 미치면 즉시 큰 각도로 재시도하지 않고, 컵 자세와 파지를 다시 확인한 뒤 `POUR_MORE`를 1회만 허용한다.
10. 초과 유입은 되돌릴 수 없으므로 초반 목표는 정확도보다 넘침 방지에 둔다.

### ✎ 기존 가정 수정

- **FSR은 유입량 센서가 아니다.** `Pouring by Feel`에서 고급 촉각 센서도 1~2mm 파지 오차에 크게 흔들렸다. FSR은 파지 안전 신호로만 사용한다.
- **로드셀 도킹 패드는 최종 검증 기준이다.** 병과 컵을 든 동안에는 읽을 수 없으므로 G2a에서는 집기 전과 반환 후에만 측정한다.
- **실시간 폐루프에는 별도 하드웨어가 필요하다.** 컵 팔이 함께 드는 로드셀 수신 모듈을 만들고 정적 자세에서 신호가 안정적일 때만 G2b를 연다.
- **건식 매체 결과는 물에 그대로 이어지지 않는다.** 마찰·유량·잔류 낙하가 다르므로 매체별 `stop_margin_g`를 새로 보정한다.
- **Pointmap 코드는 현재 프로젝트 페이지에서 연결된다.** 다만 우리 구현의 선행 조건은 모델 이식이 아니라 카메라-로봇 좌표 보정이다.

## 4. 그리퍼 설계에 반영할 내용

양쪽 팔은 교체 가능한 평행 그리퍼를 유지한다.

### 병 팔

- V홈 TPU 인서트로 원통의 좌우 이탈을 줄인다.
- FSR은 단단한 플라스틱 뒤가 아니라 접촉 패드 아래에 넣되, 하중이 센서 한 점에만 몰리지 않게 얇은 분산판을 둔다.
- 병 후보마다 `지름 × 총중량 × 표면 × FSR 임계값` 보정표를 만든다.
- 붓기 전 `미세 들기 → 2~3° 기울이기 → 원위치` 검사를 통과해야 한다.

### 컵 팔

- 넓은 평면 패드나 교체형 반원 인서트로 컵의 기울어짐을 줄인다.
- 컵 팔은 고정 명령만 내리는 팔이 아니다. `cup_tilt` 또는 `cup_pose_error`가 임계값을 넘으면 작은 자세 보정만 수행한다.
- 재안정화 중에는 병 팔의 기울임을 정지한다.
- G2a에서는 컵을 항상 같은 로드셀 도킹 패드에 반환하고, 부족하면 다시 파지해 1회 추가 붓기를 수행할 수 있어야 한다.
- G2b에서는 평행 그리퍼가 잡을 손잡이와 컵 홀더 사이에 로드셀을 둔 경량 수신 모듈을 별도로 설계한다.

### 안전 제약

- 병과 내용물 총중량: 200~300g 목표
- 팔 사이 최소 거리: 실물 무충돌 자세에서 측정 후 고정
- 붓기 최대 각도·각속도: 매체별 G1/G2 시험으로 확정
- FSR 과압 또는 컵 자세 위반: `SAFE_RETURN` 우선
- 중량 데이터 타임아웃 또는 튐: 붓기 중지 후 재측정

### 최소 하드웨어 구성

| 분류 | 수량 | 기준 | 단계 |
|---|---:|---|---|
| 교체형 평행 그리퍼 | 2 | 좌우 동일 인터페이스, 인서트 교체 가능 | 필수 |
| 병 V홈 인서트 | 1세트 | 강성 프레임 + TPU 접촉면 + FSR 분산판 | G0 |
| 컵 반원 인서트 | 1세트 | 컵 외경에 맞는 넓은 접촉면 | G0 |
| FSR 채널 | 4 | 병 좌·우, 컵 좌·우 | G0 |
| 로드셀 도킹 패드 | 2 | 병과 컵의 집기 전·반환 후 질량 측정 | G2a |
| 로드셀 증폭·ADC | 2채널 | 타임스탬프와 원시값을 함께 기록 | G2a |
| RGB-D 카메라 | 1 | 작업 셀 로컬 정렬 | G3 |
| 손목 RGB 카메라 | 좌·우 각 1 | 파지·가림·실패 구간 기록 | G0~G4 |
| 표식과 고정 타깃 | 1세트 | 카메라-로봇 좌표와 도킹 위치 확인 | G3 |
| 흘림 회수 트레이 | 1 | 건식 매체가 바닥으로 퍼지는 것을 방지 | G2 |
| 로드셀 수신 모듈 | 1 | 컵 홀더 + 손잡이 + 로드셀, 자세 보정 필요 | G2b 선택 |

로드셀 용량과 분해능은 병·컵·도킹 플레이트의 실측 총중량을 확인한 뒤 정한다. 현재 문서에서는 특정 제품 번호나 정밀도를 달성 사실처럼 고정하지 않는다.

## 5. 평가표

UMI-Bench의 전체 성공률과 진행 점수 분리를 현재 태스크에 맞게 축소한다.

| 단계 | 점수 | 통과 조건 |
|---|---:|---|
| 작업대 접근·로컬 정렬 | 10 | 베이스와 작업 셀 자세가 허용오차 안에 들어옴 |
| 컵 파지·안정화 | 15 | 컵을 들고 목표 자세를 유지함 |
| 병 파지 | 10 | 병을 들어 예비 기울임 검사까지 통과함 |
| 내용물 이송 | 40 | 일부 이송 20점, 목표 허용오차 안 이송 40점 |
| 병 반환 | 10 | 병을 지정 영역에 안정적으로 내려놓음 |
| 컵 반환 | 15 | 컵을 지정 영역에 안정적으로 내려놓음 |
| 전체 성공 | 100 | 심한 흘림·전도·충돌·수동 개입 없이 모든 단계를 완료함 |

전체 성공률과 평균 진행 점수는 반드시 따로 보고한다. 진행 점수가 높아도 마지막 안정 상태를 만들지 못하면 전체 성공으로 세지 않는다.

### 첫 평가 매트릭스

|  | 중앙 배치 | 오프셋 배치 |
|---|---:|---:|
| 기준 병·컵 | 5회 | 5회 |
| 변화 병·컵 | 5회 | 5회 |

첫 20회는 모델 성능을 주장하기 위한 수가 아니라 실패 위치를 찾기 위한 파일럿이다. 파일럿 뒤 반복 수를 늘리되, 조건별 횟수는 같게 유지한다.

### 최소 보고 지표

- `full_success_rate`
- `progress_score_mean`
- `first_failed_stage`
- `target_mass_error_g`
- `spill_mass_g`
- `cup_tilt_max_deg`
- `approach_pose_error_mm / deg`
- `recovery_attempted / recovery_success`
- `manual_intervention`

## 7. 구현 게이트와 논문 연결

| 게이트 | 먼저 만들 것 | 논문에서 가져온 원칙 | 통과 전 금지 |
|---|---|---|---|
| G0 정적 파지 | V홈·컵 인서트·FSR 임계값 | 촉각은 안전 상태, 미세 파지 변화에 대한 반복 보정 | ACT 수집, 액체 사용 |
| G1 무수 기울이기 | STABILIZE / ACT 역할, 팔 간 거리 제한 | Stabilize to Act의 역할 분리 | 저울 폐루프 주장 |
| G2a 건식 붓기 | 보정 기울임, 직립 복귀, 병·컵 도킹 저울 사후 검증 | Pouring by Feel의 저속 예비 기울임과 COFFAIL의 건식 안전 조건 | 실시간 중량 폐루프 주장, 물로 전환 |
| G2b 중량 폐루프 | 로드셀 수신 모듈, 정적 자세 신호 검증, 정지 여유량 | Pouring by Feel의 목표량 폐루프 | 신호 안정성 확인 전 자동 붓기 |
| G3 이동 통합 | Nav2 완료 조건, RGB-D/표식 정렬 | BiGym·Mobile ALOHA의 이동형 관측, UMI-Bench의 배치 변화 평가 | 이동·조작 단일 정책 |
| G4 실패 복구 | 실패 구간 라벨, 규칙 기반 복구 | COFFAIL의 이상 실행 기록, 런타임 모니터의 시간 이력 | LLM 직접 모터 제어 |

## 8. 4주 실행 순서

| 주차 | 목표 | 산출물 | 종료 조건 |
|---|---|---|---|
| 1주 | G0·G1 | 병/컵 치수표, 인서트 1차, FSR 보정표, 무수 기울임 로그 | 두 팔 정적 파지와 기울임을 반복 실행 가능 |
| 2주 | G2a | 병·컵 도킹 저울 로거, 보정 붓기, 매체별 추가 붓기 규칙 | 건식 내용물의 최종 목표량·흘림을 자동 판정 |
| 3주 | G3 | Nav2 완료 메시지, 작업 셀 로컬 좌표, 20회 평가표 | 이동과 조작 결과를 같은 episode_id로 연결 |
| 4주 | G4 | 실패 6종 데이터, 복구 스킬, 진행 점수 리포트 | 감지되지 않은 실패와 안전 중단 실패를 분리 보고 |

G2b 로드셀 수신 모듈은 G2a가 통과하고 하드웨어 제작 여력이 있을 때 별도 확장한다. ACT는 2주차 기준선과 텔레옵 수집 가능성이 확인된 뒤 착수한다. 로컬 LLM은 G4의 규칙 기반 복구가 먼저 동작한 뒤, 동일한 허용 행동 집합을 선택하는 비교군으로만 붙인다.

## 9. 바로 만들 작업 항목

1. 병 3종과 컵 2종의 지름·높이·빈 무게·표면·총중량을 기록한다.
2. V홈 TPU 인서트와 컵 반원 인서트의 치수를 정한다.
3. FSR 4채널의 무접촉·정상 접촉·과압 범위를 실측한다.
4. 병·컵 도킹 저울의 샘플링 주기, 필터, 지연, 영점 재설정 방식을 정한다.
5. `PRETILT_SLOW → POUR_CALIBRATED → RETURN_UPRIGHT → WEIGH_BOTH_DOCKS` 상태기계를 구현한다.
6. 목표량 3수준에서 매체별 기울임 시간과 `POUR_MORE` 보정량을 구한다.
7. 중앙/오프셋 배치와 기준/변화 용기를 조합한 20회 파일럿을 수행한다.
8. 실패 시작·끝 시각과 복구 결과를 기존 episode_id에 연결한다.
