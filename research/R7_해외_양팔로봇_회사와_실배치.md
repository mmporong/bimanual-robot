# R7 — 해외 양팔 로봇 회사와 실제 배치 사례

조사일 2026-08-20 · 목적: "우리가 간이 버전으로 만들 대상"을 실제 배치 사례에서 찾는다

## 결론 먼저

**양팔이 필요한 이유는 산업에서 세 갈래로 갈린다.** 하나로 뭉뚱그리면 태스크 선정이 흐려진다.

| 근거 | 무엇이 문제인가 | 대표 사례 |
|---|---|---|
| **(a) 무게·부피** | 한 팔로는 물리적으로 못 든다 | Dexterity Mech — 두 팔 합쳐 59kg, FedEx 트레일러 적재 |
| **(b) 고정 + 작업** | 한 손이 잡아줘야 다른 손이 일할 수 있다 | ABB YuMi 소형 부품 조립, Mobile ALOHA 와인 닦기 |
| **(c) 사람 작업장 그대로** | 설비를 새로 짤 수 없어 사람 형상이 필요하다 | Figure·Agility·Apptronik 휴머노이드 |

**실배치된 휴머노이드가 실제로 하는 일은 아직 "옮기기"다.** 2026년 기준 문서화된 배치의 작업 범주는 material handling, parts transfer, bin picking, kitting, 단순 조립 보조다. 정교한 양손 협응은 아직 연구 단계다. 이건 우리 픽앤플레이스 1단계가 생각만큼 뒤떨어진 목표가 아니라는 뜻이기도 하다.

**(b)가 우리가 재현할 수 있는 유일한 갈래다.** (a)는 SO-101의 페이로드로 불가능하고, (c)는 휴머노이드 하드웨어가 필요하다. (b)는 테이블탑에서 성립하고, 실제로 ABB YuMi가 상용으로 파는 가치 명제가 정확히 이것이다.

---

## 1. Dexterity — Mech (양팔 모바일 매니퓰레이터)

물류 자동화 회사. 양팔 로봇의 상업적 성공 사례로는 현재 가장 앞서 있다.

| 항목 | 내용 |
|---|---|
| 제품 | Mech — 양팔 "슈퍼휴머노이드", 트레일러 내부에서 작업 가능한 크기 |
| 작업 | 트레일러 상차·하차 (박스를 집어 컨테이너에 쌓기) |
| 양팔 근거 | **두 팔 합쳐 59kg(130 lbs) 적재**, 2.4m 높이까지 배치 |
| 실배치 | **FedEx Hagerstown 허브** (2026-07-30 발표). 파일럿을 넘어 프로덕션 규모로 확대 |
| 확장 계획 | 미국 20개 이상 허브, 수천 개 도크 도어 |
| 기술 | 세계모델 "Foresight" 기반. Kawasaki Robotics RL030N 8자유도 팔 플랫폼과 협업 |
| 투자 | 9,500만 달러 조달 |

**주목할 점**: 이 회사는 양팔을 "정교함"이 아니라 **"무게와 도달 범위"**로 정당화한다. 한 팔로 30kg 박스를 못 드니 두 팔로 든다. 우리 기체(팔당 수백 g 수준)로는 재현할 수 없는 갈래다.

## 2. ABB — YuMi (IRB 14000)

2015년 출시된 세계 최초의 진정한 협동 양팔 로봇. **우리가 참고할 가치 명제가 여기 있다.**

| 항목 | 내용 |
|---|---|
| 설계 목적 | 소형 부품 조립(small parts assembly) 환경에서 사람과 안전하게 협업 |
| 양팔 근거 | **좁은 작업공간에서 협응 동작과 정밀 조작.** 부품을 잡고, 위치시키고, 조작하는 것을 동시에 수행 — 단팔로는 같은 효율로 불가능 |
| 구성 | 양팔 + 유연 핸드 + 범용 부품 피딩 + 카메라 기반 부품 위치 인식 + 리드스루 프로그래밍 |
| 실제 응용 | 전기 소켓 생산, ATM 기계 테스트, **의료·제약 실험실** |

### YuMi의 실험실·의료 응용 (구체 사례)

- **Copan Wasp (미국)** — YuMi 기반 HEPA 필터 바이오세이프티 워크스테이션. 조직·뼈·무균 체액 샘플 관리, 스왑과 혈액배양 이송
- **시료 전처리 스테이션** — Chemspeed 액체 취급 플랫폼, 분말 X선 회절기와 함께 자동 워크플로를 구성 (재료·제약 화학용)
- 수행 가능 작업으로 언급된 것: 약품 조제, **원심분리기 로딩·언로딩**, 피펫팅과 액체 취급, **시험관 집기와 분류**

✎ 앞선 세션에서 제가 "실험실 캡 개폐"를 후보로 제시했다가 "전용 디캐퍼가 이미 한다"며 철회했는데, 절반만 맞았다. 캡 개폐는 실제로 전용기 영역이지만 **시료 전처리 스테이션 자체는 YuMi가 상용으로 들어가 있는 시장**이다. 다만 그 작업은 캡 돌리기가 아니라 시험관 집기·분류·원심분리기 로딩 쪽이다.

## 3. 휴머노이드 3사 — 실배치 기록

2026년 기준 검증된 배치 기록이 있는 곳은 Figure와 Agility다.

| 회사 | 로봇 | 고객 | 실제 작업 |
|---|---|---|---|
| **Figure AI** | Figure | BMW Spartanburg | **1,250시간 이상 가동, 11개월 투입, 3만 대 이상 차량 생산에 기여** |
| **Agility Robotics** | Digit | Amazon 물류센터 | **토트 재활용** — 빈 컨테이너를 한 구역에서 다른 구역으로 이동. Toyota에서 1년 상업 파일럿 완료 |
| **Apptronik** | Apollo | Mercedes-Benz | **최대 25kg 부품**을 작업대까지 자율 운반 |

**중요한 관찰**: 세 회사 모두 "범용 공장 노동"이 아니라 **좁고 반복적인 작업**을 겨냥한다. 그리고 문서화된 배치의 작업 범주는 전부 옮기기·전달·빈피킹·키팅 계열이다. 양손으로 정교하게 조작하는 사례는 아직 실배치 기록에 없다.

## 4. 레인보우로보틱스 — RB-Y1 (국내)

| 항목 | 내용 |
|---|---|
| 구성 | 팔당 **7자유도** 양팔 + 6축 외다리 + 바퀴형 모바일 플랫폼 |
| 크기·성능 | 약 1.4m, **팔당 3kg 적재**, 이동 속도 2.5m/s, 상하 50cm 이상 이동 |
| 최신 | ICRA 2025에서 전방향 메카넘 휠과 통합 SDK 공개 |
| 가격 | 연구용 9,000만 원 / 상용 1억 3,000만 원 |

팔당 3kg이라는 사양이 시사적이다. **국내 대표 양팔 플랫폼도 무게로 승부하지 않는다.** 높이 조절과 이동성으로 "사람이 하던 자리에 들어간다"를 노린다.

## 5. Mobile ALOHA (Stanford) — 연구지만 태스크 카탈로그로 가장 유용

저비용 전신 텔레오퍼레이션으로 양팔 모바일 조작을 학습한다. **우리 기체 계열(SO-101)과 같은 저비용 텔레옵 방식**이라 태스크가 그대로 참고된다.

### 실제 시연된 태스크

| 태스크 | 양팔 근거 |
|---|---|
| **쏟은 와인 닦기** | **한 팔이 와인잔을 들어 올리고, 다른 팔이 테이블과 잔 바닥을 수건으로 닦는다** |
| 새우 볶아 서빙, 사용한 팬을 수도로 헹구기 | 팬 고정 + 조리 도구 조작 |
| 3코스 요리, 식기세척기 적재 | 다단계 장기 태스크 |
| 양문형 벽장을 열어 무거운 냄비 보관 | 문 잡기 + 물건 넣기 |
| **계란 깨기** | 한 손 고정 + 한 손 타격·분리 |
| 탄산음료 병 따기 | 병 고정 + 뚜껑 조작 |
| 엘리베이터 호출, 의자 밀어넣기, 세탁 전 과정 | 이동 + 조작 |

**성능 기준선**: co-training으로 **태스크당 시연 50회에 성공률 80% 이상**.

이 수치는 앞서 확인한 것들과 일치한다. RoboTwin 2.0 공식 프로토콜이 demo_clean 50개, ACT의 양팔 peg-insertion이 60회로 80%. **태스크당 50~60회가 업계 공통 기준선**으로 봐도 된다.

## 6. 양팔 필수 동작의 공통 패턴

사례를 관통하는 구조가 하나 있다.

> **한 팔이 대상을 잡거나 고정해 "작업 가능한 상태"를 만들고, 다른 팔이 그 상태 위에서 작업한다.**

- YuMi 조립: 한 팔이 부품을 잡아 위치시키고 다른 팔이 결합
- ALOHA 와인 닦기: 한 팔이 잔을 들어 올려 공간을 만들고 다른 팔이 닦는다
- ALOHA 계란 깨기: 한 손이 계란을 고정하고 다른 손이 깬다
- 벽장에 냄비 넣기: 한 팔이 문을 잡고 다른 팔이 넣는다

이 구조에서는 **두 동작 사이에 시간 간격을 둘 수 없다.** 고정을 놓는 순간 작업이 무너지기 때문이다. 그래서 단팔 두 대로 분리할 수 없고, 순차 녹화로도 데이터를 만들 수 없다. R4에서 정의한 B2 등급의 실질적 정의가 이것이다.

반대로 Dexterity의 무게 근거(a)는 우리가 재현할 수 없고, 휴머노이드의 형상 근거(c)는 하드웨어가 다르다.

## 7. 우리가 만들 수 있는 "간이 버전" 후보

각 후보에 **원본 회사·제품**과 **양팔 근거**를 붙였다. 전부 (b) 갈래이며 테이블탑 SO-101 규모에서 성립한다.

| # | 간이 버전 | 원본 | 시퀀스 | 양팔 근거 | 난점 |
|---|---|---|---|---|---|
| **1** | **소형 부품 조립 셀** | ABB YuMi (전기 소켓 생산, ATM 테스트) | 부품 A를 한 팔이 집어 고정 → 다른 팔이 부품 B를 결합 → 검사 → 양·불 분리 | 고정 없이는 결합 불가 | 저가 서보 백래시로 정밀 결합이 어려움. 공차를 크게 설계해야 함 |
| **2** | **실험실 시료 전처리 스테이션** | ABB YuMi + Copan Wasp | 랙에서 시험관 집기 → 한 팔 고정, 다른 팔이 라벨 스캔·내용물 이송 → 원심분리기 트레이에 적재 → 결과 기록 | 튜브를 세운 채 유지해야 이송 가능 | 액체를 실제로 쓰면 환경 관리 부담. 고체·비드로 대체 가능 |
| **3** | **테이블 정리·오염 처리** | Mobile ALOHA (쏟은 와인 닦기) | 물체 인식 → 한 팔이 물체를 들어 올림 → 다른 팔이 그 아래를 닦음 → 물체 원위치 | 들지 않으면 아래를 닦을 수 없음 | 닦기 성공 판정이 애매. 오염 면적을 비전으로 재는 설계 필요 |
| **4** | **주문 키팅 스테이션** | Agility Digit(Amazon 토트), Figure(BMW) | 주문서 수신 → 부품 빈에서 지정 품목 픽 → 트레이에 배치 → 검수 → 출고 트레이로 | 트레이를 잡고 배치 / 큰 품목은 양손 | **양팔 근거가 가장 약함**(B0). 실배치 작업과는 가장 가까움 |

### 판단

**1번(소형 부품 조립 셀)이 가장 강하다.** 이유가 셋이다.

1. **원본이 명확하다.** ABB YuMi가 정확히 이 용도로 10년째 팔리고 있다. "YuMi가 하는 일의 간이 버전"이라고 한 문장으로 설명된다
2. **양팔 근거가 구조적이다.** 고정 없이는 결합이 성립하지 않으므로 B2가 자연스럽다
3. **측정이 쉽다.** 결합 성공률, 허용 공차(mm), 사이클 타임, 검사 정확도가 전부 수치로 나온다

**2번(실험실)은 차선**이다. 시장이 실재하고 YuMi 사례도 있지만, 시료 전처리는 작업이 "옮기기" 위주라 양팔 근거가 1번보다 약하다.

**3번은 데모 임팩트가 가장 크다.** 심사위원이 즉시 이해하고, ALOHA 원본 영상이 유명해서 비교 서사도 만들기 쉽다. 다만 성공 판정 설계가 까다롭다.

**4번은 실배치 현실과 가장 가깝지만 양팔 근거가 약하다.** 1단계 픽앤플레이스가 사실상 이것이므로, 기준선으로 이미 커버된다.

## 8. 확인 안 된 것

- Dexterity Mech의 팔당 자유도·정확한 사양 (두 팔 합계 적재량만 확인)
- YuMi 실험실 응용의 구체 사이클 타임·성공률 수치
- 국내에 YuMi식 소형 조립 셀을 운용하는 회사가 있는지 (R4 실측에는 잡히지 않음)
- Figure·Agility 배치에서 양팔 협응이 실제로 쓰이는지, 아니면 한 팔씩 쓰는지
