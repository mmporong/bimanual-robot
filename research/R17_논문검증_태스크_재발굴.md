# R17 — 논문에서 검증된 태스크 재발굴

작성 2026-08-20 · 계기: 기존 후보들이 전부 "조건부"라 확신이 안 선다는 지적

## 결론 먼저

**접근을 바꿨다.** 지금까지는 "어느 회사가 무엇을 하나"에서 태스크를 역산했고, 그래서 후보마다 "될지 모르겠다"가 붙었다. 이번엔 **양팔 조작 연구가 실제로 검증한 태스크 목록**에서 우리 규모에 맞는 것을 골랐다. 그러면 "될까"가 아니라 **"논문이 됐다고 한 것을 저비용 하드웨어로 재현한다"**가 된다.

**새 유력 후보는 지퍼 당기기다.** 지금까지 나온 어떤 후보보다 리스크가 낮으면서 모든 축을 통과한다. **소모품이 없어 반복 실험이 무제한**이라는 점이 특히 크다.

---

## 1. 양팔 연구가 다루는 태스크 전체 목록

`awesome-bimanual-manipulation` 저장소에서 추출했다. 굵게 표시한 것이 우리 규모에서 가능한 것이다.

| 유형 | 태스크 (연구·연도) |
|---|---|
| **유연물** | 천 접기(IROS 2011) · 동적 천 조작(ICRA 2020) · FabricFlowNet(CoRL 2021) · **로프 공중 매듭(IROS 2021)** · 선형 탄성체 포장(2021) · 볶음 요리(RA-L 2022) · **봉투 들어올리기(IROS 2021 WS)** |
| **도구 사용** | 스푼·전동드릴·드라이버·클램프 파지 · **바나나 껍질 벗기기(2022)** · **커피 젓기** · **컵 흔들기** |
| **조립** | peg-in-hole(URAI 2014) · 접힘 조립(Humanoids 2016) |
| **정밀 조작** | 나사 조작 · 문 열기(ICRA 2017) · 태극권 밀어내기 |
| **의료** | 자율 봉합(RA-L 2019) · **봉합 바늘 재파지(2020)** |
| **이송** | 픽앤플레이스 · 빈 패킹 · 클러터 스토잉 · **핸드오버(T-ASE 2021)** |
| **BUDS 검증셋** | **채소 자르기 · 지퍼 당기기 · 마커 캡 끼우기** |

**BUDS**는 양팔 태스크를 **stabilizer(안정화)와 executor(작업)** 역할로 분해하는 방법이고, 위 세 태스크로 검증했다. 우리가 계속 써 온 "안정화 팔 / 작업 팔" 프레임의 직접 선행 연구다.

## 2. 신규 후보 평가

### 지퍼 당기기 ★ 최우선

옷이나 가방의 지퍼를 끝까지 채운다.

| 축 | 평가 |
|---|---|
| **논문 검증** | **BUDS 검증 태스크 3종 중 하나.** 됐다는 근거가 있다 |
| **양팔 필수** | **B2** — 천을 고정하지 않으면 지퍼를 당길 때 천이 딸려온다. 놓는 순간 실패 |
| **학습 필수** | 천 상태·지퍼 걸림·정렬이 매번 다르다. 걸렸을 때 되돌려 다시 당기는 복구 동작은 규칙으로 못 쓴다 |
| **하드웨어** | **최적** — 가볍고 회전 불필요. 슬라이더는 강체라 파지가 쉽다 |
| **인식** | 쉬움 — 지퍼는 선형이고 슬라이더는 금속이라 대비가 크다 |
| **판정** | **명확** — 끝까지 올라갔는가(이진), 이동 거리(mm), 걸림 횟수 |
| **소모품** | **없음.** 같은 지퍼로 무한 반복 — 수천 에피소드 수집의 전제 조건 |
| **산업 연결** | 의류 제조 · **옷 입히기 보조**(고령 돌봄) |
| **대중 이해** | 최상 — 설명이 필요 없다 |

**리스크**: 슬라이더가 작으면 파지가 어렵다. 가방용 대형 지퍼로 시작해 크기를 줄여가면 그 자체가 난이도 축이 된다.

**다양성 축**: 지퍼 종류(코일·비슬론·금속) · 천 종류(두께·미끄러움) · 시작 위치 · 걸림 유도

### 바나나 껍질 벗기기

한 손이 바나나를 잡고 다른 손이 껍질을 벗긴다.

| 축 | 평가 |
|---|---|
| 논문 검증 | **목표 조건부 이중 행동 모방학습(2022)** — 양팔 로봇으로 검증됨 |
| 양팔 필수 | **B2** — 고정 없이 당기면 바나나가 딸려온다 |
| 학습 필수 | **매우 높음** — 개체마다 크기·익은 정도가 다르고 껍질이 벗겨지는 방식도 다르다 |
| 하드웨어 | 바나나 약 120 g — 페이로드 경계. 껍질은 가벼움 |
| 판정 | 명확 — 벗겨짐 여부, 과육 손상 정도 |
| **소모품** | **매번 새 바나나.** 수백~수천 에피소드면 비용과 처리가 부담 |
| 대중 이해 | **최상** |

**결정적 약점은 소모품이다.** 1,000 에피소드면 바나나 1,000개다. 데이터 규모를 키울 수 없어 R16의 스케일링 설계와 충돌한다.

### 마커 캡 끼우기

마커 뚜껑을 밀어 끼운다.

| 축 | 평가 |
|---|---|
| 논문 검증 | BUDS 검증 태스크 |
| 양팔 필수 | B2 — 고정 없이 밀면 마커가 밀린다 |
| 학습 필수 | **낮음** — 강체이고 정렬만 맞으면 된다. 규칙으로 풀림 |
| 하드웨어 | 최적 — 가볍고 **회전 불필요**(밀어 끼움) |
| 소모품 | 없음 |

**앞서 폐기한 용기 뚜껑의 회전 문제가 없는 버전**이다. 다만 학습 필수성이 약해 단독 주제로는 부족하고, **기준선 태스크**로 쓰기 좋다.

### 봉합 바늘 재파지

한 손에서 다른 손으로 바늘을 옮겨 잡는다.

| 축 | 평가 |
|---|---|
| 논문 검증 | Suture Needle Regrasping (2020) |
| 양팔 필수 | **B2 정의상** — 한 손에서 다른 손으로 넘기는 것이 태스크 자체 |
| 산업 | 수술 로봇 — 시장이 크고 관심도 높다 |
| 하드웨어 | **어려움** — 봉합 바늘은 수 mm. 정밀도가 SO-101 백래시를 넘는다 |
| 대안 | 큰 바늘·곡선 막대로 스케일업하면 가능하나 원본과 연결이 흐려진다 |

### 옷 입히기 보조

마네킹 팔에 옷소매를 끼운다.

| 축 | 평가 |
|---|---|
| 논문 검증 | Science Robotics 게재, York 대학이 **간병인 동작을 모방하는 드레싱 로봇** 발표. 최근 연구가 단팔에서 **양팔로 전환**되는 추세 |
| 성능 | 타이트한 옷 대상 80회 시험에서 **성공률 95%**(기준선 61.25%) |
| 양팔 필수 | **B2** — 두 팔이 사람 팔 양옆에서 옷을 동시에 끌어올린다 |
| 학습 필수 | 높음 — 2D 유연물 + 자세 변동 |
| 하드웨어 | 옷 무게가 경계. **소형 의류·소매 조각으로 축소 필요** |
| 사회적 의미 | **최상** — 고령화 돌봄 |
| 리스크 | 사람 대상은 안전 문제라 마네킹 필수. 그러면 자세 변동이 사라진다 |

## 3. 기존 후보와 비교

| 후보 | 논문 검증 | 양팔 | 학습 | 하드웨어 | 판정 | **소모품** | 종합 |
|---|---|---|---|---|---|---|---|
| **지퍼 당기기** | **BUDS** | B2 | 높음 | **최적** | **명확** | **없음** | **1위** |
| 와이어 하네스 | 다수 | B2 | 매우높음 | 조건부(파지) | 명확 | 없음 | 2위 |
| 보호필름 박리 | 있음 | B2 | 높음 | 조건부(파지) | 명확 | **필름 소모** | 3위 |
| 옷 입히기 보조 | Science Robotics | B2 | 높음 | 축소 필요 | 보통 | 없음 | 4위 |
| 마커 캡 | BUDS | B2 | **낮음** | 최적 | 명확 | 없음 | 기준선용 |
| 바나나 껍질 | 있음 | B2 | 매우높음 | 경계 | 명확 | **매회 소모** | 보류 |
| 봉합 바늘 재파지 | 있음 | B2 | 중간 | **정밀도 초과** | 명확 | 없음 | 보류 |

**소모품 항목이 판도를 바꾼다.** R16에서 확인했듯 우리는 수천 에피소드를 모을 수 있는데, 매회 소모되는 재료를 쓰면 그 능력을 못 쓴다. 바나나·필름·모종·식품이 전부 여기 걸린다.

## 4. 권고

**주 태스크를 지퍼 당기기로 바꾸는 것을 검토한다.**

| 항목 | 지퍼 | 와이어 하네스(현행) |
|---|---|---|
| 파지 대상 | **슬라이더 — 강체, 손잡이 있음** | 커넥터(우회 설계 필요) |
| 인식 | **선형 + 금속 대비, 쉬움** | 얇은 케이블 — depth 불가, RGB+평면 투영 필요 |
| 논문 검증 | **BUDS 검증 태스크** | 다수, 다만 양팔 하네스는 아직 연구 단계 |
| 산업 근거 | 의류 제조 · 돌봄 보조 | **자동차 전장 90% 수작업 — 더 강함** |
| 실패 복구 | **걸림 → 되돌려 다시 당김.** 복구 동작이 태스크에 내장 | 별도 설계 필요 |
| 30분 검증 | 슬라이더를 그리퍼로 잡아보면 끝 | 케이블·커넥터 파지 시험 |

**지퍼가 이기는 지점은 확실성이고, 하네스가 이기는 지점은 산업 서사다.**

### 절충

**둘 다 한다.** 같은 파이프라인에서 두 태스크를 돌리면 R16의 스케일링 실험이 그대로 성립하고, 태스크 간 비교라는 축이 하나 더 생긴다.

- **지퍼** — 확실히 되는 쪽. 파이프라인 관통과 스케일링 곡선을 여기서 만든다
- **하네스** — 산업 서사 쪽. 지퍼로 검증된 파이프라인을 옮겨 일반화를 보인다
- **마커 캡** — 기준선. 가장 쉬운 태스크로 하한을 잡는다

이러면 **"쉬운 것 → 어려운 것"의 난이도 계단이 태스크 자체로 만들어진다.** 그리고 하네스가 막혀도 지퍼 결과가 남는다.
