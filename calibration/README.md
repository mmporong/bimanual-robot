# 캘리브레이션 상태

현행 왼손은 TPU FinRay가 아니라 SO-101 순정 회전식 죠를 사용한다.

`bi_follower/arms_left.json`과 `so_follower_left/follower_left.json`의 ID 6 값은 FinRay 장착
당시 기록이므로 순정 죠 캘리브레이션으로 사용하지 않는다. 나머지 관절 기록과 과거 실행 재현을
위해 파일은 보존한다.

순정 죠를 조립한 뒤 다음 순서로 갱신한다.

1. 완전 개폐의 기구 간섭과 서보 방향을 확인한다.
2. 순정 죠의 ID 6 원시 끝점과 안전 여유를 측정한다.
3. 단일팔 왼쪽 follower 파일에 새 범위를 기록한다.
4. 양팔 follower 파일로 반영하고 읽기 전용 대조를 통과한다.
5. 마른 컵·젖은 컵 파지와 선반 재파지를 다시 시험한다.

측정 전에는 과거 순정 참고값이나 FinRay 값을 새 JSON에 추정해 넣지 않는다. 상세 절차와 과거
값은 [`docs/20260909_그리퍼_캘리브레이션_인계.md`](../docs/20260909_그리퍼_캘리브레이션_인계.md)에 있다.
