# 그리퍼 파지 인서트

ggao50 `SO101-Parallel-Gripper` 죠에 볼트로 붙이는 교체형 파지면이다. 죠 본체는 그대로 두고 물체에 닿는 면만 갈아 끼운다.

## 왜 필요한가

ggao50 죠의 파지면은 완전 평면이다. STL을 직접 측정한 결과 축정렬 평면이 전체 면적의 69%이고 곡면이나 홈이 없다. 평면 죠와 원통은 선접촉 두 줄이라 병이 죠 안에서 자기 축으로 돌고, 기울일 때 축 방향으로 미끄러진다. 붓기에서는 주둥이 방향이 매번 달라진다는 뜻이다.

## 죠 실측 기준값

`STL/Parallel Jaw Gripper - leftgripper.stl` 직접 측정.

| 항목 | 값 |
|---|---|
| 파지 평면 | `x = -49.4` |
| 손가락 방향 범위 | `Y -84.2 ~ -11.5` (72.5 mm) |
| 병 축 방향 범위 | `Z -29.3 ~ 28.2` (뿌리 기준 57.5 mm) |
| 파지면 면적 | 2,449 mm² |
| 최대 개폐 | 105 mm |

## 파지면은 테이퍼다

죠 파지면을 평면으로 잘라 재 보면 손끝으로 갈수록 좁아지는 **하나의 테이퍼**다. 끊긴 두 면이 아니다.

```
높이 = 0.682 × Y + 67.5      (R² 0.958)
  손끝 Y = -84  ->   8.7 mm
  뿌리 Y = -16  ->  57.5 mm
```

**인서트는 뿌리 쪽에만 붙인다.** 손끝은 접촉 높이가 8.7 mm라 병을 세워 잡는 데 기여가 없고 기울일 때 회전축이 된다. 높이 40 mm 이상인 구간이 `Y ≥ -40.4`이므로, 부착 창을 `Y -42 ~ -14`의 28 mm로 잡고 외곽을 죠 테이퍼에 맞춘 사다리꼴로 만든다.

| | 값 |
|---|---|
| 부착 창 | `Y -42 ~ -14` (28 mm) |
| 외곽 | 사다리꼴, 높이 34.0 → 52.3 mm |
| 죠 외곽에서 인셋 | 2 mm |
| 볼트 | M3 2개, 손가락 방향 중심거리 20 mm, `Z = 0` |

볼트를 손가락 방향으로 두는 이유는 홈이 병 축(`Z`) 방향으로 파여서 `Z = 0` 중심선에는 항상 재료가 남기 때문이다.

## V홈 폭은 부착 창이 제한한다

부착 창이 28 mm라 홈 폭도 그 안에서 정해진다.

| 홈 폭 | 면으로 받는 최대 지름 | 인서트 두께 | 유효 개폐 |
|---:|---:|---:|---:|
| 24 mm (기본) | **D62.7** | 11.0 mm | 83.1 mm |
| 26 mm | D67.9 | — | — |
| 28 mm | D73.2 | — | 창 여유 없음 |

기본값 `24 mm`는 `source_container` 규격(`200~330 mL`, 지름 `50~62 mm`)을 면으로 받는다. 그보다 큰 병은 홈 모서리에 걸려 2점 접촉이 된다.

쐐기 마찰 증폭은 `135°`에서 1.08배로 거의 없다. **V홈의 가치는 마찰이 아니라 지름과 무관한 자기중심에 있다.** 미끄러짐은 TPU 패드가 맡는다 — 마찰계수를 0.2에서 0.8~1.0으로 올리므로 효과가 4~5배로 훨씬 크다.

## 세 형상

| 인서트 | 두께 | TPU | 시간 | 용도 |
|---|---:|---:|---:|---|
| `insert_A_flat_pad` | 7.0 mm | 8.4 cm³ | 47m | 평면. 마찰만 올림 |
| `insert_B_v_groove` | 11.0 mm | 11.4 cm³ | 1h 02m | V홈. 자기중심 추가 |
| `insert_C_trapezoid` | 8.1 mm | 8.2 cm³ | 47m | 사다리꼴 홈. 원통·평면 겸용 |

전부 같은 부착 규격이라 볼트를 풀고 바꿔 끼우면 된다.

## 부착

- M3 볼트 2개, 손가락 방향 중심거리 20 mm
- 인서트에 `Ø3.4` 관통, 파지면 쪽에 `Ø6.5 × 1.6` 자리파기로 머리를 묻는다
- **죠 쪽에 `Ø3.4` 관통 2개를 추가해야 한다.** 상류 STL 에는 없다. 실물 죠를 받아 부착 창 위치를 확인한 뒤 뚫는다

## ggao50 본체 출력

상류 STL 은 라이선스 표기가 없어 이 저장소에 두지 않는다. 필요할 때 받아서 방향을 잡고 슬라이싱한다.

```bash
cd "$HOME/bimanual-robot"
python3 design/gripper/prepare_ggao50_print.py --out "$HOME/gcode/ggao50"
```

받은 STL 과 생성한 G-code 는 `--out` 아래에만 생기고 커밋 대상이 아니다.

| 부품 | 방향 | 서포트 | PETG | 시간 |
|---|---|---|---:|---:|
| `backplate` | Y+90 | tree | 67.1 cm³ | 2h 49m |
| `leftgripper` | 원본 | tree | 26.4 cm³ | 1h 23m |
| `rightgripper` | X180 | tree | 26.4 cm³ | 1h 23m |
| `cameraplate` | 원본 | tree | 21.2 cm³ | 1h 42m |
| `connectorplate` | 원본 | tree | 12.0 cm³ | 41m |
| `pinion` | **X+90** | **off** | 2.7 cm³ | 17m |

한 팔 `155.8 cm³` ≈ `198 g`, `8h 14m`. 양팔이면 `396 g`, `16h 29m`이다.

`pinion` 은 X+90 으로 눕히면 서포트가 사라진다. 나머지 다섯은 회전으로 없앨 수 없어 tree 서포트를 베드에서만 세운다(`--plate-only`). 죠는 파지면이 수직이 되는 원본 방향을 유지해 접촉면에 서포트 자국이 남지 않게 한다.

## 인서트 출력

인서트는 TPU 95A 로 뽑는다.

```bash
python3 design/cad/slice_k1max_petg.py --out "$HOME/gcode/inserts" \
  --tpu --infill 100% --support off design/gripper/exports/stl/insert_*.stl
```

| 인서트 | TPU | 시간 |
|---|---:|---:|
| `insert_A_flat_pad` | 8.4 cm³ | 47m |
| `insert_B_v_groove` | 11.4 cm³ | 1h 02m |
| `insert_C_trapezoid` | 8.2 cm³ | 47m |

양팔이면 각 4개, 세 형상 전부 뽑아도 합계 `112 cm³`, `9h 44m`이다.

노즐 `230 °C`, 베드 `45 °C`. TPU 는 인필 100% 로 뽑아야 V 형상이 눌리지 않는다.

## 재생성

```bash
cd "$HOME/bimanual-robot"
"$HOME/.cache/bimanual-cad-venv/bin/python" design/gripper/generate_jaw_inserts.py
"$HOME/.cache/bimanual-cad-venv/bin/python" design/gripper/generate_jaw_inserts.py --v-angle 120 --groove-width 30
```

출력은 `exports/step`, `exports/stl`, `exports/manifest_inserts.json`이다.

## 선정 방법

계산으로 고르지 않는다. 세 형상을 TPU 95A로 뽑아 같은 병으로 기울임 시험을 한다.

1. 병을 물리고 `112.3°`까지 천천히 기울인다
2. 축 방향으로 흘러내리는지 확인한다
3. 주둥이 방향이 도는지 확인한다

그리퍼 조립 전에 죠 2개만 손으로 눌러도 재현된다.
