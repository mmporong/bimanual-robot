# 납품 규칙

## 폴더

```
~/Downloads/발표자료/<YYYYMMDD>_<팀·행사>_<작업>/
├── <파일 기본이름>.pptx      발표용(최신본 하나만 맨 위에). PDF는 만들지 않는다(사용자 지시 2026-10-07)
├── 발표 안내.txt
├── 글꼴/                    Pretendard Regular·SemiBold·Bold TTF + LICENSE.txt(OFL)
├── _build/                  deck.config.js · slides/ · assets/ (다시 빌드할 원본, 작업 디렉터리로도 사용)
└── _이전버전/                바뀌기 전 pptx/pdf. 결함이 있으면 안내문에 적는다
```

- `package.sh`가 pptx·글꼴·_build를 채운다. 기존 파일과 내용이 다르면 `_이전버전/`으로 옮긴다(삭제하지 않음).
- 이전 시안은 지우지 않고 `_이전버전/`에 둔다. 사용자의 다른 파일은 범위 밖이면 건드리지 않는다.
- 예: `~/Downloads/발표자료/20261002_MS팀_출정식_모션리디자인/MS팀_프로젝트출정식_모션리디자인_화이트스카이.pptx`

## 발표 안내.txt 틀

```
<덱 이름> (<디자인 이름>, <YYYY-MM-DD>)

파일
- <이름>.pptx : 발표용 최신본
- 글꼴/ : Pretendard Regular·SemiBold·Bold TTF와 라이선스(OFL)
- _build/ : 다시 생성할 때 쓰는 스크립트 입력과 이미지·영상 자산
- _이전버전/ : (있으면) 무엇이고 왜 쓰지 않는지

발표 방법
1. LibreOffice Impress 또는 PowerPoint의 슬라이드 쇼로 엽니다. 한 쪽에 클릭 한 번이면 됩니다.
   등장 애니메이션은 쪽이 열리면 자동으로 이어서 재생됩니다(대부분 1.5~3.5초 안에 끝남).
2. 쪽 사이 전환: PowerPoint 2019 이상·Microsoft 365는 Morph, LibreOffice는 페이드로 넘어갑니다.
3. 영상: 쪽마다 무엇인지, 배속, 언제 재생되는지. PowerPoint는 반복 재생, LibreOffice는 한 번 재생 후 멈춤.
   소리가 필요하면 PowerPoint에서 영상 선택 → 재생 탭 → 볼륨에서 음소거 해제.
4. 다른 PC에서 글꼴이 바뀌어 보이면 글꼴 폴더의 TTF 3개를 설치한 뒤 다시 엽니다.
5. LibreOffice에서 이 파일을 PPTX로 다시 저장하면 Morph·일부 애니메이션·포함 글꼴이 빠질 수 있습니다. 보기·발표만 하고 저장은 하지 않습니다.

디자인
- 색·글꼴·로고·이미지 처리(둥근 모서리, 원본 색 유지한 실험 자료)

쪽별 모션
- 모션이 특징적인 쪽만 한 줄씩

디자인 외에 바뀐 내용
- 원문과 달라진 문구·수치·쪽 번호·다시 만든 차트와 표 (빠짐없이)

확인 범위
- 확인함: 구조 검사, 애니메이션 시각 대조, 렌더 검수, 가림 검사, 문구 대조, LibreOffice 녹화로 확인한 쪽
- 확인하지 못함: PowerPoint 실재생, 녹화하지 않은 쪽

사용한 스킬·도구
- Anthropic pptx 스킬, ppt-master(MIT), Pretendard(OFL) 링크
```

## 완료 보고

1. 결과 한 줄과 납품 폴더 전체 경로
2. 바꾼 내용: 사용자 요청 항목별로
3. 검증 근거: 빌드 출력의 세 줄(맞춤 경고, 가림, validate), 렌더 검수, 녹화로 확인한 쪽
4. 남은 제약: LibreOffice 1회 재생·Morph 없음·영상 모서리, PowerPoint 미확인, 녹화하지 않은 쪽
5. 띄운 프로세스(Xvfb·soffice·ffmpeg)가 남지 않았는지 확인했다는 사실
