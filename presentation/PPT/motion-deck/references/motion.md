# 모션 규칙

## 효과 지정

`txt/box/circle/line/img/…(…, a)`의 마지막 인자 `a`로 단다. 배열이면 한 객체에 효과 여러 개.

```js
{ e: 'up', d: 300, t: 0.45 }                                   // 300ms에 위로 떠오르며 0.45초
[{ e: 'fade', d: 0, t: 0.3 }, { e: 'path', d: 300, t: 2.4, dx: 0.8, dy: 0 }]   // 나타난 뒤 경로 이동
{ e: 'pulse', d: 1600, t: 0.6, size: 108, repeat: 2 }          // 커졌다 돌아오기 2번
{ e: 'out', d: 2250, t: 0.5 }                                  // 사라지기(덮개용)
```

| `e` | 효과 | 쓰임 |
|---|---|---|
| `fade` | 나타나기 | 글자, 범례, 출처 |
| `up` / `down` | 떠오르기 / 내려오기 | 카드, 행, callout |
| `zoom` | 서서히 확대 | 큰 숫자, 사진, 강조 카드 |
| `grow` | 확대 | 번호 원, 아이콘 점, 커넥터 |
| `wipeR` `wipeL` `wipeU` `wipeD` | 닦아내기: 왼→오, 오→왼, 아래→위, 위→아래 | 선 그리기, 막대 채우기, 표, 셰브런 |
| `path` | 직선 경로 이동. `dx`·`dy`는 쪽 크기 비율(가로 13.333, 세로 7.5 인치 기준) | 이동 배지, 데이터 점 |
| `pulse` | 크기 강조 후 원래대로(`size` %, `repeat`) | 허브, 채택 칸 |
| `out` | 사라지기 | `coverUntil` 덮개 |

- `d`는 **쪽 시작부터의 절대 ms**다. 모든 효과는 "이전과 동시에" 트리거로 묶인다. 클릭 한 번으로 쪽 전체가 자동 진행된다.
- `repeat: 60` + `path`는 사실상 계속 반복한다(kickoff s17 데이터 점). 반대 방향 점은 반 주기 늦게 시작한다.
- `path` 프리셋은 가감속(50%/50%)이 들어 있어 처음과 끝이 느리다. 시계·재생 막대처럼 등속이어야 하면 `linear: true`를 준다.
  (2026-10-07 해커톤 덱 90초 재생 막대: 가감속 상태에서 처음 10초 동안 거의 움직이지 않는 것을 녹화로 확인)
- 이동이 끝난 점이 글자를 가리면 `{ e: 'out', d: 도착 시각 }`으로 지우고, 정지 렌더에서는 `if (!L.STATIC)`로 뺀다.
- 표·차트는 그린 뒤 `L.anim(objectName, a)`로 단다.

## 시간 배분

- 헤더(칩·제목·로고·쪽 번호)와 배경 원은 애니메이션 없이 바로 보인다. Morph가 이전 쪽에서 이어 준다.
- 순서: 주 요소(0~300ms) → 세부(150~220ms 간격으로 차례로) → 결론 callout(마지막). 한 쪽 전체는 1.5~3.5초 안에 끝낸다.
- 길이: 글자 0.3~0.5초, 카드 0.45~0.5초, 선 그리기 0.8~2.4초, 경로 이동은 선 그리기와 같은 시간에 맞춘다.
- 이동 배지와 단계 점등은 같은 시계를 쓴다: 단계 i의 등장 시각 = 출발 + (i/(n-1))·이동시간.
- 같은 덩어리(카드 + 아이콘 + 글자)는 같은 `a` 객체를 넘겨 함께 움직인다.

## 쪽 전환과 Morph

- 기본 전환은 Morph(0.9초)다. PowerPoint 2019 이상과 Microsoft 365에서만 동작하고, 그 밖에서는 페이드(0.7초)로 대체된다.
- 이름이 같은 객체끼리 짝지어진다: `!!orb1` `!!orb2` `!!chipnum` `!!chiplabel` `!!title` `!!logo` `!!pg` `!!q1`~`!!q4`.
  - 팀 허브 쪽의 큰 카드 `!!q1~4`는 다음 쪽부터 미니 팀 지도 칸(`header({ mini })`)으로 줄어든다.
- 표지처럼 앞 쪽과 이어질 것이 없는 쪽은 `newSlide({ transition: 'fade' })`로 둔다.
- `!!` 이름은 한 쪽 안에서 한 번만 쓴다. 겹치면 post.py가 멈춘다.

## 영상

- `videoCard(name, file, poster, x, y, w, h, 길이ms, 재생시각ms, { cover, appear })`
  - 기본은 무음 자동 재생, PowerPoint는 반복, 영상을 클릭하면 일시정지/재생. 소리가 필요한 시연 영상은 `{ sound: true }`(변환 때 오디오를 빼지 말 것).
  - 휴대폰 세로 영상은 회전 정보(rotation -90 등)가 있어 저장 크기와 화면 비율이 다르다. `ffprobe -show_entries stream_side_data=rotation`으로 확인하고 `scale=720:-2`처럼 비율을 유지해 변환, 카드도 9:16으로 둔다.
  - 영상이 쪽 시작보다 늦게 나타나면 `appear`를 주고 `cover: true`를 함께 준다.
    덮개는 배경색 상자이고 `appear` 시각에 사라진다. PDF용 STATIC 빌드에서는 빠진다.
- 포스터는 영상의 첫 프레임이 검은 화면이면 1~2초 지점에서 뽑는다:
  `ffmpeg -ss 1.5 -i clip.mp4 -frames:v 1 -q:v 3 poster.jpg`
- 길이 ms는 실제 길이를 넣는다: `ffprobe -v error -show_entries format=duration -of csv=p=0 clip.mp4`
- 배속·편집 영상이면 `tagPill('영상 3배속', …)`처럼 표시한다.
- 화면 크기: 16:9 영상은 폭 7.75" 카드(높이 4.36")가 기준이다. 쪽 아래쪽 띠에 둘 때는 높이 2.4"로 둔다.
